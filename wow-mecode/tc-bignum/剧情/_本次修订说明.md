## 关键设定变更对照

### 真龙起源（最重要）

**旧版（作废）**
```
五色守护巨龙各剥离一片龙魂 + 星灵献出星辉 + 世界之魂碎片
→ 三者在世界之柱遗址融合 → 真龙诞生
→ 定位：一条"绷带"，欠所有人的债
```
问题：他是被造物 → 就有造物主 → 就有软肋 → 和「绝对无敌」自相矛盾；
      而且戏剧性太强，像机械降神。

**新版（采用）**
```
第一重·先于形体：真龙与世界之魂同岁甚至更早。天地生养万物，
                 也生养了"看着万物的那只眼"。他一直在，只是没有形。
第二重·天意指示：世界之魂受创到阈值，必然性显形。八方生灵在同一
                 瞬间"想起"同一件事——去那里，护住那团东西。
第三重·集合力量：巨龙们做的不是"造"，是"聚"和"护"。持续七百年。
                 成形之日无任何异象。
```
好处：无造物主 → 无软肋 → 支撑绝对无敌；
      去戏剧化 → 越大的事越安静 → 反而更有史诗感；
      "孕育"变成巨龙们自己的谦称，真相是天生地养 —— 完全贴合用户原话。

### 「万物之债」重新定义
- 旧：真龙欠守护者/星灵/世界的债
- 新：**均衡律**。天地生养万物，万物欠天地。真龙代天收账，
      他既是债主，也是那本账簿本身。他不欠任何人。

### 噩梦线升级（新）
噩梦不杀人，**它放大你本来就想做但一直忍着的事**。
→ 噩梦爆发时最可怕的不是怪物，是身边战友突然去砍了他恨了两百年的人。
→ 于是：**外部的病，只能靠内部的和解来治**。主题彻底统一。
→ 七位梦魇领主 = 七笔被放大的旧账，每一笔都对应前面写过的种族故事，
  可直接做成 7 个副本 Boss。

### 「源血」机制（新·逼出跨阵营合作）
唯一能补裂缝的物质，只在少数地方涌出，且**必须两种以上不同血脉的
生灵同时在场**才能采集（世界之魂需要"多样性"来确认自己还活着）。
→ 剧情上逼双方坐下，玩法上逼混合队。
