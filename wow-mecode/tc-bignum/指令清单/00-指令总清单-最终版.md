### 📦 第 4 批：幻化模块（独立模块，持久化）

```
.transmog set 装备ID              把当前选中装备槽幻化成指定外观
.transmog slot head 装备ID        指定槽位幻化
.transmog remove                  移除当前槽位幻化
.transmog clear                   清空全身幻化
.transmog list                    查看当前幻化状态
```

**为什么这次能做成持久化**（上一轮说做不到，是因为没深挖）：

我找到了关键点——全服**只有一个函数**负责写外观字段：

```cpp
// Player.cpp:12170，全仓库仅此一处写 PLAYER_VISIBLE_ITEM_ENTRYID
void Player::SetVisibleItemSlot(uint8 slot, Item* pItem)
{
    SetUInt32Value(PLAYER_VISIBLE_ITEM_1_ENTRYID + (slot * 2), pItem->GetEntry());
    ...
}
```

调用点只有 5 处，全部在 Player.cpp 内。所以只要在这一个函数里插入
"查幻化表，有映射就用映射的 entry"，**所有场景（登录、换装、跨图）自动生效**。

再配合已确认存在的脚本钩子做持久化：
```cpp
virtual void OnLogin(Player* player, bool firstLogin);   // ScriptMgr.h:692
virtual void OnSave(Player* player);                     // ScriptMgr.h:707
```

存储用一张自定义表 `custom_transmog(guid, slot, fake_entry)`。
**结论：重登不失效、换装不失效、别人也能看到。是真幻化。**

## 四、⭐ 我额外推荐的（源码已验证可行，你没提但很实用）

按"玩家用起来舒适"这个目标，我挑了这些：

### A. 玩家自助类（不给 GM 权限，普通玩家也能用）

```
.my stuck                         卡住自救（比 .unstuck 限制更松）
.my repair                        自助修理（可设收费/免费）
.my bank                          随地开银行
.my mail                          随地开邮箱
.my resetcd                       清自己的技能CD
```

> **这类最能提升体验**。原版 `.bank`/`.mailbox` 都是 GM 权限，
> 开成玩家可用（用独立 RBAC 权限号，给默认玩家组）能省掉大量跑图时间。

### B. 效率类

```
.gear stats                       全身装备属性汇总（不用一件件看）
.item info 物品ID                 查物品完整数值（含大数值改造后的）
.lookup item name 中文名          按中文搜物品（原版 .lookup item 已支持，但我可优化输出）
.tele last                        传送回上一个位置（撤销误传）
.tele home                        回炉石点
```

### C. 战斗测试类（自己调数值时特别有用）

```
.dummy spawn                      在脚下召唤一个打不死的木桩假人
.dummy dps                        ⭐显示对木桩的 DPS 统计（测装备用）
.combat log                       输出最近一次战斗的伤害明细
```

> `.dummy dps` 这个对你改造大数值装备很有价值——改完直接打木桩看实际 DPS，
> 不用靠感觉猜。实现方式：召唤高血量假人 + 统计 `DealDamage` 累计值 / 时间。

### D. 管理便利类

```
.gm fly                           GM 飞行（原版 .gm fly 有但常被忽略）
.go last                          回到上一个传送点
.announce cn 消息                 发全服中文公告（带格式美化）
.online                           查看当前在线人数与列表
```

## 六、⚠️ 框架陷阱提醒（第 1 批会踩）

这个仓库**新旧两套命令框架混用**：

| 框架 | 文件数 | 写法 |
|---|---|---|
| 新版 `ChatCommandTable` | 31 个 | `HandleXxx(ChatHandler*, Optional<uint32> arg)` 自动解析参数 |
| 旧版 `std::vector<ChatCommand>` | 11 个 | `HandleXxx(ChatHandler*, char const* args)` 手工 `atoi` |

- **`cs_modify.cpp` 是旧版** ← 第 1 批要改它，必须用旧写法
- **新建的文件我一律用新版**（更简洁、参数自动校验）

网上教程大多是新版写法，直接抄进 `cs_modify.cpp` 会编译失败。
