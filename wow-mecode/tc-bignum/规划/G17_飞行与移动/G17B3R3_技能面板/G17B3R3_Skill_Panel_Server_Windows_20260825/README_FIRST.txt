G17-B3R3 御龙技能面板（高版本御空术式：技能住进你自己的技能书）
================================================================

按你的要求实现"高版本御空术"模式：技能上限不再受坐骑栏 6 按钮约束——
骑龙时服务端把御龙技能临时教给玩家本人（4 移动 + 5 当前坐骑类型战斗），
配一个独立插件条 G17DragonBar 显示 11 个按钮，客户端 UI 一个文件都不改。

原理（已在服务端源码核实）：
  - 本 fork 的 SpellInfo::CheckVehicle 允许玩家在载具座位上施放带
    0x100（骑乘时可施放）属性的法术——我们的 29 个技能全带此属性；
  - B3R1 当年失败只是因为默认 UI 在控制座位时藏起了玩家动作条；
  - G17DragonBar 是普通插件（Interface\AddOns 文件夹），完全绕开这一点。

你会得到：
  - 骑龙时屏幕下方多一条 11 按钮技能条：
    [拉升][俯冲][推进][冲刺][制动][着陆] + [当前坐骑类型的5个战斗技能]
  - 战斗技能按钮带冷却转圈；条上显示龙能量数值；
  - 换不同类型坐骑（龙/兽/魔法/机械/通用）时战斗技能自动换成对应5个；
  - 下龙自动隐藏、技能自动从技能书移除（登录也会清理）；
  - 原来的 6 按钮坐骑栏完全保留——两条路都能放技能，互不冲突，
    冷却双端同步（哪边按了另一边也灰）；
  - 技能条可拖动（左键，脱战时）；/g17bar reset 重置位置。

安装（一个包全搞定，无需 SQL/DBC——B3R2 已铺好）：
  1. 关闭 WoW 客户端和 worldserver。
  2. 双击 01_Install_Build_G17B3R3.cmd
     （自动：包自检+24项单测 -> 源码替换 -> 安装插件到客户端
       Interface\AddOns\G17DragonBar -> MSBuild 重编 -> 校验新 exe）
     首行必须显示 B3R3_BUILD=r1_skillpanel。
  3. 看到 [G17B3R3] INSTALL/BUILD PASSED。
  4. 启动 worldserver（日志应出现 ">> G17-B3R3 skill panel LOADED"）
     和 WoW 客户端（插件列表里应启用 G17 DragonBar）。
  5. 召唤坐骑：G17DragonBar 出现，11 个技能随便用。

回滚：双击 02_Rollback_G17B3R3.cmd（源码回 B3R2d + 移除插件 + 重编）。

已知边界（如实说明）：
  - 插件是按 3.3.5 API 写的，但无法在沙箱里跑真实客户端。若进游戏后
    按钮按下无反应（客户端拦截了控制座位的玩家施法），回传现象——
    备用方案是给 29 个法术的 DBC 再补一个 AttributesEx6 位
    （CASTABLE_WHILE_ON_VEHICLE），管线我们已经有了，下一版就能出。
  - 位移类技能（拉升/俯冲等）从玩家施放时同样生效（服务端双施法者支持）。
