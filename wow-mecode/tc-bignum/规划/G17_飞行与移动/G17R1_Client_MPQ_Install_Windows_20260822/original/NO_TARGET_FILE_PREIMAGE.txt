G17-R1 client packed-MPQ target preimage policy
Date: 2026-08-22 Asia/Shanghai

This batch never overwrites an existing client patch archive or an existing
loose patch directory. It scans patch-Z.MPQ down through patch-A.MPQ and only
selects an absent target. Therefore the accepted target preimage is exactly:

TARGET_PREIMAGE=ABSENT

Existing higher-priority custom patches are read-only inspected. If one already
contains DBFilesClient\Spell.dbc, or cannot be inspected safely, installation
fails closed. The generated install state records the chosen target, archive
hash, client root, client DBC hash, server DBC hash and absent-target preimage.
Rollback removes only that exact state-owned archive after its hash is verified,
and preserves the removed archive plus install state under uploads.
