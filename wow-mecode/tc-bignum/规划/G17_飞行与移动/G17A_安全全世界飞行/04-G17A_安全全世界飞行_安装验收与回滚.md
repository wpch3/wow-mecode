## 4. 安全边界

G17只在以下条件全部成立时替代旧世界的 `IsFlyable()`失败：

- `WorldFlight.Enable=1`；
- `WorldFlight.AllowOldWorld=1`；
- map恰好为0或1；
- MapEntry是普通世界地图；
- 当前Area/Zone存在；
- 不带 `AREA_FLAG_NO_FLY_ZONE`；
- 不带 `AREA_FLAG_ARENA` / `AREA_FLAG_ARENA_INSTANCE`；
- `BlockIndoorAreas=1`时不带 `AREA_FLAG_INSIDE`；
- `BlockCapitalAreas=1`时不带主城/主城子区域flags；
- 当前Zone/Area不在 `BlockedAreaIds`。

仍然执行：

```text
player->CanFlyInZone(map_id, zone_id, this)
```

因此北裂境54197逻辑没有被改成恒真。原版外域/北裂境逻辑也保持原样。

`strict=false`的区域更新链同样使用G17边界，所以进入主城、室内或额外禁飞Area时，原飞行光环会通过现有 `UpdateAreaDependentAuras` 链被移除，而不是只在首次召唤时检查。

## 5. 安装器模式

```powershell
python install_g17a_world_flight.py --self-test
python install_g17a_world_flight.py --check D:\TrinityCore
python install_g17a_world_flight.py --apply D:\TrinityCore
python install_g17a_world_flight.py --rollback D:\TrinityCore
```

- `--self-test`：不读用户源码；验证完整源文件、正反fixture、Apply/重复Apply/Rollback。
- `--check`：只读真实源码，必须看到 `CHECK_READY_TO_APPLY=True`。
- `--apply`：精确修改1个文件并创建备份。
- `--rollback`：只接受精确posthash和精确prehash备份。

当前先运行self-test和check；看到统一入口规定的完整成功标志后再Apply。

## 7. 验收矩阵

| 编号 | 场景 | 预期 |
|---|---|---|
| A0 | Enable=0，东部王国/卡利姆多 | 完全保持原版，飞行坐骑不能启用 |
| A1 | Enable=1，东部王国普通户外 | 飞行坐骑可启用、起飞、移动、降落 |
| A2 | Enable=1，卡利姆多普通户外 | 同A1 |
| A3 | 主城，BlockCapitalAreas=1 | 禁止召唤；从野外飞入时光环被移除 |
| A4 | 明确室内，BlockIndoorAreas=1 | 禁止或进入后移除飞行光环 |
| A5 | NO_FLY区域 | 始终禁止，不能通过conf绕过 |
| A6 | 世界竞技场/竞技场实例 | 始终禁止 |
| A7 | 普通副本/团队副本 | map不是0/1，始终不走G17放行 |
| A8 | 战场 | 始终不走G17放行 |
| A9 | 外域 | 原版逻辑不变 |
| A10 | 北裂境无54197 | 原版寒冷天气要求仍生效 |
| A11 | 北裂境有54197 | 原版允许 |
| A12 | BlockedAreaIds加入当前Area | 该Area禁止；移除ID并重启后恢复 |

每项记录：地图ID、Zone ID、Area ID、坐骑法术、召唤结果、是否自动移除、Server.log第一条G17相关错误（正常情况下应没有错误）。

## 8. 回滚

先正常停服，然后：

```powershell
python install_g17a_world_flight.py --rollback D:\TrinityCore
```

确认恢复哈希：

```text
78dbc810f8afa080275d7fabcb2bc75ff52652295a25677b447cbe5f3ca89753
```

删除或移走运行目录的 `g17_world_flight.conf`，再按原配置重新编译。不要手工用旧01号方案修改DBC或 `Player::CanFlyInZone()`。
