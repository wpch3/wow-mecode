G17-B3R4c 御龙战斗体验强化（伤害/特效/射程/坐骑协战 + 插件v2，谱系门修复版）
================================================================

按你的实测反馈逐项修复 + 新增坐骑协战：

【修复】插件技能条不出现（G17DragonBar v1 的根因）
  - v1 用了 IsSpellKnown——3.3.5 客户端没有这个 API，所以条永远不显示。
  - v2 改为扫描技能书按法术名检测（GetSpellBookItemName/GetSpellName，
    3.3.5 原生 API）；按钮改为纯 SecureActionButtonTemplate 手工构建，
    不再依赖任何不确定的模板继承；所有调用 pcall 保护。
  - 进游戏后可用 /g17bar debug 查看检测结果（标记法术是否识别）。

【修复】伤害太弱（80级满装只有几十点）
  - 伤害现在按骑手等级缩放：每级+15（终结技每级+45再乘2.6倍）。
  - 80级参考值：普通技约1250、生成器约630+8能量、终结技约9800
    （再乘坐骑类型倍率0.9-1.2；对玩家×0.45）。

【修复】无法命中
  - 根因：25个战斗法术的DBC射程是"自身"(0码)，选中目标施放时服务端
    CheckRange直接拒绝。
  - 本包自动把服务端 Spell.dbc 里这25条的射程改为30码（原位修改、
    幂等、有备份）。移动技能(拉升/俯冲等)保持自身射程不受影响。

【新增】战斗特效回馈
  - 战斗技能命中：龙做出攻击动作（近战攻击包）+ 目标身上触发冲击环
    特效；治疗技能触发丝带特效；伤害数字随伤害包正常浮动显示。

【新增】坐骑协战（你要求的"我自己战斗的时候坐骑也会自己释放技能"）
  - 你进入战斗时，坐骑每3.5秒自动协助攻击你当前目标：
    伤害归属=你，40码+视线校验，每次消耗5点龙能量；
    能量低于20时自动停止（绝不会把你耗到飞不起来）；
    战场/竞技场禁用。
