F45R1：拾取播报源码级静默（版本兼容）
=====================================

为什么需要它：你在 worldserver.conf 加了 AoELoot.Announce = 0 但播报还在——
说明你编译进 worldserver.exe 的那版 CustomAoELoot.cpp 没有走这个开关
（你的 F45 包曾被新旧版本混杂污染过，实际应用的版本未知）。

本补丁直接改源码，自动识别两种版本：
  V1（有开关版）：把开关默认值 true 改成 false——不依赖任何 conf，播报关闭
  V2（无开关版）：把整条播报语句替换为注释（括号/字符串感知的精确匹配）
只动播报，不动任何拾取逻辑。自动备份原文件到 uploads\F45R1_Backup_*\，
可随时 02_Rollback_F45R1.cmd 恢复。

安装顺序（与 G17-B3R11 一起，一次编译）：
  1. 关闭 worldserver
  2. 双击 01_Install_F45R1.cmd → PASSED（此时只是源码变了，还没编译）
  3. 双击 G17B3R11 的 01_Install_Build_G17B3R11.cmd → PASSED（统一编译）
  4. 重启 worldserver → 播报消失（拾取功能保留）＋ 陆地坐骑飞行不再蹬腿
