The tool is used only to create, list, inspect and extract the client custom MPQ.
The package verifies the executable hash before use. It creates a WotLK format-2
archive, then independently checks file count and extracts both
DBFilesClient\Spell.dbc and DBFilesClient\AreaTable.dbc for exact SHA-256 and
size verification before and after installation.

A same-version Linux AMD64 upstream binary was used only for the offline real-MPQ
lifecycle simulation. That Linux binary is not shipped in this Windows package.
