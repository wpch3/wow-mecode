# G17-B2R2 三技能 Runtime 最终修正

日期：2026-08-24
状态：**承接 B2R1 的真实 Windows 源码应用/World 迁移/MSBuild PASS，针对用户真人 Runtime 反馈的三项缺陷做最终修正。**

## 背景：用户对上一版（B2R1）的真人反馈

1. **技能2有反馈，但特效太简陋。** 只有一个细尾流，缺少爆发感和分段反馈。
2. **技能3有 bug：不是按照我的方向冲刺，而是固定方向转弯冲刺，会出现增强掉头。** 路径基线用了陈旧的平滑航向，导致朝旧方向起步再弯回当前朝向。
3. **技能4无法使用，所有坐骑都这样；技能选错了，应该是“飞行器着陆”，ID=52226，它是任务道具的技能。**

## 修复1：技能2 特效增强（不再简陋）

**重要：只用项目真实 3.3.5a zhCN SpellVisualKit.dbc 已审计过的 Kit（B2R1 视觉审计证据中的 44/696/13709/13481/1066），不凭空捏造客户端可能不存在的 ID。** “更丰富”靠这些已知 Kit 的分层与节奏实现，不引入未验证 ID（B2R1 已明确拒绝 14475 火焰模型与 11818 持久状态 Kit）：

- **启动**：连发两次 Kit 44（ChargeTrail+启动声）形成双层爆发，再立刻发一次 Kit 696 尾流，机械/火箭额外发 Kit 13481 喷气火焰，其它类型补发 Kit 13709 风爆。
- **持续**：尾流间隔从 700ms 收紧到 550ms（Kit 696 RibbonTrail），并叠加一条 1100ms 的交替脉冲（奇数次 Kit 13709 风爆、偶数次 Kit 696 尾流），让推进有“身体”和节奏，而不是一条细线。
- **进入极速**（速度≥1150%）：连发 Kit 13709 风爆 + Kit 13709 冲击环，明确提示进入极速段。
- **结束**：连发 Kit 13709 结束风爆 + Kit 13709 冲击环，避免推进突然无声中断。

所有 Kit 均为客户端一次性视觉，无 Aura、无伤害、无循环状态；机械火焰仍然只对机械类型生效。

## 修复2：技能3 朝向冲刺（根除掉头）

- 删除以 `_smoothedTravelHeading`（上次冲刺/动量采样残留的旧航向）作为路径基线的逻辑。
- 7 节点路径的**起点切线、每一步前进方向、终点切线全部锚定施法瞬间骑乘者的当前朝向**（`Player::GetOrientation()`，取不到时回退 `Creature::GetOrientation()`）。
- 水平方向不再做任何偏航插值（移除 0.70 弧度转弯与 Catmull-Rom 水平转弯），只有高度按 SmoothStep 爬升——冲刺就是“朝你看的方向直线前冲爬升”。
- 终点切线写回平滑航向并平滑交还控制；保留 20/12/7 码三级 LOS 避障回退与 2600ms 超时 fail-safe。

这样无论玩家怎么转向，技能3都不会朝旧方向冲出去再掉头。

## 修复3：技能4 全部坐骑可用（52226 飞行器着陆）

- 保留用户指定的 52226（“飞行器着陆”，任务道具技能）作为动作条第4格与 `spell_script_names` 绑定；World 绑定守护 SQL 幂等复核该绑定，拒绝外来冲突槽。
- 给 `spell_g17_dragon_safe_landing` 增加 `OnCheckCast`：当施法者是 G17 御龙骑乘生物时显式返回 `SPELL_CAST_OK`，覆盖 52226 原本携带的任务/道具施法条件——这正是 B2R1 里“所有坐骑都不能用”的根因（龙不是原任务的飞行器，DBC 条件拒绝施法）。
- `OnEffectHit` 中 `PreventHitDefaultEffect` 抑制原生 Dummy 效果，保证任务行为不会在御龙骑乘时误触发；仅启动 G17 着陆状态机。
- 额外在 `AfterCast` 中做一次幂等的 `ACTION_LAND` 兜底（AI 内有 `_landing` 守卫，重复调用安全），避免单一钩子顺序问题导致着陆不启动。
- 着陆外观仍按类型分段：魔法平姿风托、龙45码斜坡、机械反推、猛兽无火扑落、通用避障；触地统一归一 Vehicle/速度/姿态/重力/fall 信息并交还控制。

## 安装（用户 Windows）

> 前提：B2R1 已经真实 Apply + World 迁移 + MSBuild 通过。R2 只替换一个 C++ 文件并复核 SQL 绑定。

1. 停掉 worldserver。
2. 在解压目录执行（PowerShell）：
   `py -3 tools\apply_g17b2r2_source.py apply --source-root D:\TrinityCore`
   预期 `G17B2R2_SOURCE_APPLY=PASS`。
3. 用 DBeaver 对 `world` 库执行 `sql\G17B2R2_world_landing_binding_guard.sql`，结果应为 `G17B2R2_WORLD_BINDING_GUARD=PASS`（B2R1 已迁移时为幂等通过）。
4. 重新 CMake/VS2022 增量编译 worldserver（只需重编 `scripts` 项目）。
5. 启动新 worldserver，进游戏在户外空旷处：
   - 技能2：能看到启动爆发+持续尾流+气浪+极速冲击环+结束冲击环；
   - 技能3：无论转向何处，都朝当前朝向直线冲刺爬升，不再掉头；
   - 技能4：任意坐骑（龙/魔法/机械/猛兽/通用）都能触发分类型着陆。

回滚：`py -3 tools\apply_g17b2r2_source.py rollback --source-root D:\TrinityCore` 回到 B2R1 字节像。
