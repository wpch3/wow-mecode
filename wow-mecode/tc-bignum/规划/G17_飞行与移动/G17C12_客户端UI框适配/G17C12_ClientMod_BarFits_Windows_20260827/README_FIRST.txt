G17-C12 客户端魔改 v2：八个技能按钮适配 UI 框
=============================================

问题（用户报告）：技能加到八个后，原版载具条的 UI 框太小装不下（皮肤
美术按六个按钮的尺寸画的，按钮 7/8 溢出）。

方案（选择"缩小图标适配框"，不改皮肤美术）：在客户端自己的
VehicleMenuBar.lua 里给整个动作按钮框加一行 SetScale(0.75)——
8 个 62px 按钮等比缩放后正好回到原来 6 个按钮的占位宽度，与皮肤
美术严丝合缝。点击/快捷键/冷却全部不受缩放影响。
（觉得还想再大/再小：包内 payload lua 搜 0.75 改成想要的值即可，
或告诉我们下一版调。）

前置：C11 已装（你已装好 ✓）。
操作：关闭 WoW → 双击 01_Install_G17C12.cmd → PASSED → 重启客户端。
效果：上龙 → 八个按钮整齐排在载具条美术框内。
回滚：02_Rollback_G17C12.cmd。
结果文件：uploads\G17C12_CLIENTMOD_RESULT.txt
