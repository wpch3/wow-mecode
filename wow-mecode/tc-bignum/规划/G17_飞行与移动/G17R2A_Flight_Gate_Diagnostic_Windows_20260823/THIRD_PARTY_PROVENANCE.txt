The upstream documentation states that mpqcli creates, lists, extracts and
inspects MPQ archives through StormLib, supports a wow-wotlk game profile,
retains directory structure with Windows-style archive paths, and adds a
(listfile) automatically. This package additionally verifies the generated
archive by listing the internal target, checking format-version/file-count,
extracting DBFilesClient\Spell.dbc, and matching its exact SHA-256.

A same-version Linux AMD64 upstream binary was separately used for local
behavior validation of create --game wow-wotlk, list, info and extract. That
Linux binary is not shipped in this Windows package.
