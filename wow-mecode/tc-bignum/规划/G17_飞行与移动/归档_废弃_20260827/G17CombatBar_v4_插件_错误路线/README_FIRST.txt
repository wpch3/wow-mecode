G17CombatBar v4 战斗技能条（架构重做版）
=========================================

基于你回传的真实客户端诊断数据彻底重做的架构。

诊断发现（决定性）：
  - LearnSpell() 在 3.3.5 只影响服务端，客户端全部 IsKnown=false
  - 技能书 210 条里没有一条 G17 法术
  - 载具动作条（6 个移动技能）完全正常工作
  - 玩家骑龙时载具能量类型 3（能量）最大 100

v4 的改变：
  1. 检测方式：不再查法术书，改为检测载具状态
     （玩家在载具上 + 载具能量类型 3 + 最大值 100 = 我们的御龙）
  2. 只显示 5 个战斗技能（移动技能已在坐骑栏上，不需要重复）
  3. 施法方式：点击按钮调用 CastSpellByName()，由服务端的
     SpellScript 解析龙并执行（法术带 CASTABLE_WHILE_MOUNTED 属性）
  4. 自动识别坐骑类型（龙/兽/魔法/机械），显示对应的 5 个战斗技能

安装：
  1. 把 G17CombatBar 文件夹复制到 D:\WOW\Interface\AddOns\G17CombatBar\
  2. 重启 WoW 客户端，勾选 G17 CombatBar
  3. 召唤坐骑骑上去 → 战斗技能条自动出现

使用：
  左键点击按钮施放技能（可拖动调整位置）
  /g17c reset     重置位置
  /g17c debug     完整诊断
  /g17c arch      查看当前检测到的坐骑类型

布局：
  坐骑栏（底部中央）：[拉升][俯冲][推进][冲刺][着陆][切页]  ← 已有
  战斗条（可拖动）：  [技能1][技能2][技能3][技能4][技能5]  ← 新增
  同时可见 = 11 个技能

注意事项：
  - 如果按钮点击后没有反应，请输入 /g17c debug 回传结果
  - 自动施法（坐骑自动协击）需要你在战斗中才会触发
  - 确保目标在 40 码内且有视线
