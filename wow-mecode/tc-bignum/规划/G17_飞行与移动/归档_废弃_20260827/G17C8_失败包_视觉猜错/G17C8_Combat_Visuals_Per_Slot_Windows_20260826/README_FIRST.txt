G17-C8 技能差异化（每个技能不同特效 + 冷却显示）
==================================================

解决你反馈的两个问题：
  1. 只有一种特效 → 每个技能槽位现在有不同的法术视觉
  2. 没有冷却显示 → DBC写入RecoveryTime，客户端显示冷却转圈

每个技能的视觉（按槽位，不按坐骑类型）：
  [1] 生成器   → 火焰冲击（快速打击）    4秒冷却
  [2] 主伤害   → 火球术（投射弹道）      6秒冷却
  [3] 治疗/防御 → 快速治疗（治疗光效）   20秒冷却
  [4] 控场     → 制裁之锤（眩晕锤击）   10秒冷却
  [5] 终结技   → 炎爆术（大爆炸）       60秒冷却

同时确保（与C7幂等）：
  Effect_1 = SCHOOL_DAMAGE(2)  客户端渲染法术视觉
  ImplicitTargetA = 18          弹道飞向当前目标
  RangeIndex = 4                30码射程

前置条件：C3v2 已安装（有25个战斗法术载体在DBC中）。

操作：
  1. 完全关闭 worldserver 和 WoW 客户端。
  2. 双击 01_Install_G17C8_PerSlot_Visuals.cmd
     （自动：服务端DBC + 客户端MPQ 一步修复）
  3. 看到 [G17C8] INSTALL PASSED。
  4. 启动两端，召唤坐骑，切到战斗页：
     - 5个技能按钮各不相同（不同图标+不同特效）
     - 按技能后有冷却转圈显示

回滚：双击 02_Rollback_G17C8.cmd
