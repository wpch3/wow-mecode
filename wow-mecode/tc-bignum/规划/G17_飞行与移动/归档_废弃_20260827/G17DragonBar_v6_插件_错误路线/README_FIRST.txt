G17DragonBar v6 御龙术专用技能条（混合模式+诊断）
==================================================

v6 解决"第 7 格不显示"：
  * 槽 1-6：原生动作槽（与默认载具条同机制，安全点击）
  * 槽 7-8：混合模式——客户端若填充了 Bonus 第 7/8 槽则原生显示；
    否则自动切换为"玩家施法"安全按钮（type="spell" 按 ID 施放，服务端
    双施法路径支持，B3R8 服务端最佳；默认槽7=制动、槽8=切页）
  * /g17bar set 7|8 <990000-990028> 可把第 7/8 格换成任意御龙技能
  * /g17bar status：打印 BonusBarOffset + Bonus 槽 1-12 全部内容 + 当前页
    （请把输出回传——它能一次性告诉我们客户端到底填了几个槽）
  * /g17bar testcast <法术ID>：把槽 7 指向任意法术，点击测试玩家施法路径

保留 v5 全部功能：冷却圈（成功才显示，无幻影）、龙能读数+页名、
按键 1-8 与小键盘、拖动/缩放、只在御龙载具激活（任务坐骑零影响）。

安装：本文件夹里的 G17DragonBar 覆盖到 D:\WOW\Interface\AddOns\G17DragonBar
（确保 toc/xml/lua 三个文件都在），重启客户端。

建议服务端配套：G17B3R8_FINAL.zip（切页恒在第 6 格安全位＋制动第 7 格）。
