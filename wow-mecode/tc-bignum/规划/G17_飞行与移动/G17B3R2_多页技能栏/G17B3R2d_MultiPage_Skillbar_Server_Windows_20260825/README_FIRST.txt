G17-B3R2 坐骑多页技能栏（服务端综合包，配套 G17-C3 客户端按钮包）
================================================================

本包按你的要求重做了技能系统（一个服务端包：源码 + 服务端 DBC + world SQL + 重编译）：

 1) 技能栏在坐骑上，不在玩家法术书里
    - 坐骑动作条共 8 个槽位（Creature::m_spells），突破之前 4-5 个的显示上限；
    - 召唤坐骑后自动装上"移动技能页"，并立刻把新技能栏发给客户端；
    - 之前 B3R1 塞进法术书的 25 个技能会在上车/登录时自动清掉（迁移清理）。

 2) 移动技能页（纯净飞行，无攻击技能，6 个可见按钮）
    [1] 拉升      —— 消耗20能量，沿当前朝向急速爬升（新）
    [2] 俯冲      —— 不耗能量！恢复15龙能量+动量（新，能量回收循环）
    [3] 增强推进  —— 30能量高速冲刺（原有）
    [4] 朝向冲刺  —— 25能量限角冲刺（原有）
    [5] 飞行器着陆 —— 类型化着陆，r1d 起约2倍速度、更陡更连贯（原有）
    [6] 切换技能页 —— 切到战斗技能页（新）
    ※ 滑翔制动暂离动作条（按 S 键同样强力减速；技能保留注册，等将来扩
      客户端UI槽位时回归）。火息术已移除。
    ※ 原版3.3.5客户端的坐骑栏固定只显示6个技能按钮（实测发7个只显6个），
      所以每页排成"5技能+切页"= 6个。总技能数不受限：靠切页扩展。

 3) 战斗技能页（按坐骑类型，5技+切页）
    [1] 生成器    —— 免费！+8龙能量，造成一半伤害（新定位）
    [2] 主伤害    —— 12能量
    [3] 防御/治疗 —— 12能量，治疗18%+净化控制
    [4] 控场      —— 12能量，伤害+2秒眩晕（保证解除）
    [5] 终结技    —— 30能量，巨额伤害
    [6] 切换技能页 —— 切回移动页
    战斗页速度上限降为600%（设计文档7.2），切回移动页恢复。

 4) 切页随时可用，资源不重置
    - 切页只改动作条映射（m_spells + 重发SMSG_PET_SPELLS）；
    - 龙能量和冷却挂在坐骑身上，切页不重置（设计文档5.1）；
    - 战斗技能由坐骑施放，伤害/治疗/击杀归属=玩家本人；
    - 战场/竞技场禁用全部战斗技能（设计文档5.3）；
    - 攻击不能绕过距离（40码）/视线/阵营合法性；
    - 被动回能：每2秒+1（俯冲和生成器是快速回复手段）。

操作：
  1. 先装客户端按钮包 G17C3（01_Install_G17C3_Bar_Buttons.cmd），完成后再装本包。
  2. 完全关闭 worldserver。
  3. 双击 01_Install_Build_G17B3R2.cmd
     （自动：包自检+44项单测 -> 源码替换 -> 服务端 Spell.dbc 追加 990025-990028
       -> world SQL 脚本绑定+模板动作条对齐 -> MSBuild 重编 -> 校验新 exe）
     首行必须显示 B3R2_BUILD=r1d_sixslot_fastland。
  4. 看到 [G17B3R2] INSTALL/BUILD PASSED。
  5. 启动 worldserver，日志应出现：
     >> G17-B3R2 multi-page skillbar LOADED
  6. 进游戏召唤坐骑验收：
     - 坐骑技能栏显示 7 个移动按钮（没有火息术）；
     - 按最后一个按钮切到战斗技能页（当前坐骑类型的 5 个技能）；
     - 选中敌人按战斗技能：生成器回能、终结技爆发、控场眩晕；
     - 俯冲后能量恢复；随时切回移动页继续飞。
