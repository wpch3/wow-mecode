G17VisualDB 法术视觉对照库（3.3.5.12340 全量）
================================================

为什么有这个库：C8 特效灾难的教训（凭名字猜视觉ID→绿色旋风）写进了交接
文件铁律 §0.1——"查找资料＋完整对照"。本库把"资料"固化在仓库里：
49839 条 Spell.dbc 记录的 ID→SpellVisualID→名称 全量映射，列位经五个
已验证龙类法术校准。

用法（选特效的固定流程）：
  1. 按技能语义挑候选真实法术（如"弹幕"→奥术飞弹 5143）
  2. python g17visualdb.py 5143        → 得到视觉ID 262
  3. python g17visualdb.py 262         → 反查该视觉的其它来源，判断视觉强弱
  4. 检查 25 槽内无重复（C9/C10 的补丁器自带该检查）
  5. 在包内补丁器 dict 里写 visual 并注明源法术ID（可追溯）
