G17Diag 御龙术客户端诊断工具
============================

这是一个纯客户端插件（不改任何游戏文件），用来一次性采集所有诊断信息。

安装：
  1. 把整个 G17Diag_客户端诊断工具_20260825 文件夹里的 G17Diag 文件夹
     复制到 D:\WOW\Interface\AddOns\G17Diag\
     （确保里面有 G17Diag.toc 和 G17Diag.lua 两个文件）
  2. 重启 WoW 客户端
  3. 登录界面插件列表勾选 G17 Diag
  4. 进入游戏后聊天区应出现 "|cffffd700G17Diag|r 已加载"

使用：
  /g17diag          完整诊断报告（推荐）
  /g17d vehicle     只看载具状态
  /g17d spells      只看 G17 法术检查
  /g17d book        只看技能书扫描
  /g17d bar         只看动作条状态

诊断步骤（推荐顺序）：
  1. 召唤坐骑骑上去
  2. 输入 /g17diag
  3. 截图或复制聊天区全部输出
  4. 回传给开发

报告包含：
  - 客户端版本/区域/build
  - 载具状态（名称/GUID/能量/等级/类型/增益）
  - 玩家身上的增益列表
  - 全部29个G17法术的 DBC 存在性/图标/IsKnown/Usable/冷却
  - 动作条状态（VehicleMenuBar可见性/按钮图标）
  - 技能书完整扫描（标签页信息 + G17法术匹配结果）
