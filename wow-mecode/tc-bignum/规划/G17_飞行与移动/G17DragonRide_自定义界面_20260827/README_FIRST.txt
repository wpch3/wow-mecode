G17DragonRide 全新御龙界面（自定义 UI，整体覆盖原版无效载具条）
================================================================

这就是你要的"新客户端 UI"：骑龙时不再依赖原版 6 格载具条——一个完整的
专属界面接管全部技能操作，原版无效按钮默认隐藏。

界面组成：
  ┌────────────────────────────────┐
  │  G17 御龙术·专属界面    移动页  │
  │  ▓▓▓▓▓▓▓▓▓░░░ 龙能 62/100      │
  │  [拉升][俯冲][推进][冲刺][着陆][切页]   ← 主技能行（6格·原生机制·100%可用）
  │  [制动]                              ← 扩展行（玩家施法·可配6格·突破6格限制）
  └────────────────────────────────┘

关键能力：
  * 主技能行：原生动作槽机制（和原版条同源，绝不出错）
  * 扩展行：玩家施法按钮（配 B3R9 服务端全部技能可用）——
    /g17ride add 1 990000 把任意技能放上去（1-6格，990000-990028 任选）
    => 御龙术技能格数从此没有上限，想几格就几格
  * 原版载具条 6 个按钮默认隐藏（俯仰/离开等有效控件保留）
  * 能量条 + 页面指示 + 冷却圈（成功才显示，无幻影）
  * 按键：1-6 主行，7 8 9 0 - = 扩展行
  * 自动判定玩家施法是否被客户端放行：被拦截会自动折叠扩展行并提示
  * 只在御龙载具激活（能量类型3+上限100）——任务坐骑零影响

安装：
  1. 删除旧的 D:\WOW\Interface\AddOns\G17DragonBar（避免双条叠加）
  2. 把本文件夹里的 G17DragonRide 复制到 D:\WOW\Interface\AddOns\G17DragonRide
  3. 重启客户端，登录界面勾选 G17 DragonRide

必须配套：服务端 G17B3R9_FINAL.zip（三个移动技能的玩家施法支持）。
命令：/g17ride status 查看完整诊断（含 Bonus 槽 1-12 内容——请把输出发回，
它会最终确认客户端的填充行为，写入交接文档）。
