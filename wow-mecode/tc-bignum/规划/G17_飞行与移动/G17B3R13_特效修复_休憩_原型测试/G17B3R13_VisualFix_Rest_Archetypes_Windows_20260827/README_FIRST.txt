三个内容（源码-only；DBC/SQL 步骤是对 B3R12 的幂等重跑，直通）：

1.【更名】990029 聊天文案：突袭·俯冲打击 → 裂地重击
   （"俯冲"字样在攻击页被你读成飞行技能；配合 C14 客户端更名一起生效）

2.【.dragon rest 御龙休憩】（B4 第一步：骑乘恢复）
   骑龙状态下输入 .dragon rest → 龙悬停、你每秒回复 5% 最大生命与法力；
   再输一次或移动/下龙即结束。脱战吃喝的"休憩"形态先行落地。

3.【.dragon archetype 0-4】（你要求的"分种类应用测试"）
   骑龙状态下随时切换原型：0通用 1猛兽 2龙类 3魔法 4机械。
   战斗技能页立即刷新为该族技能，特效按该族显示——一只坐骑测完五族。

坐骑分类全表（服务端 InferArchetype 实际逻辑，多语言关键词+生物类型）：
   2 龙类：幼龙/始祖龙/元龙/巨龙/龙/proto-drake/drake/wyrm/netherwing…
   1 猛兽：马/狼/虎/熊/豹/科多兽/猛犸/迅猛龙/陆行鸟/山羊/raptor/kodo…
   3 魔法：飞毯/扫帚/凤凰/魔法/虚空鳐/无头骑士/亡灵/幽灵/carpet/phoenix…
   4 机械：火箭/机械/飞行器/摩托/直升机/涡轮/rocket/chopper/motorcycle…
   0 通用：以上都不匹配时的兜底（按生物类型兜底：龙类→龙、机械→机械、
     野兽→猛兽、恶魔/元素→魔法，其余→通用）
