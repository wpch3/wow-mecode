G17-C10 全类型特效完善（客户端 DBC）＋ G17DragonBar 御龙专用条插件
==================================================================

一、DBC 特效（双击 01_Install_G17C10.cmd）
------------------------------------------
龙类 5 技特效保持你已验收的 C9 v3 不变；其余 4 类全部换成语义匹配、
强视觉的真实法术（每个视觉 ID 都用完整 3.3.5.12340 Spell.dbc 对照库核对了来源法术）：

  猛兽: 撕咬=凶猛撕咬(48576) 连爪=斜掠(33876) 守护=强效治疗(2060)
        扑袭=突袭(9005)     嗜血=嗜血(23881)
  魔法: 弹幕=奥术飞弹(5143) 虹吸=吸取生命(689) 护盾=真言盾(17)
        过载=奥术超载(56432) 新星=奥爆(29919 boss版)
  机械: 机炮=机枪(10346)     火箭=火箭冲击(1940) 维修=焊接光束(35919)
        烟幕=烟雾弹(8817)    过载=流星(24340)
  通用: 猛击(1464) 顺劈斩(845) 快速治疗(2061) 制裁之锤(853) 炎爆术(11366)

前置：C3v2 及之后任一状态（C3/C6/C7/C8/C9 已装都行，幂等）。
操作：关闭 WoW → 双击 01_Install_G17C10.cmd → PASSED → 重启客户端。

二、G17DragonBar 御龙术专用技能条（手动复制，可选但强烈推荐）
-------------------------------------------------------------
把 addon\G17DragonBar 整个文件夹复制到 D:\WOW\Interface\AddOns\G17DragonBar
（确保里面有 G17DragonBar.toc/.xml/.lua 三个文件），重启客户端，登录界面勾选。

它做什么：
  * 御龙时自动显示独立的 8 格技能条（原生载具动作槽机制，安全施法）
    —— 默认载具条只有 6 格，这里能显示第 7/8 格（需要服务端 B3R7 起的
    7 槽布局；旧服务端也能用，只是第 7/8 格为空）
  * 修复"有冷却但 UI 不显示"：监听施法成功事件，按服务端冷却表
    （4/6/20/10/60 秒，切页 1 秒）对专用条和默认载具条的按钮显示冷却圈
  * 龙能读数、按键 1-8 与小键盘 1-8 施放、可拖动/缩放
  * 只在御龙载具（能量类型3、上限100）上激活——任务坐骑完全不受影响，
    任务坐骑继续用原生 6 格条（"任务是任务，御龙术是御龙术"）

命令：/g17bar unlock|lock|scale N|hideblizz on|off|strict on|off|test|reset|status

验收：
  1. 上龙 → 默认条上方出现"G17 御龙术"8 格条
  2. 施放任一战斗技能 → 对应按钮出现冷却圈并倒计时
  3. 无目标施放被拒 → 不出现冷却圈（不再有幻影冷却）
  4. 换上猛兽/魔法/机械类坐骑 → 特效按上表显示且 5 技互不相同

回滚：双击 02_Rollback_G17C10.cmd；插件删除 AddOns\G17DragonBar 即可。
结果文件：uploads\G17C10_CLIENT_VISUALS_RESULT.txt（安装）/ G17C10_ROLLBACK_RESULT.txt（回滚）
