G17-B3R11 服务端：陆地坐骑飞行"蹬腿"修复
==========================================

问题（用户报告）：陆地坐骑（马/狼等猛兽类、通用类模型）用御龙术飞行时
双腿不停蹬动（跑步动画）。

根因：这些模型没有 Fly 动画层，3.3.5 客户端回退到地面动画层——移动时
播放跑步循环。动画层无法修复（fork 源码注明：Swim 层客户端不处理，
Fly 层对无飞行动画的模型照样回退地面层）。

修复：服务端在飞行期间给 BEAST/GENERIC 原型的龙设置 EMOTE STATE
（站姿）——表情状态会覆盖非自身单位的移动动画（脚本 NPC 被推动时保持
姿势滑行的同一原理），双腿在空中停住；落地/退出时清除恢复正常动画。
带飞行动画的原型（龙/机械/魔法）完全不受影响。

可与 F45 静默补丁（F45R1）一起安装：先装 F45R1（改源码不编译），
再装本包（统一 MSBuild），或任意顺序（都会编译）。
操作：关 worldserver → 双击 01_Install_Build_G17B3R11.cmd →
      首行 G17B3R11_BUILD=520696ee → PASSED → 重启。
包含 B3R7-R10 全部改进；B3R6-R10 任一源码状态直装。
验收：骑陆地坐骑（马/狼类）上飞行腿不再蹬动（站姿滑翔）；
     龙类/机械/魔法坐骑外观不变；落地动画正常。
回滚：02_Rollback_G17B3R11.cmd。
