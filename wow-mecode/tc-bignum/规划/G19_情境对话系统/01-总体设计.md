## 零、你说得对，A42 我做窄了

A42 只做了「同一句话，不同职业换个说法」——**换皮，不是新内容**。

你要的是**内容量级的提升**：
```
到了幽暗城   -> 说幽暗城的事
进了通灵学院 -> 说通灵学院的事
在荒芜之地赶路 -> 说赶路的话
```

**这是"情境"维度，和"口音"维度正交。** 两者相乘才是真正的丰富度。

## 一、先算一笔账：为什么必须做成数据驱动

假设：

```
情境数    副本80个 + 主城7个 + 野外区域50个 + 通用场景10个  ≈ 150
职业数    10
每种至少  3 条
```

如果每个组合都单独写：`150 × 10 × 3 = 4500 条`。**不可能手写。**

### 解法：三层回退 + 占位符

```
第1层  精确情境（这个副本/这个城）+ 精确职业     最少，只给重点内容写
第2层  情境类别（"在副本里"/"在主城"）+ 职业     中等
第3层  纯通用                                    兜底
```

**任何一层命中就用，命中不了往下回退。**

这样：
- 重点副本（ICC、太阳井）手写专属台词 —— **有惊喜**
- 冷门副本走"在副本里"的通用词 + 自动填地名 —— **不空洞**
- 实在没有走纯通用 —— **不会哑巴**

**预计实际要写的：300-400 条**，可控。

### 2.3 主城/小镇判断 —— 不用手写列表

```cpp
DBCEnums.h:268    AREA_FLAG_TOWN       = 0x00200000,   // 带旅店的小镇
```

**A08 的 `.protect` 已经用过这招，验证有效。**

### 2.4 【重要发现】地名可以自动取，还带中文

```cpp
// DBCStructure.h:176
struct AreaTableEntry
{
    uint32 ID;                      // 0
    uint32 ContinentID;             // 1
    uint32 ParentAreaID;            // 2  if 0 then it's zone
    uint32 AreaBit;                 // 3
    uint32 Flags;                   // 4
    int32  ExplorationLevel;        // 10
    char const* AreaName[16];       // 11-26   <- 【多语言，含中文】
    ...
};
```

**这意味着台词可以写成模板：**

```
"{zone}这地方……我以前来过。"
```

运行时自动替换成「幽暗城这地方……我以前来过。」

**一条台词覆盖所有区域，这是把 4500 条压到 300 条的关键。**

## 三、数据表设计

### 3.1 新表 `npcbot_situation_text`

```sql
CREATE TABLE IF NOT EXISTS `world`.`npcbot_situation_text` (
  `id`          INT UNSIGNED     NOT NULL AUTO_INCREMENT,

  -- ===== 情境匹配（都是 0 = 不限）=====
  `scene`       TINYINT UNSIGNED NOT NULL DEFAULT 0
       COMMENT '场景类别 0=任意 1=副本 2=团本 3=主城 4=小镇 5=野外 6=战场 7=圣所',
  `map_id`      INT UNSIGNED     NOT NULL DEFAULT 0 COMMENT '精确地图 0=不限',
  `zone_id`     INT UNSIGNED     NOT NULL DEFAULT 0 COMMENT '精确区域 0=不限',

  -- ===== 说话人匹配 =====
  `bot_class`   TINYINT UNSIGNED NOT NULL DEFAULT 0 COMMENT '职业 0=通用',
  `bot_race`    TINYINT UNSIGNED NOT NULL DEFAULT 0 COMMENT '种族 0=通用',

  -- ===== 触发时机 =====
  `trigger_on`  TINYINT UNSIGNED NOT NULL DEFAULT 1
       COMMENT '1=进入区域 2=闲聊 3=战斗前 4=战斗后 5=死亡 6=升级',

  -- ===== 内容 =====
  `text`        TEXT             NOT NULL
       COMMENT '占位符 {zone}区域名 {player}你 {bot}我 {map}地图名',
  `emote`       INT UNSIGNED     NOT NULL DEFAULT 0,
  `weight`      TINYINT UNSIGNED NOT NULL DEFAULT 10,
  `cooldown`    INT UNSIGNED     NOT NULL DEFAULT 600 COMMENT '同条冷却(秒)',
  `comment`     VARCHAR(255)              DEFAULT NULL,

  PRIMARY KEY (`id`),
  KEY `idx_pick` (`trigger_on`, `scene`, `zone_id`, `map_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='G19 情境对话池';
```

### 3.2 匹配算法（评分制，比多级回退更优雅）

不用写一堆 if-else，改用**打分**：

```text
候选台词的得分 =
    map_id  匹配 ? +100 : (map_id  == 0 ? 0 : 淘汰)
  + zone_id 匹配 ? +100 : (zone_id == 0 ? 0 : 淘汰)
  + scene   匹配 ? +50  : (scene   == 0 ? 0 : 淘汰)
  + bot_class 匹配 ? +20 : (bot_class == 0 ? 0 : 淘汰)
  + bot_race  匹配 ? +10 : (bot_race  == 0 ? 0 : 淘汰)

取【最高分那一档】的所有台词，再按 weight 权重随机。
```

**好处**：
- 有专属词就用专属，没有自动降级，**不用写回退逻辑**
- 加新台词不用改代码，只加数据
- 「通灵学院+牧师」的词得分 220，会盖过「副本+牧师」的 70

### 第2步的技术要点（已实证）

```cpp
// 取环境
uint32 zoneId = me->GetZoneId();                  // Object.h:389
uint32 areaId = me->GetAreaId();                  // Object.h:390
Map* map = me->FindMap();                         // Object.h:468 安全版

uint8 scene = 0;
if (map)
{
    if (map->IsRaid())                    scene = 2;
    else if (map->IsDungeon())            scene = 1;
    else if (map->IsBattlegroundOrArena())scene = 6;
}
if (!scene)
{
    if (AreaTableEntry const* area = sAreaTableStore.LookupEntry(areaId))
    {
        if (area->Flags & AREA_FLAG_CAPITAL)        scene = 3;
        else if (area->Flags & AREA_FLAG_SANCTUARY) scene = 7;
        else if (area->Flags & AREA_FLAG_TOWN)      scene = 4;
        else                                        scene = 5;   // 野外
    }
}

// 取地名（自动中文）
char const* zoneName = "";
if (AreaTableEntry const* z = sAreaTableStore.LookupEntry(zoneId))
    zoneName = z->AreaName[locale];    // locale 用 GetSessionDbLocaleIndex()
```

## 六、防骚扰设计（很重要）

bot 话多会烦人。三道闸：

| 闸 | 参数 | 说明 |
|---|---|---|
| **单条冷却** | `cooldown` 字段，默认 600 秒 | 同一句话 10 分钟内不重复 |
| **全局冷却** | 每个 bot 至少间隔 90 秒 | 防止连珠炮 |
| **进区域去重** | 同一 zone 只在**首次进入**触发 | 来回跑不刷屏 |

**还要加个总开关**：

```
.pbot chat on/off        或   .npcbot chat on/off
```

让你随时能让它们闭嘴。
