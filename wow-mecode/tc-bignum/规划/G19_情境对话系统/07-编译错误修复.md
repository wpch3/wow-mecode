### 第2步 · 找一个【安全的插入点】

**不要凭行号插。用下面这个方法找绝对安全的位置：**

在 `bot_ai.cpp` 里搜这一行（这是文件里一个函数的完整结束 + 下一个函数的开始）：

**如果搜不到**，换成搜任意一个形如 `void bot_ai::` 或 `uint8 bot_ai::` 开头、
且**顶格写（前面没有空格）**的行。

**判断依据（这是关键，能自检）**：

```
一个合法的插入点，它的【上一行】必须是顶格的单独一个  }
而且【下一行】是顶格的  返回类型 bot_ai::函数名(
```

长这样：

```cpp
}                                    <- 上一个函数的结束，顶格
                                     <- 空行
uint8 bot_ai::GetCurrentScene() const   <- 在这里插入你的新函数
{
    ...
}
                                     <- 空行

{
```

**自检口诀：新函数的 `uint8` 三个字母必须【顶到最左边，前面一个空格都没有】。**
如果它前面有缩进（4个或8个空格），说明你插在别的函数里面了，一定报 C2601。

### 第3步 · 插入函数（内容不变）

```cpp
// G19第3步：算出 bot 当前所处的场景类别
//   0=未知 1=副本 2=团本 3=主城 4=小镇 5=野外 6=战场 7=圣所
//   用 FindMap()(Object.h:468 无断言) 而不是 GetMap()(Object.h:467 有 ASSERT)
uint8 bot_ai::GetCurrentScene() const
{
    Map const* map = me->FindMap();
    if (!map)
        return 0;

    if (map->IsBattlegroundOrArena())
        return 6;
    if (map->IsRaid())
        return 2;
    if (map->IsDungeon())
        return 1;

    if (AreaTableEntry const* area = sAreaTableStore.LookupEntry(me->GetAreaId()))
    {
        if (area->Flags & AREA_FLAG_CAPITAL)    return 3;
        if (area->Flags & AREA_FLAG_SANCTUARY)  return 7;
        if (area->Flags & AREA_FLAG_TOWN)       return 4;
    }
    return 5;
}
```

## 组2 · 修 `bot_companion.cpp:775` 的大括号

`C2447 "{" 缺少函数标题` = **大括号不配对**，
几乎总是"整函数替换时，旧函数的收尾 `}` 多留了一个或少删了一个"。

### 3.1 定位

```bash
cd /d/TrinityCore/src/server/game/AI/NpcBots
sed -n '750,790p' bot_companion.cpp
```

### 3.2 看什么

正常应该是这样（新 PickText 结束 → 空行 → 下一个函数）：

```cpp
    return chosen->Text;
}                                              <- PickText 的收尾

// ---------------------------------------------------------------------------
//  按等级挑物品。挑等级段最匹配的（尽量给好的）。
// ---------------------------------------------------------------------------
CompanionItem const* BotCompanionMgr::PickItem(uint8 careType, uint8 level) const
{
```

**如果你看到连续两个 `}`，或者 `}` 后面直接跟 `{`**，就是多余的收尾没删干净。

### 3.3 最可靠的自检：数括号

```bash
cd /d/TrinityCore/src/server/game/AI/NpcBots
python -c "d=open('bot_companion.cpp',encoding='utf-8').read(); print('{ =',d.count('{'),' } =',d.count('}'))"
```

**两个数字必须相等。** 不等就是括号不配对，差几个就找几个。

## 我的教训（已入坑表）

> **让用户插入函数时，只说"插在某函数上面"是不够的 ——
> 必须给出【顶格】这种可以肉眼自检的判断依据。**

正确的说法应该是：

```
新函数的返回类型必须顶到最左边，前面一个空格都没有。
它的上一行应该是顶格的单独一个 }
```

我在 06 号文档里写的是"找到该函数的起始行，插在它前面"，
**没有告诉你怎么确认那一行是不是函数起始行**，这是指令缺陷。
