## 一、这条线的最终定义

G17普通全世界飞行只是服务端安全能力的一期，不等于“完美客户端”。最终产品必须同时覆盖：

1. **人物模型与角色表现**：高清玩家模型、脸/发型/肤色、男女模型、骨骼、动画、装备贴合、坐骑姿态、变形与真龙形态；
2. **城市建模与世界重塑**：真实ADT地形、WMO建筑、M2摆件、碰撞、Area边界、服务端vmap/mmap/navmesh、NPC与服务设施，而不是只用SQL在废墟旁摆几个物件；
3. **新增可玩种族**：模型、动画、创建界面、DBC、阵营、语言、出生地、成长、装备、任务与完整服务端支持；
4. **新增职业**：职业定义、资源、技能、天赋、UI、gt缩放表、装备与任务、玩家逻辑、NPCBot/PBot AI和完整验收；
5. **新增NPC种族**：不可玩文明、模型与材质、语言/派系/文化、刷新区、剧情职能、AI与生态；
6. **新增地图与新世界**：改造旧空区、重建城市、新大陆/时间线地图、副本与传送链，客户端MPQ和服务端地图数据必须同步；
7. **新增伟大主线**：以真龙史诗为总主线，让剧情从txt进入任务、场景、城市变化、时间线、NPC立场、多结局和可持续世界状态；
8. **统一客户端产品化**：补丁exe、MPQ、DBC、Interface、模型、地图、音画资源、版本清单、哈希、原始文件与回滚必须组成同一可安装发行包。

**不能再混淆：**

```text
服务端放行旧世界飞行 ≠ 客户端动态飞行物理
SQL相位/摆物件           ≠ 真正城市与地形建模
DisplayID换皮            ≠ 完整可玩种族
复制现有法术             ≠ 完整新职业
故事txt/.story            ≠ 游戏内伟大主线
模型文件存在              ≠ 动画/装备/UI/运行验收完成
```

## 三、完美客户端八条工程线

### PC-1 人物模型与角色表现

交付范围：

- 原生可玩种族男女模型高清化；
- 新种族与真龙各形态模型；
- 脸型、肤色、发型、毛发、纹身与选择界面；
- 站立/行走/跑步/跳跃/游泳/飞行/施法/攻击/受击/死亡/表情动画；
- 头肩胸手腿鞋、武器、披风等装备贴合；
- 坐骑挂点、武器attachment、阴影、粒子与LOD降级；
- NPC版本与玩家版本的一致性。

最低验收：每个试点种族男女各一，完成全动作、至少三类装备、三类武器、一种坐骑、登录/切角色/传送/死亡复活30分钟无崩溃。

### PC-2 城市与建筑建模

最终路线不是“废墟旁摆物件”，而是：

```text
Noggit/ADT地形 + WMO主体建筑 + M2细节 + 地表材质/光照/水体
+ Area/Zone/地图DBC + 服务端vmap/mmap/navmesh + NPC/设施/任务
```

候选垂直切片：通希尔或小型废墟先跑通；之后再做新洛丹伦、地面达拉然、奎尔萨拉斯修复、兽人家园及种族主城。

最低验收：无裂地/浮空/黑面/穿模；建筑门窗碰撞正确；NPC可寻路；玩家/坐骑/飞行边界正确；客户端与服务端坐标一致；重登和传送稳定。

### PC-3 新增可玩种族

每个种族固定交付：

- `ChrRaces.dbc`、`CharBaseInfo.dbc`、`CharSections.dbc`、`CharHairGeosets.dbc`、`CharStartOutfit.dbc`；
- GlueXML创建按钮、名称、图标、说明与阵营展示；
- 服务端枚举/掩码/定长数组、出生信息、语言、阵营、技能、成长与装备；
- 男女模型/动画/装备贴合；
- 专属出生区、开场任务、城市/阵营反应；
- NPCBot/PBot兼容边界。

试点顺序待CP0裁决真实槽位。叙事优先候选是真龙；工程最小候选可先选客户端自带骨骼/模型的预留种族跑通工具链。

### PC-4 新增职业

新职业必须包含：

- `ChrClasses.dbc`、资源类型、角色创建入口与职业颜色；
- 技能、法术书、训练/任务、装备权限、动作条；
- 天赋树与UI，全部`gt*.dbc`缩放数据；
- 服务端职业枚举、定长数组、属性/暴击/闪避/递减等；
- 1–80/扩展等级完整成长；
- 玩家技能循环、三系定位、死亡/复活/传送/副本兼容；
- NPCBot和PBot对应AI；AI未完成时必须明确标“玩家可用、Bot不可用”。

候选：工程试点“断链武僧”；主线核心“真龙+龙裔”必须独立里程碑，不能用老职业技能拼盘冒充。

### PC-5 NPC种族与世界文明

NPC种族单独建账，不依附于可玩种族：

- 模型/DisplayInfo/材质/动画；
- 语言、派系、城市/聚落、职业结构；
- 生物模板、装备、声音、表情、名字库；
- 社会关系、商人/守卫/任务/敌对生态；
- NPCBot能否使用该种族模型及职业AI；
- 主线作用和长期世界状态。

`设定集`已有织梦蛾人等候选，后续需形成“NPC种族总表+模型来源+聚落地图+剧情章节+AI状态”。

### PC-6 新地图、新世界与时间线

分三级但最终都服务于完整世界：

1. 改造现有空区/废弃区；
2. 复制/扩展现有地图作为时间线容器；
3. 全新WDT/ADT/Map.dbc/AreaTable地图。

每张地图必须同时交付：客户端地图/建筑/光照/音乐/小地图，以及服务端map/vmap/mmap、传送、墓地、探索、飞行、任务、NPC与副本数据。

### PC-7 真龙伟大主线

最终不是文字阅读器，而是完整游戏主线：

- 真龙天意线、部落联盟尘世线、世界之魂噩梦线三线并行；
- 序章到终卷任务链、过场、场景、战斗、抉择和多结局；
- 城市重建、时间线、新种族、新职业、新地图都必须由主线解锁或改变；
- NPC和Bot有种族/职业/关系立场；
- 选择永久改变城市、势力、任务与世界之魂状态；
- 游戏内精简文本与完整设定档双版本。

`.story`和讲述者NPC可以做早期原型，但不能被写成“主线已落地完成”。

### PC-8 客户端发行与版本工程

最终每个版本必须是一套不可拆的同步交付：

```text
定制Wow.exe/启动器
客户端Data/Patch-*.MPQ
Interface/GlueXML/FrameXML
客户端DBC
服务端dbc/maps/vmaps/mmaps
服务端源码/SQL/conf
ORIGINALS原件目录
CHANGELOG + FILE_MANIFEST + SHA256SUMS
安装器 + Check/Apply/Rollback
版本兼容矩阵 + 崩溃/性能报告
```

禁止只发MPQ不发服务端DBC，或只改服务端DBC不更新客户端。

每项12.x功能只能使用以下状态，不允许“看起来像”就写完成：

```text
WATCHED     已确认官方功能/资料，尚未设计
DESIGNED    已完成本项目适配设计，尚未施工
PIPELINED   客户端/服务端工具链已跑通
```

### 7.3 “真正全世界可飞”的最终口径

当前主城禁召和飞入落地是G17-A安全一期的正确结果，但只是**临时安全基线**。最终完美客户端配置必须达到：

1. 东部王国、卡利姆多、外域、北裂境、全部重建城市、全部新地图/时间线户外空域默认可飞；
2. 主城不再因3.3.5旧硬限制一刀切禁飞，而是完成屋顶、WMO碰撞、Area边界、起降点和空中导航后开放；
3. 同时支持稳定飞行与客户端真动态飞行，不能用服务端匀速移动冒充12.x飞行；
4. 室内、过场、机制副本和竞技PvP如需禁飞，必须是**明确的玩法/物理设计例外**，不能因为旧客户端做不到而永久禁用；
5. 飞行验收覆盖起飞、加速、俯冲、爬升、滑翔、失速/落地、跨Area、跨地图、传送、重登、死亡、载具和网络预测。

### 7.4 跟进方式

- 每个12.x内容更新后建立官方功能差分清单，分成“必须跟进/本项目改写/不适用”；
- 官方美术资产只能在合法授权和项目可分发边界内处理；技术路线以自制、兼容转换和可复现管线为主；
- 先做一个完整垂直切片，再批量扩展；不以几百个半成品替代一个真正闭环；
- 本项目的真龙主线、NPC种族和世界重塑优先于机械照搬，但客户端质量、交互和系统完整度必须追到12.x标准。
