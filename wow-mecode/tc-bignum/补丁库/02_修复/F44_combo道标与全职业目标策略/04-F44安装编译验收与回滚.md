## 4. 第三步：VS2022 RelWithDebInfo/x64编译

继续保持worldserver关闭：

```powershell
& {
    $ErrorActionPreference = "Stop"
    $Sln = "D:\TC-Build\TrinityCore.sln"
    $RunDir = "D:\TC-Build\bin\RelWithDebInfo"
    $Exe = Join-Path $RunDir "worldserver.exe"
    $Pdb = Join-Path $RunDir "worldserver.pdb"
    $VsWhere = Join-Path ${env:ProgramFiles(x86)} "Microsoft Visual Studio\Installer\vswhere.exe"

    if (Get-Process worldserver -ErrorAction SilentlyContinue) { throw "编译前必须停服" }
    foreach ($Path in @($Sln, $Exe, $Pdb, $VsWhere)) {
        if (-not (Test-Path -LiteralPath $Path -PathType Leaf)) { throw "找不到：$Path" }
    }
    $MSBuild = @(& $VsWhere -latest -products * -requires Microsoft.Component.MSBuild -find "MSBuild\**\Bin\MSBuild.exe" | Where-Object { $_ })[0]
    if (-not $MSBuild) { throw "找不到MSBuild.exe" }

    $BeforeExe = Get-Item -LiteralPath $Exe
    $BeforePdb = Get-Item -LiteralPath $Pdb
    $BeforeHash = (Get-FileHash -LiteralPath $Exe -Algorithm SHA256).Hash.ToLowerInvariant()

    & $MSBuild $Sln /m /t:worldserver /p:Configuration=RelWithDebInfo /p:Platform=x64 /verbosity:minimal
    if ($LASTEXITCODE -ne 0) { throw "MSBuild失败：$LASTEXITCODE；回传第一条真实C/C++错误" }

    $AfterExe = Get-Item -LiteralPath $Exe
    $AfterPdb = Get-Item -LiteralPath $Pdb
    $AfterHash = (Get-FileHash -LiteralPath $Exe -Algorithm SHA256).Hash.ToLowerInvariant()
    if ($AfterExe.LastWriteTimeUtc -le $BeforeExe.LastWriteTimeUtc) { throw "worldserver.exe时间未前进" }
    if ($AfterPdb.LastWriteTimeUtc -le $BeforePdb.LastWriteTimeUtc) { throw "worldserver.pdb时间未前进" }
    if ($AfterHash -eq $BeforeHash) { throw "worldserver.exe哈希未变化" }

    Write-Host "[OK] exe size=$($AfterExe.Length) sha256=$AfterHash utc=$($AfterExe.LastWriteTimeUtc.ToString('o'))"
    Write-Host "[OK] pdb size=$($AfterPdb.Length) utc=$($AfterPdb.LastWriteTimeUtc.ToString('o'))"
    Write-Host "[OK] F44_WINDOWS_BUILD_PASS=True"
}
```

若失败，只回传第一条真实C/C++错误、文件/行号和上下文；不要只发后续`LNK1181`。

**2026-08-21真实结果：本步已PASS并关闭，禁止重复编译。** MSBuild 18.8.2明确编译`CombatSpecData.cpp`和`cs_combathelper.cpp`，生成`scripts.lib`并链接新worldserver。新exe=36730368字节/SHA `d32ee2cf...64bcfe`；新PDB=433311744字节/SHA `4b1dd7e7...ff0606`。证据：`证据/f44_step3_windows_build_pass_20260821.txt`。

### F44-A 圣光道标稳定目标

1. 神圣圣骑士与至少一名队友组队；把坦克设为主坦标记；场景设为副本/团本并开启自动buff；
2. 脱战开启`.combo`，确认道标落在主坦；
3. 让不同队员轮流成为最低血目标，持续至少30秒；
4. 预期：治疗会跟随血线，但道标不迁移、不每500ms重补；
5. 主坦死亡或离组后，才允许道标迁移到下一合法坦克/队友。

### F44-B 大地之盾

恢复萨满重复同一矩阵；大地之盾固定主坦，任意rank的自身Aura存在时不重复铺。

### F44-C NPCBot治疗与团队buff

混合玩家+NPCBot队伍中让NPCBot受伤；治疗职责必须能选中NPCBot。团队buff应逐合法玩家/NPCBot检查，不再只给施法者自己。

### F44-D SELF、嘲讽和失败退避

- 自身触发技能不得错误投给低血队友；
- 单嘲只在怪正攻击其它合法组员时使用；怪已经攻击自己时不嘲；
- 挑战怒吼/挑战咆哮只在存在失控敌人时使用；正义防御对被攻击的友方目标施放；
- 故意制造一次缺材料/错误目标等施法失败，失败不得计成功，也不得高频刷屏。

### F44-E generation与清理

连续10次执行`.combo`开启→500ms内`.combo off`→立即重开。预期施法频率不倍增、聊天不重复爆发；最终`.combo off`后自动施法停止。重登后旧事件链不得恢复。
