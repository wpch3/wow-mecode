# F44首次命令相对路径错误——纠正记录

日期：2026-08-21

## 发生了什么

首次命令把探针写成相对路径：

```text
.\tc-bignum\补丁库\02_修复\F44_combo道标与全职业目标策略\probe_combo_source.py
```

但用户PowerShell当前目录是：

```text
C:\Users\Administrator
```

Windows上并没有`C:\Users\Administrator\tc-bignum\...`，所以`Test-Path`、`Get-FileHash`和Python依次报找不到文件。该错误发生在探针启动前，没有读取或修改`D:\TrinityCore`。

原命令又被拆成多条独立语句执行，前一条`throw`不会阻止用户随后粘贴的其它独立语句，因此产生了Null、SHA为空和Python找不到文件的连锁错误。这些都不是源码问题。

## 已纠正

1. 不再假设Windows存在完整`wow-mecode`仓库；
2. 只下载`probe_combo_source.py`到固定绝对路径`C:\Users\Administrator\Downloads\probe_combo_source.py`；
3. 报告固定输出到桌面时间戳文件；
4. 全流程放入带`$ErrorActionPreference="Stop"`的单一原子块；
5. 先检查文件存在和SHA，再self-test，最后才读取真实源码；
6. 统一入口及专项执行说明已同步替换旧命令。
