## 改动 3：站桩修复（改 1 个词）

**Ctrl+F 搜**（约 15711 行）：

```cpp
            BotMovement(BOT_MOVE_POINT, target, nullptr, false);
```

**改成**：

```cpp
            BotMovement(BOT_MOVE_POINT, target, nullptr, IsWanderer());
```

> 最后一个参数是 `generatePath`。
> 原来恒为 `false` = 直线冲，被地形挡住就卡住。
> 改成 `IsWanderer()` = **只让游荡bot启用真寻路**，有主bot行为不变。

## 配置项

worldserver.conf 加一行（**先 grep 确认没有**）：

```bash
grep -n "NpcBot.WanderingBots.PeaceMode" worldserver.conf
```

没输出才加：

```ini
# 1 = 和平模式，游荡bot互不攻击（默认）
# 0 = 大逃杀模式，游荡bot互相残杀
NpcBot.WanderingBots.PeaceMode = 1
```

**不加也能跑**，代码里默认值就是 `true`（和平）。
