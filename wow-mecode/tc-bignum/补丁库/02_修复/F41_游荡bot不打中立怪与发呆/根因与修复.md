# F41 · 游荡bot 不打中立怪 + 站着发呆

> 2026-08-09
> 用户：「你好像忘记写游荡bot卡中立怪的修复了，
> 要让他识别到目标不在面前，自己在发呆，会前往怪物的面前」

---

## 一、你说得对，F39 修不了这个

F39 我加的条件是：

```cpp
if (!mmover && IsWanderer() && me->IsInCombat())    // <- 问题在这
```

**中立怪不会主动攻击你，bot 永远进不了 `IsInCombat()`**，
所以那段代码根本不执行 —— bot 继续站着发呆。

**这是两个独立问题**：

| 问题 | 表现 | 根因 |
|---|---|---|
| **A. 不打中立怪** | 看见中立怪当没看见 | `bot_ai.cpp:3616` 直接 return false |
| **B. 有目标也不走过去** | 锁定了却站着放技能 | F39 已修一半，但被 `IsInCombat()` 卡住 |

## 二、问题A：中立怪为什么打不了

```cpp
// bot_ai.cpp:3616  —— CanBotAttack 里
if ((target->GetFaction() == 35 || target->GetFaction() == me->GetFaction())
    && me->GetFaction() != FACTION_TEMPLATE_NEUTRAL_HOSTILE)
    return false;
```

**faction 35 = 中立友好**（不主动攻击任何人的那种）。

```cpp
// botcommon.h:157
FACTION_TEMPLATE_NEUTRAL_HOSTILE = FACTION_CREATURE,  // 2150
// 注释：Hates players and other bots, not attacked by guards
```

**翻译**：只有阵营是 `2150`（敌视所有人）的 bot 才能打中立怪。
普通游荡bot 用的是种族默认阵营（人类/兽人等），**所以中立怪一律跳过**。

### 还有一道

```cpp
// bot_ai.cpp:3614
if (me->GetFaction() == 35 && IAmFree() && target->IsCreature() && target->GetVictim() != me)
    return false;
```

如果 bot 自己是 faction 35，**它谁也不打**（除非对方先打它）。

## 三、问题B：F39 的条件太严

```cpp
// F39 我给的
if (!mmover && IsWanderer() && me->IsInCombat())
```

正确的应该是：**只要锁定了目标就该走过去**，不管在不在战斗。

```
bot 锁定中立怪 -> 还没开打 -> IsInCombat() == false -> F39 不执行 -> 发呆
```

## 四、修复（三处）

**文件**：`D:\TrinityCore\src\server\game\AI\NpcBots\bot_ai.cpp`

### 改动1 · 让游荡bot 能打中立怪

搜索原文（`:3616-3617`，全文件唯一）：

```cpp
    if ((target->GetFaction() == 35 || target->GetFaction() == me->GetFaction()) && me->GetFaction() != FACTION_TEMPLATE_NEUTRAL_HOSTILE)
        return false;
```

替换为：

```cpp
    // F41: 原版只允许 faction 2150(敌视所有) 的bot打中立怪，
    //   普通游荡bot 用种族默认阵营，于是看见中立怪当没看见 -> 站着发呆。
    //   这里放行：游荡bot 可以打 faction 35 的中立生物（野猪、鹿这类）。
    //   注意仍然保留"不打同阵营"的限制，避免它去打友方NPC。
    if (target->GetFaction() == me->GetFaction() && me->GetFaction() != FACTION_TEMPLATE_NEUTRAL_HOSTILE)
        return false;
    if (target->GetFaction() == 35 && me->GetFaction() != FACTION_TEMPLATE_NEUTRAL_HOSTILE)
    {
        // 游荡bot 放行，其他bot（有主人的）保持原行为
        if (!IsWanderer())
            return false;
    }
```

> **为什么保留"不打同阵营"**：否则 bot 会去打卫兵和任务NPC，那就乱套了。

### 改动2 · 保护任务NPC和飞行管理员

`:3625-3628` 上游已经有这个保护，但**只在 `IsWanderer()` 分支里**。
改动1 放行中立怪后，要确认这层保护仍然生效。

搜索原文（`:3623`）：

```cpp
    if (IsWanderer() && target->IsCreature() && target->GetVictim() != me)
    {
        if (BotCfg::EnableWanderingUntargetNpcQuestgiver() && target->IsQuestGiver())
            return false;
        if (BotCfg::EnableWanderingUntargetNpcFlightmaster() && target->IsTaxi())
            return false;
```

**在 `IsTaxi()` 那条下面加**：

```cpp
        // F41: 放行中立怪后，必须额外保护这些功能NPC，
        //   否则 bot 会去打商人/修理工/银行家，把城镇搅乱。
        if (target->IsVendor() || target->IsTrainer() || target->IsBanker() ||
            target->IsInnkeeper() || target->IsAuctioner() || target->IsSpiritService())
            return false;
        // 有名字的稀有精英也别惹（避免游荡bot自杀式冲锋）
        if (target->ToCreature() && target->ToCreature()->isWorldBoss())
            return false;
```

> **这些 API 我全部实查过**（都在 `Unit.h` public 段）：
> ```
> Unit.h:1102  IsVendor()          Unit.h:1103  IsTrainer()
> Unit.h:1109  IsBanker()          Unit.h:1110  IsInnkeeper()
> Unit.h:1114  IsAuctioner()       Unit.h:1117  IsSpiritService()
> Creature.h:157  isWorldBoss()    <- 注意是小写 i 开头
> ```

### 改动3 · 修正 F39 的触发条件

搜索原文（F39 装的那段）：

```cpp
            if (!mmover && IsWanderer() && me->IsInCombat())
            {
                if (Unit* victim = me->GetVictim())
                {
```

替换为：

```cpp
            // F41: 去掉 IsInCombat() 限制。
            //   中立怪不会主动攻击，bot 永远进不了战斗状态，
            //   原条件导致"锁定了目标却站着不动"。
            //   只要有目标就该走过去。
            if (!mmover && IsWanderer())
            {
                if (Unit* victim = me->GetVictim())
                {
```

## 五、为什么这样改是安全的

| 顾虑 | 说明 |
|---|---|
| bot 会打卫兵吗 | 不会。改动1 保留了"同阵营不打" |
| bot 会打任务NPC吗 | 不会。改动2 加了功能NPC保护 |
| 会影响有主人的bot吗 | 不会。改动1 里 `if (!IsWanderer()) return false;` |
| bot 会去打世界BOSS吗 | 不会。改动2 排除了 `isWorldBoss()` |
