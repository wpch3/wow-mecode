# `.pin status` / `.pin fix` 没反应 —— 一步定位

> 我这边的文件是对的（下面有证据）。所以问题在**你机器上跑的不是这份文件**。
> 下面这条命令能一次性判断是哪一环断了。

---

## 一、先看我这边的证据（确认不是我漏写了）

`cs_botpersist.cpp` 第 728-733 行：

```cpp
        // step60: 新增两个诊断/修复子命令
        if (s0 == "status" || s0 == "stat" || tok[0] == "状态")
            return DoStatus(handler, player);

        if (s0 == "fix" || s0 == "repair" || tok[0] == "修复")

```

函数定义：

```
577:    static bool DoStatus(ChatHandler* handler, Player* /*player*/)
642:    static bool DoFix(ChatHandler* handler, Player* /*player*/)
```

**代码在，分发在，函数在。** 所以是文件/编译/exe 三环之一断了。

## 三、按结果对号入座

### 情况A：第1步 MD5 对不上

**文件没覆盖成功。** 重新复制，注意用**复制文件**不要在编辑器里粘贴。

```bash
cp -f "/c/Users/你的用户名/Desktop/cs_botpersist.cpp" \
      "/d/TrinityCore/src/server/scripts/Commands/cs_botpersist.cpp"
md5sum /d/TrinityCore/src/server/scripts/Commands/cs_botpersist.cpp
```

### 情况B：MD5 对，但第3步是 0

**编译了但 exe 没更新**，两种可能：

**B1. 编译其实失败了**（你可能只看了"生成成功"但那是上次的）

VS 里看**输出窗口**，搜 `error`。
或者直接**重新生成解决方案**（不是"生成"，是**重新生成**）。

**B2. 编译成功了，但你跑的是另一个 exe**

第4、5步对比时间：
- 如果第5步的 exe 时间比第4步早 -> **你没把新 exe 复制到服务器目录**

```bash
cp -f /d/TC-Build/bin/RelWithDebInfo/worldserver.exe /你的服务器目录/
```

### 情况C：第3步 >= 1，但游戏里还是没有

**exe 是新的，但指令没注册**。查这个：

```bash
grep -n "AddSC_botpersist_commandscript" \
     /d/TrinityCore/src/server/scripts/Commands/cs_script_loader.cpp
```

**应该有 2 行**（一行声明、一行调用）。

- **0 行** -> step49 的注册没做，回去补
- **1 行** -> 少了声明或调用
- **2 行以上** -> 重复注册

### 情况D：全都对，游戏里还是不认

那就是 **`.pin` 这个指令本身没生效**（不只是 status 子命令）。

游戏里试：

```
.pin
```

- **提示"请先选中一个游荡bot"** -> `.pin` 是通的，那 status 也该通
- **提示"There is no such command"** -> 整个 `.pin` 都没注册

## 四、最可能的原因（我的判断）

你上一步在处理 **LNK2019（`AddSC_botpersist_commandscript` 未解析）**。

那个错误的本质是 **`cs_botpersist.cpp` 没被编译进工程**。

**如果你是这么解决的**：

> 把 `cs_script_loader.cpp` 里那两行注释掉，让编译过

那 `.pin` **整个指令都不存在**，当然没有 status/fix。

**验证**：游戏里打 `.pin`，如果说"没有这个命令"就是这种情况。

**解法**：
1. 确认 `cs_botpersist.cpp` 在 `D:\TrinityCore\src\server\scripts\Commands\` 里
2. 把 `cs_script_loader.cpp` 里那两行的注释**去掉**
3. **重跑 CMake**（关键！新文件必须重跑才会进工程）
4. 重新生成
