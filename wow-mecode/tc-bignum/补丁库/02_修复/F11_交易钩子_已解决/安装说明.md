```cpp
    _player->m_trade = new TradeData(_player, pOther);
    pOther->m_trade = new TradeData(pOther, _player);

    info.Status = TRADE_STATUS_BEGIN_TRADE;
    info.TraderGuid = _player->GetGUID();
    pOther->GetSession()->SendTradeStatus(info);

    // step57: PlayerBot 没有客户端，收不到上面那个 BEGIN_TRADE，
    // 也就永远不会发 CMSG_BEGIN_TRADE 回来。而真正打开【双方】窗口的
    // OPEN_WINDOW 只在 HandleBeginTradeOpcode 里发（本文件 584-586 行）。
    // 不替它走这一步，发起方的交易窗口永远不会出现。
    if (pOther->GetSession()->IsBotSession())
    {
        WorldPacket beginTrade(CMSG_BEGIN_TRADE, 0);
        pOther->GetSession()->HandleBeginTradeOpcode(beginTrade);
    }
}
```

### 为什么这样一定行

| | 轮询（旧） | 核心钩子（新） |
|---|---|---|
| 时机 | 最坏延迟 1 秒 | **同一个函数内，零延迟** |
| 依赖 `g_pbots` | 是（重启就空） | **否** |
| 依赖 `_pbotTradeOpened` | 是（会卡死） | **否** |
| 依赖开关配置 | 是 | **否** |

**`IsBotSession()` 是你 step40 自己加在 `WorldSession.h` 里的**，
`cs_playerbot.cpp:280` 每次 spawn 都会 `SetBotSession(true)`。
这个标记跟着会话走，不会失步。

### 不用加 include

`CMSG_BEGIN_TRADE` 来自 `Opcodes.h`，
而 `TradeHandler.cpp:33` 已经 include 了 `WorldPacket.h`，
`WorldPacket.h:22` 里就有 `#include "Opcodes.h"`。**我查过了。**

### 2.1 先加一个辅助函数

**Ctrl+F 搜**（大约第 60 行）：

**在这个函数【上面】插入**：

```cpp
// step57: 判断一个字符串是不是客户端的"单位ID"而非真实角色名。
//
// 背景：组队里有 NPCBot（Creature 冒充队伍成员）时，3.3.5 客户端某些
// UI 操作会把 UnitID 当成名字直接发上来（CMSG_GROUP_UNINVITE）。
// 服务端拿 "party1" 去 Group::GetMemberGUID 按名字找（Group.cpp:2854），
// 永远找不到，于是回一句 ERR_TARGET_NOT_IN_GROUP_S
// -> 聊天栏刷屏 "party1不在你的队伍中"。
//
// 这类请求本身就是客户端发错的，静默丢弃即可。
static bool IsClientUnitId(std::string const& name)
{
    static char const* const prefixes[] =
    {
        "party", "raid", "partypet", "raidpet", "arena", "boss"
    };
    static char const* const exacts[] =
    {
        "player", "target", "focus", "pet", "mouseover", "none", "vehicle"
    };

    // 完全匹配的保留字
    for (char const* e : exacts)
        if (name == e)
            return true;

    // 前缀 + 纯数字（party1 / raid25 / arena3 ...）
    for (char const* p : prefixes)
    {
        size_t len = strlen(p);
        if (name.size() > len && name.compare(0, len, p) == 0)
        {
            bool allDigits = true;
            for (size_t i = len; i < name.size(); ++i)
            {
                if (name[i] < '0' || name[i] > '9')
                {
                    allDigits = false;
                    break;
                }
            }
            if (allDigits)
                return true;
        }
    }

    return false;
}
```

**Ctrl+F 搜**（大约第 338 行）：

**改成**（在 `recvData >> membername;` 后面加 3 行）：

```cpp
void WorldSession::HandleGroupUninviteOpcode(WorldPacket& recvData)
{
    TC_LOG_DEBUG("network", "WORLD: Received CMSG_GROUP_UNINVITE");

    std::string membername;
    recvData >> membername;

    // step57: 客户端发的是 UnitID（party1/raid5...）不是真名，静默丢弃。
    // 组队里有 NPCBot 时客户端会这么发，不处理会刷屏。
    if (IsClientUnitId(membername))
        return;

    // player not found
    if (!normalizePlayerName(membername))
        return;
```

### 2.3 完成

按 GUID 那个 handler（`HandleGroupUninviteGuidOpcode`）**不用改** ——
它收的是 `ObjectGuid` 不是字符串，不会有 UnitID 的问题。

> 你看到"每个ID刷两次"，是因为客户端**同一个操作发了两个不同的包**，
> 但只有按名字那个会命中 UnitID 问题。改一处就够。
