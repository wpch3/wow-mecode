## 4. VS2022增量编译

```powershell
& {
    $ErrorActionPreference = "Stop"
    $Sln = "D:\TC-Build\TrinityCore.sln"
    $RunDir = "D:\TC-Build\bin\RelWithDebInfo"
    $Exe = Join-Path $RunDir "worldserver.exe"
    $Pdb = Join-Path $RunDir "worldserver.pdb"
    $VsWhere = Join-Path ${env:ProgramFiles(x86)} "Microsoft Visual Studio\Installer\vswhere.exe"

    if (Get-Process worldserver -ErrorAction SilentlyContinue) { throw "编译前必须停服" }
    $MSBuild = @(& $VsWhere -latest -products * -requires Microsoft.Component.MSBuild -find "MSBuild\**\Bin\MSBuild.exe" | Where-Object { $_ })[0]
    if (-not $MSBuild) { throw "找不到MSBuild.exe" }

    $BeforeExe = Get-Item -LiteralPath $Exe
    $BeforePdb = Get-Item -LiteralPath $Pdb
    $BeforeHash = (Get-FileHash -LiteralPath $Exe -Algorithm SHA256).Hash.ToLowerInvariant()

    & $MSBuild $Sln /m /t:worldserver /p:Configuration=RelWithDebInfo /p:Platform=x64 /verbosity:minimal
    if ($LASTEXITCODE -ne 0) { throw "MSBuild失败：$LASTEXITCODE；回传第一条真实C/C++错误" }

    $AfterExe = Get-Item -LiteralPath $Exe
    $AfterPdb = Get-Item -LiteralPath $Pdb
    $AfterHash = (Get-FileHash -LiteralPath $Exe -Algorithm SHA256).Hash.ToLowerInvariant()
    if ($AfterExe.LastWriteTimeUtc -le $BeforeExe.LastWriteTimeUtc) { throw "worldserver.exe时间未前进" }
    if ($AfterPdb.LastWriteTimeUtc -le $BeforePdb.LastWriteTimeUtc) { throw "worldserver.pdb时间未前进" }
    if ($AfterHash -eq $BeforeHash) { throw "worldserver.exe哈希未变化" }

    Write-Host "[OK] exe size=$($AfterExe.Length) sha256=$AfterHash utc=$($AfterExe.LastWriteTimeUtc.ToString('o'))"
    Write-Host "[OK] pdb size=$($AfterPdb.Length) utc=$($AfterPdb.LastWriteTimeUtc.ToString('o'))"
    Write-Host "[OK] F44R1_WINDOWS_BUILD_PASS=True"
}
```

编译失败时只需回传第一条真实C/C++错误、文件和行号，不要只发后续链接错误。

## 5. 启动与真人验收

正常启动刚生成的`D:\TC-Build\bin\RelWithDebInfo\worldserver.exe`并连接游戏。以下内容严格区分“游戏内实际命令”和“反馈文本模板”。

### 5.1 游戏内实际命令

先清旧状态：

```text
.combo off
.buff off
```

打开场景菜单，选择副本或团本：

```text
.buff scene
```

开启自动增益并仅建立一次合法初始队列：

```text
.buff on
.buff now
```

开启自动战斗（弹出菜单后选择当前专精与“治疗”职责）：

```text
.combo
```

完成测试后必须停止：

```text
.combo off
.buff off
```

### 5.2 F44R1-A：王者印记与互斥祝福

1. 神圣圣骑与队伍站在40码内，记录开始时王者印记数量；
2. 只执行一次`.buff now`，等待聊天给出的预计队列时间再加5秒；
3. 初次消耗最多应等于需要强效祝福的不同职业数，不得出现“三种祝福对同一目标循环覆盖”；
4. 再观察90秒：祝福仍有效时王者印记不得继续减少；
5. 不要求等待30分钟自然到期。可在一名测试角色上手动右键取消其祝福，预期只对缺失目标补一次，随后停止。

### 5.3 F44R1-B：治疗自己、坦克和DPS

1. 选神圣专精+治疗职责并开启`.combo`；
2. 分三轮让自己、主坦、DPS分别降到场景治疗线以下；
3. 每轮其余成员尽量保持安全血线，以便确认实际目标；
4. 预期三类目标都被持续治疗；任一目标低于治疗线且治疗暂时受GCD/CD/移动阻挡时，不得改为攻击抢下一个施法窗口；
5. 全队安全时才允许治疗角色参与攻击。

### 5.4 F44R1-C：队列/GCD抢占

1. 脱战执行一次`.buff now`，紧接着开启`.combo`；
2. 脱战安全时，`.combo`应完整让出GCD直到队列完成；
3. 队列期间进入战斗或让友方跌破治疗线，剩余buff队列应自动取消，治疗/战斗继续；
4. 执行`.buff off`后，尚未执行的队列事件必须停止。

### 5.5 F44R1-D：稳定目标与全专精互斥族

- 道标/神圣壁垒继续固定主坦；主坦仍合法时不得随最低血迁移；
- 可用战士、德鲁伊或死亡骑士任选一个做`.combo`全专精代表测试：不得循环切姿态/形态/领域；
- 萨满代表测试：同元素图腾不得彼此覆盖循环；同一次战斗每个入选图腾只部署一次；
- 盗贼毒药、萨满武器附魔当前不得被`.combo`自动重放（仍可手动使用）。

## 6. 回滚

仅在F44R1真实失败并决定撤回时使用；先正常停服：

```powershell
& {
    $ErrorActionPreference = "Stop"
    $Python = "C:\Users\Administrator\AppData\Local\Programs\Python\Python312\python.exe"
    $Package = "C:\Users\Administrator\Downloads\workspace\wow-mecode\tc-bignum\补丁库\02_修复\F44R1_combo增益生命周期与治疗优先"
    $Installer = Join-Path $Package "install_f44r1_combo.py"
    $Root = "D:\TrinityCore"
    if (Get-Process worldserver -ErrorAction SilentlyContinue) { throw "回滚前必须停服" }
    & $Python $Installer --rollback $Root
    if ($LASTEXITCODE -ne 0) { throw "F44R1回滚失败：$LASTEXITCODE" }
    & $Python $Installer --check $Root
    if ($LASTEXITCODE -ne 0) { throw "F44R1回滚后Check失败：$LASTEXITCODE" }
    Write-Host "[OK] F44R1_ROLLBACK_CHECK_PASS=True"
}
```

回滚只恢复到已经真实安装/编译过的旧F44源码，不会回退更早批次；随后需重新编译或恢复同时间戳的F44R1前二进制备份。
