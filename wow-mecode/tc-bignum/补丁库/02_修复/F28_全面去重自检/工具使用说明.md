# F28 重复代码检测器 —— 使用说明

## 这是什么

一个 Python 脚本，自动检查你源码里的补丁代码有没有被**重复粘贴**。

**为什么需要它**：

```text
函数体内的【语句重复】     -> 编译器完全不报错   <- F27 就是这种
函数定义/枚举/成员声明重复 -> 报错 C2084/C2011/C2535
```

**"能编译成功"不代表"没重复"** —— 恰恰是最危险的那类编译器不管。

F27 的 `_player->m_trade = new TradeData(...)` 被执行 3 次，
编译一点问题没有，但导致交易窗口一闪而过。

---

## 怎么用

在 Git Bash 里跑：

```bash
cd /d/TrinityCore    # 或你放 tc-bignum 的地方
python tools/check_dup.py D:/TrinityCore/src
```

如果 `python` 不行就试 `python3`。

### 看详细（连正常项也列出来）

```bash
python tools/check_dup.py D:/TrinityCore/src --verbose
```

---

## 输出怎么看

### 有重复（要处理）

```text
  [重复] IsBotSession                    3 处 (应有 1)
         说明: step57 bot交易钩子
         行号: 12, 17, 23
         >>> 多了 2 处，需要删掉
```

**行号直接告诉你去哪删。** 保留第一处，删掉后面的。

### 缺失（通常可忽略）

```text
  [缺失] uint8 GetGiftNeedState(         0 处 (应有 1)
         说明: A37-3  <- 该补丁可能没装或没装全
```

如果那个补丁你本来就没装，忽略即可。
**如果装了却显示缺失，说明装的位置或写法和文档不一致。**

### 退出码

```text
0 = 没有重复（可能有缺失）
1 = 有重复
2 = 参数错误 / 目录不存在
```

```text

[正确] 正常代码（各1份）零告警
[正确] 退出码：故障=1  正常=0
```

## 找不到文件怎么办

脚本会自动尝试几个常见位置。如果还是找不到，会打印：

```text
[跳过] 找不到文件: server/scripts/Custom/pbot_autoaccept.cpp
```

这不影响其它文件的检查。如果你的文件放在特殊位置，
告诉我路径，我把它加进 `ALT_PATHS`。

---

## 规则怎么维护

规则表在脚本开头的 `RULES` 字典里：

```python
"server/game/Handlers/TradeHandler.cpp": [
    ("// OK start trade",  1, "上游原注释", True),   # 第4个参数True=搜索词本身是注释
    ("IsBotSession",       1, "step57 bot交易钩子"),
],
```

**以后我每给一个新补丁，会同步往这里加规则。**
