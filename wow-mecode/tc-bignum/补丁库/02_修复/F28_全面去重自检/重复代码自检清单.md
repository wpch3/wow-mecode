**看查找框右边显示的"共 N 项匹配"**。

## 为什么编译能过却有重复

这是最容易忽略的地方：

| 重复类型 | 编译器 | 后果 |
|---|---|---|
| **函数体内的语句重复** | **不报错** | **逻辑执行多次** <- F27 就是这种 |
| `if` 分支重复 | 不报错 | 第二个永远进不去（死代码） |
| `#include` 重复 | 不报错 | 有 include guard，无害 |
| 函数定义重复 | **报错** | C2084 |
| 枚举值重复 | **报错** | C2011 / C2365 |
| 类成员声明重复 | **报错** | C2535 |

**所以"能编译"不代表"没重复"** ——
恰恰是最危险的那种（语句重复）编译器完全不管。
