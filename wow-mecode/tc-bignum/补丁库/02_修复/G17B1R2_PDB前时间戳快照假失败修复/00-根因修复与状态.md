# G17-B1R2 PDB前时间戳快照假失败修复

状态：`B1R1_REAL_BUILD_ACCEPTED / FALSE_FINAL_ASSERTION_PROVEN / CANONICAL_SCRIPT_FIXED / NO_USER_RERUN`

B1R1真实报告已经证明native selftest、源码后像、MSBuild、`cs_dragonriding.cpp` fresh OBJ、worldserver链接、EXE哈希变化以及EXE/PDB时间晚于BUILD_START全部通过。最终FAIL是安装器后检假阴性，不是C++构建失败。

根因：B1R1在构建前保存`$bp=Get-Item $Pdb`，却没有在构建前读取并保存`$bp.LastWriteTimeUtc`。构建后首次读取该属性得到新PDB时间，再与`$ap.LastWriteTimeUtc`比较，二者相等，错误触发`timestamp did not advance`。

修复：构建前立即保存值类型`$BeforeExeUtc`和`$BeforePdbUtc`，构建后只与这两个快照比较，并记录`BEFORE_PDB_UTC`。

用户无需重编、无需回滚、无需再运行安装包；当前直接进入B1 Runtime。
