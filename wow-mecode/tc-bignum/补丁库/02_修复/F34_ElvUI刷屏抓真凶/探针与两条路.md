## 一、ElvUI 源码实查结果（这部分是硬事实）

### 1.1 全仓库只有一处 `UninviteUnit`

```lua
-- ElvUI/Modules/Misc/Misc.lua:253
function M:DisbandRaidGroup()
    if InCombatLockdown() then return end

    local numRaid = GetNumRaidMembers()

    if numRaid > 0 then
        for i = 1, numRaid do
            local name, _, _, _, _, _, _, online = GetRaidRosterInfo(i)
            if online and name ~= E.myname then
                UninviteUnit(name)              -- :262
            end
        end
    else
        for i = MAX_PARTY_MEMBERS, 1, -1 do     -- :266  MAX_PARTY_MEMBERS = 4
            if GetPartyMember(i) then
                UninviteUnit(UnitName("party"..i))   -- :268  <- 遍历 party1~party4
            end
        end
    end

    LeaveParty()
end
```

**`:266-270` 这个循环，形态和你看到的「party1 / party2 不在你的队伍中」完全吻合。**

### 1.2 但它只在「解散队伍」时触发

```lua
-- ElvUI/Core/StaticPopups.lua:382
OnAccept = function() Misc:DisbandRaidGroup() end,
```

**唯一调用者是一个确认弹窗。** 你不点"解散队伍"，它不会跑。

**所以它解释不了"持续刷屏"。**

### 1.3 ElvUI 里【没有】任何 whois / who 查询

```
grep -rn "SendWho|/who|WhoIs|whois|SetWhoToUI"  ->  0 个真实调用
```

搜到的全是 `FriendsFrame` 的皮肤代码，跟查询无关。

**所以「未找到名为卡特莉娜的在线玩家」也不是 ElvUI 主动发的。**

### 1.4 结论

| 猜测 | 实查结果 |
|---|---|
| ElvUI 批量踢人导致刷屏 | **只在点"解散队伍"时**，解释不了持续刷屏 |
| ElvUI 发 whois | **源码里根本没有** |

**两条线索都断了。说明真凶不是我想的那个。**

## 四、日志怎么读（你自己也能判断）

### 如果看到 `F34-NOTIFY: string_id=808`

```
Language.h:763   LANG_PLAYER_NOT_EXIST_OR_OFFLINE = 808
```

→ 确认是 `MiscHandler.cpp:1067 HandleWhoIsOpcode`
→ **有东西在发 CMSG_WHOIS**。既然 ElvUI 源码里没有，
  那就是**别的插件**，或者 ElvUI 的某个插件（`ElvUI_Enhanced` 之类）

### 如果看到 `F34-PARTY: op=2 res=...`

```
PARTY_OP_UNINVITE = 2
```

→ 确认是踢人路径。看 `member=` 字段：
- `member=''`（空）→ 按GUID版 `GroupHandler.cpp:295`
- `member='鲤鱼'` → 按名字版 `GroupHandler.cpp:338`

### 如果两个都没有

→ 说明这句话**根本不是服务端发的**，是客户端插件自己弹的。
  那时候才轮到改插件，而且我们会知道该改什么。

## 五、如果确认要改插件 —— 源码和改法都备好了

仓库：`https://github.com/ElvUI-WotLK/ElvUI`

你本地的路径应该是：

```
D:\WOW\Interface\AddOns\ElvUI\Modules\Misc\Misc.lua
```

### 改法（如果确认是 `DisbandRaidGroup` 的锅）

搜索原文（`:266-270`）：

```lua
		for i = MAX_PARTY_MEMBERS, 1, -1 do
			if GetPartyMember(i) then
				UninviteUnit(UnitName("party"..i))
			end
		end
```

替换为：

```lua
		for i = MAX_PARTY_MEMBERS, 1, -1 do
			if GetPartyMember(i) then
				-- F34: 跳过 NPCBot。UnitIsPlayer 对 Creature 返回 false，
				-- 踢它们会让服务端回「XXX不在你的队伍中」刷屏。
				local unit = "party"..i
				if UnitIsPlayer(unit) then
					UninviteUnit(UnitName(unit))
				end
			end
		end
```

同时在文件顶部的 local 声明区（`:22` 附近）加：

```lua
local UnitIsPlayer = UnitIsPlayer
```

> **为什么用 `UnitIsPlayer`**：NPCBot 在客户端眼里是 Creature，
> 这个 API 对它返回 false，是最干净的过滤方式。
> ElvUI 自己在 `Threat.lua:53` 也用这个 API。

**改完 `/rl` 重载界面即可，不用重启客户端。**
