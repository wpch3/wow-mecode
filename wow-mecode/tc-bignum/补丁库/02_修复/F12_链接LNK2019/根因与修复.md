## 二、为什么"没重跑 CMake"会导致这个

实查 `cmake/macros/AutoCollect.cmake:23`：

```cmake
function(CollectSourceFiles current_dir variable)
  list(FIND ARGN "${current_dir}" IS_EXCLUDED)
  if(IS_EXCLUDED EQUAL -1)
    file(GLOB COLLECTED_SOURCES        # <-- 【关键】
      ${current_dir}/*.c
      ${current_dir}/*.cc
      ${current_dir}/*.cpp             # <-- 收集所有 .cpp
      ...
```

`src/server/scripts/CMakeLists.txt:206` 用它来建 `scripts` 库。

**`file(GLOB)` 是"CMake 运行那一刻"的目录快照。**

也就是说：

```
你往 Commands\ 里放了 cs_botpersist.cpp
        |
        v
但没重跑 CMake
        |
        v
.vcxproj 工程文件里【没有这个文件】
        |
        v
VS 编译时【根本不知道有这个文件】-> 不产生 .obj
        |
        v
链接时找不到 AddSC_botpersist_commandscript -> LNK2019
```

> 这就是 step49 安装说明 3.4 节写「新增了 .cpp 文件，**必须重跑**」的原因。
> 但那条太不起眼了，我应该写得更醒目。**这是我文档的问题。**

## 六、顺便：一条自检命令，以后每次改完 loader 都跑

```bash
grep -oP 'AddSC_\w+' /d/TrinityCore/src/server/scripts/Commands/cs_script_loader.cpp \
  | sort | uniq -c | awk '$1!=2'
```

**没有任何输出 = 全部正常。**

原理：每个 `AddSC_xxx` 都应该恰好出现 **2 次**（1次声明 + 1次调用）。

- 出现 **1 次** -> 声明了没调用，或调用了没声明
- 出现 **3 次以上** -> 重复注册（step47 那个 `wp` 出现 4 次的坑）

**但注意**：这条命令查不出"函数没有实现"（也就是你现在这个错），
因为它只看 loader 文件。所以再补一条：

```bash
# 检查每个被注册的 AddSC_ 是否都有对应的实现文件
cd /d/TrinityCore/src/server/scripts
for f in $(grep -oP 'AddSC_\w+' Commands/cs_script_loader.cpp | sort -u); do
  if ! grep -rq "void $f()" . ; then
    echo "缺实现: $f"
  fi
done
```

**没输出 = 每个注册的函数都能找到实现。**
