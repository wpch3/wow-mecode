# F27 交易窗口一闪而过 —— 「刚做好能用，现在不行」的真相

## 你这句话是关键线索

> **明明刚做好时还能用，现在不行了**

代码没变，行为变了 -> **一定是某个"内存状态"没了**。

---

## 根因：`IsBotSession()` 是内存标志，重启就没

### step57 的核心钩子长这样

`TradeHandler.cpp` 的 `HandleInitiateTradeOpcode` 结尾（约 729 行后）：

```cpp
    info.Status = TRADE_STATUS_BEGIN_TRADE;
    info.TraderGuid = _player->GetGUID();
    pOther->GetSession()->SendTradeStatus(info);

    // step57 加的
    if (pOther->GetSession()->IsBotSession())
    {
        WorldPacket beginTrade(CMSG_BEGIN_TRADE, 0);
        pOther->GetSession()->HandleBeginTradeOpcode(beginTrade);
    }
}
```

**这一步是唯一能让双方交易窗口真正打开的路径**
（`OPEN_WINDOW` 只在 `HandleBeginTradeOpcode` 里发，`TradeHandler.cpp:584-586`）。

### `IsBotSession()` 从哪来

```text
WorldSession.h   bool IsBotSession() const { return m_isBotSession; }
                 void SetBotSession(bool val) { m_isBotSession = val; }

cs_playerbot.cpp:280   sess->SetBotSession(true);     <- 只有这一个地方设
```

**`m_isBotSession` 是纯内存变量，不落库。**

### 所以链条是

```text
情况A：你刚 .pbot spawn 上线的 bot
   -> cs_playerbot.cpp:280 设了 SetBotSession(true)
   -> 钩子生效 -> 窗口打开  【刚做好时能用】

情况B：服务器重启后，bot 是用【别的方式】进世界的
   （比如它本来就在线上、或你直接用账号密码登的、或某个自动上线机制）
   -> m_isBotSession 是 false
   -> 钩子【整段跳过】
   -> 双方都收不到 OPEN_WINDOW
   -> 客户端等不到窗口数据，自己关掉
   -> 同时 pbot_autoaccept.cpp:410 的距离自愈每秒跑一次
   -> 发现"没在交易范围"就 TradeCancel  【现在不行了】
```

**"一闪而过"正是这个** —— 客户端先收到 `BEGIN_TRADE`（`:729` 发的，
这句不受钩子影响，所以窗口会闪一下），
但收不到 `OPEN_WINDOW`，于是关闭。

---

## 三步修复（从最可能到兜底）

### 第 1 步：先确认 bot 是怎么上线的

进游戏打：

```text
.pbot list
```

**看鲤鱼在不在列表里。**

| 结果 | 含义 | 怎么办 |
|---|---|---|
| **在列表里** | `g_pbots` 有它，但不代表 `IsBotSession` 为真 | 走第 2 步 |
| **不在列表里** | 服务器重启后 `g_pbots` 清空了 | **`.pbot despawn 鲤鱼` 再 `.pbot spawn <账号> 鲤鱼`**，大概率立刻好 |

`g_pbots` 和 `m_isBotSession` 都是内存的，重启后**两个一起丢**。

---

### 第 2 步：把 `IsBotSession` 判断改宽（治本）

即使不是 `.pbot spawn` 上线的，只要它在 `g_pbots` 里，也应该走钩子。

#### 改 `TradeHandler.cpp`

搜索原文（约 723-730 行）：

```cpp
    // OK start trade
    _player->m_trade = new TradeData(_player, pOther);
    pOther->m_trade = new TradeData(pOther, _player);

    info.Status = TRADE_STATUS_BEGIN_TRADE;
    info.TraderGuid = _player->GetGUID();
    pOther->GetSession()->SendTradeStatus(info);
}
```

替换为：

```cpp
    // OK start trade
    _player->m_trade = new TradeData(_player, pOther);
    pOther->m_trade = new TradeData(pOther, _player);

    info.Status = TRADE_STATUS_BEGIN_TRADE;
    info.TraderGuid = _player->GetGUID();
    pOther->GetSession()->SendTradeStatus(info);

    // step57 / F27: PlayerBot 没有客户端，收不到 BEGIN_TRADE，
    // 也就永远不会发 CMSG_BEGIN_TRADE 回来。而真正打开【双方】窗口的
    // OPEN_WINDOW 只在 HandleBeginTradeOpcode 里发（本文件 584-586 行）。
    //
    // F27: 原来只判 IsBotSession()，那是纯内存标志，
    // 只有 .pbot spawn 才设（cs_playerbot.cpp:280），重启后为 false。
    // 现在加一条：没有活跃 socket 的会话也当 bot 处理。
    if (pOther->GetSession()->IsBotSession() || pOther->GetSession()->PlayerDisconnected())
    {
        WorldPacket beginTrade(CMSG_BEGIN_TRADE, 0);
        pOther->GetSession()->HandleBeginTradeOpcode(beginTrade);
    }
}
```

#### 为什么用 `PlayerDisconnected()`

实查 `WorldSession.h:503`：

```cpp
bool PlayerDisconnected() const { return !m_Socket; }
```

**它判断的就是"这个会话没有真实网络连接"** ——
`.pbot` 创建的会话 `m_Socket` 为空，这是它和真人玩家最本质的区别。

| 判断方式 | 重启后失效？ | 依赖什么 |
|---|---|---|
| `IsBotSession()` | **会**（纯内存标志） | `.pbot spawn` 时手动设 |
| `PlayerDisconnected()` | **不会** | 会话本身有没有 socket |

两个用 `||` 连起来，任一为真都走钩子，**互相兜底**。

> 我先查了 `GetSocket()`，**它在这个版本不存在**，
> 所以用了 `PlayerDisconnected()`。它在 `pbot_autoaccept.cpp:389` 已经用过，
> 确认可用。

---

### 第 3 步：距离自愈仍要装（F26 改动一）

即使窗口开了，`pbot_autoaccept.cpp:410` 那段还会每秒检查：

```cpp
    if (!bot->IsWithinDistInMap(trader, TRADE_DISTANCE, false))
        bot->TradeCancel(true);
```

`IsWithinDistInMap` 内部查 `InSamePhase`（`Object.cpp:1207`），
pbot 相位不同就永远 false -> 窗口开了也会被秒关。

**F26 的改动一必须一起装**，替换成：

```cpp
    // 只按【纯距离】判断，不掺相位检查。
    // IsWithinDistInMap 内部还查 InSamePhase(Object.cpp:1207)，
    // pbot 用 .pbot spawn 上线不同步相位 -> 站一起也判"太远" -> 秒取消。
    if (bot->GetMapId() != trader->GetMapId())
    {
        bot->TradeCancel(true);
        return;
    }

    float const cancelDist = TRADE_DISTANCE * 3.0f;
    if (bot->GetExactDist2d(trader) > cancelDist)
        bot->TradeCancel(true);
```
