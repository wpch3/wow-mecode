## 为什么这会导致交易窗口一闪而过

### 关键在于 `m_trade` 被 new 了 3 次

`TradeData` 构造函数（`TradeData.h:37-39`）只是存指针，
**没有任何"注册"动作**：

```cpp
TradeData(Player* player, Player* trader) :
    _player(player), _trader(trader), _accepted(false), _acceptProccess(false),
    _money(0), _spell(0), _spellCastItem() { }
```

所以第 2 次 `new` 时：

```cpp
_player->m_trade = new TradeData(...);   // 指针直接被覆盖
```

**第 1 次 new 出来的那个对象没人 delete，成了内存泄漏，
但更要命的是 —— 双方的 `m_trade` 指向的对象对不上了。**

### 具体错乱过程

```text
第1轮:  你.m_trade = A1      bot.m_trade = B1
        钩子还没执行

第2轮:  你.m_trade = A2      bot.m_trade = B2     <- A1/B1 泄漏
        钩子第1次执行 -> HandleBeginTradeOpcode
                     -> 读 _player->m_trade = A2
                     -> A2->GetTrader() = bot，发 OPEN_WINDOW  【窗口打开】

        钩子第2次执行 -> 又发一次 OPEN_WINDOW      【重复包】

第3轮:  你.m_trade = A3      bot.m_trade = B3     <- A2/B2 泄漏
                                                  <- 客户端手里的窗口还关联着 A2
        钩子第3次执行 -> 发第三次 OPEN_WINDOW
```

客户端收到**三次** `BEGIN_TRADE` + **三次** `OPEN_WINDOW`，
但服务端的 `m_trade` 已经换成了第 3 个对象，
**客户端和服务端的交易会话状态完全对不上** ->
客户端判定异常 -> 发 `CMSG_CANCEL_TRADE` -> 你看到「对方取消了交易」。

### 为什么「刚做好时能用」

因为当时只粘贴了**一次**。后来每次我给新补丁（F26 / F27），
你可能又粘了一遍，**累积成了 3 份**。

### 从这一行开始，一直到函数的闭合大括号 `}` 为止，整段选中删除

也就是把你贴给我的那**一大坨**（三份重复的）全部删掉。

删除范围：从 `    // OK start trade` 这行，
到它下面第一个**顶格的** `}`（这个 `}` 是 `HandleInitiateTradeOpcode` 函数的结尾）。

### 然后粘贴这一份正确的

```cpp
    // OK start trade
    _player->m_trade = new TradeData(_player, pOther);
    pOther->m_trade = new TradeData(pOther, _player);

    info.Status = TRADE_STATUS_BEGIN_TRADE;
    info.TraderGuid = _player->GetGUID();
    pOther->GetSession()->SendTradeStatus(info);

    // step57 / F27: PlayerBot 没有客户端，收不到上面那个 BEGIN_TRADE，
    // 也就永远不会发 CMSG_BEGIN_TRADE 回来。而真正打开【双方】窗口的
    // OPEN_WINDOW 只在 HandleBeginTradeOpcode 里发（本文件 584-586 行）。
    // 不替它走这一步，发起方的交易窗口永远不会出现。
    //
    // 【只能有这一处，多贴一次会导致 m_trade 被重复 new，客户端状态错乱】
    if (pOther->GetSession()->IsBotSession() || pOther->GetSession()->PlayerDisconnected())
    {
        WorldPacket beginTrade(CMSG_BEGIN_TRADE, 0);
        pOther->GetSession()->HandleBeginTradeOpcode(beginTrade);
    }
}
```

**注意最后那个 `}` 要留着，它是函数的结尾。**
