## 零、先想清楚：他们会想什么

写台词之前必须定人设，否则会写成"换个词说同一句话"。

### 关键设计：种族给的是【经历】，职业给的是【态度】

```
职业 = 他怎么说话（战士粗、法师傲）
种族 = 他经历过什么（亡灵死过、德莱尼流亡、血精灵失去过太阳井）
```

**所以种族台词的重点不是口音，是【视角】。**

### 十族的内心（这决定台词怎么写）

| 种族 | 他们经历过什么 | 说话时的底色 |
|---|---|---|
| **人类** | 洛丹伦陷落、家园重建 | 务实、有礼、提"重建" |
| **兽人** | 从恶魔之血中赎罪 | 重荣誉、耻于软弱、"力量" |
| **矮人** | 挖掘泰坦遗迹、发现自己是造物 | 豪爽、爱酒、好奇造物主 |
| **暗夜精灵** | 万年不老、见过上古之战 | 时间尺度不同、疏离、耐心 |
| **亡灵** | 死过一次、被抛弃 | 阴冷自嘲、对"活着"敏感 |
| **牛头人** | 游牧、大地母亲信仰 | 厚重、缓慢、敬自然 |
| **侏儒** | 诺莫瑞根被自己人毒气毁掉 | 跳脱、好奇、不提伤心事 |
| **巨魔** | 帝国衰落、巫毒传统 | 慵懒口音、宿命感、"曼" |
| **血精灵** | 太阳井被毁、魔瘾 | 高傲掩饰失落、优雅、克制 |
| **德莱尼** | 流亡两万五千年 | 虔诚、外来者视角、感恩 |

### 举例：同样是"收到食物"

```
亡灵：  "食物……我其实尝不出味道。但谢谢你还记得。"
德莱尼："在我们流亡的岁月里，一块面包就是恩典。谢谢你。"
矮人：  "有吃的就好，要是再来杯酒就完美了！"
暗夜：  "我活了很久，但每次有人递来食物，还是会觉得温暖。"
```

**这才是"种族"该有的分量** —— 不是把"谢谢"换成方言。

## 一、四级评分匹配（核心设计）

第1步的职业匹配是"专属优先、回退通用"，加了种族后组合变成 4 种，
用 if-else 会很乱。改用**评分制**：

```text
得分 = (职业匹配 ? +20 : 职业==0 ? 0 : 淘汰)
     + (种族匹配 ? +10 : 种族==0 ? 0 : 淘汰)

取【最高分那一档】的所有台词，再按 weight 权重随机。
```

效果自动分级：

| 台词配置 | 得分 | 含义 |
|---|---|---|
| `bot_class=5, bot_race=5` | 30 | 亡灵牧师专属 |
| `bot_class=5, bot_race=0` | 20 | 牧师通用 |
| `bot_class=0, bot_race=5` | 10 | 亡灵通用 |
| `bot_class=0, bot_race=0` | 0 | 全局兜底 |

**好处**：加新台词不用改代码；没有专属自动降级；
「亡灵牧师」不会因为种族匹配就丢掉牧师的味道。

### 3.2 PickText 换成评分匹配

搜索原文（`:189`，整个函数直到它的收尾 `}`）：

```cpp

```

**把整个函数替换为**：

```cpp
// A42第2步：四级评分匹配
//   职业匹配 +20，种族匹配 +10，字段为 0 表示"不限"（得 0 分但不淘汰）
//   取最高分那一档，再按 weight 权重随机。
//
//   自动分级效果：
//     亡灵牧师专属(class=5,race=5) 30 分  ->  最优先
//     牧师通用    (class=5,race=0) 20 分
//     亡灵通用    (class=0,race=5) 10 分
//     全局兜底    (class=0,race=0)  0 分
std::string BotCompanionMgr::PickText(uint8 careType, uint8 botClass, uint8 botRace/* = 0*/) const
{
    auto itr = _texts.find(careType);
    if (itr == _texts.end() || itr->second.empty())
        return std::string();

    int bestScore = -1;
    std::vector<CompanionText const*> pool;

    for (CompanionText const& t : itr->second)
    {
        // 指定了职业但对不上 -> 淘汰
        if (t.BotClass != 0 && t.BotClass != botClass)
            continue;
        // 指定了种族但对不上 -> 淘汰
        if (t.BotRace != 0 && t.BotRace != botRace)
            continue;

        int score = 0;
        if (t.BotClass != 0) score += 20;
        if (t.BotRace  != 0) score += 10;

        if (score > bestScore)
        {
            bestScore = score;
            pool.clear();
            pool.push_back(&t);
        }
        else if (score == bestScore)
            pool.push_back(&t);
    }

    if (pool.empty())
        return std::string();

    // 权重随机
    uint32 total = 0;
    for (CompanionText const* t : pool)
        total += t->Weight;

    if (!total)
        return pool[0]->Text;

    uint32 roll = urand(0, total - 1);
    for (CompanionText const* t : pool)
    {
        if (roll < t->Weight)
            return t->Text;
        roll -= t->Weight;
    }

    return pool[0]->Text;
}
```

## 附：为什么不用 `me->GetRace()`

```cpp
// botmgr.cpp:1137
if (bot_class >= BOT_CLASS_EX_START)
{
    switch (bot_class)
    {
        case BOT_CLASS_BM:           return RACE_ORC;         // 剑圣
        case BOT_CLASS_SPHYNX:       return RACE_UNDEAD_PLAYER;
        case BOT_CLASS_ARCHMAGE:     return RACE_HUMAN;
        case BOT_CLASS_DREADLORD:    return RACE_UNDEAD_PLAYER;
        case BOT_CLASS_SPELLBREAKER: return RACE_BLOODELF;
        case BOT_CLASS_DARK_RANGER:  return RACE_BLOODELF;
        case BOT_CLASS_NECROMANCER:  return RACE_HUMAN;
        case BOT_CLASS_SEA_WITCH:    return RACE_TROLL;
        case BOT_CLASS_CRYPT_LORD:   return RACE_UNDEAD_PLAYER;
    }
}
return bot_race;
```

自定义职业的 `me->GetRace()` 存的是**模型种族**，不是"该按哪个种族说话"。
用 `BotMgr::GetBotPlayerRace(me)` 才对 —— 这也是上游
`QueryHandler.cpp:69` 给客户端发名字查询时用的同一个函数。
