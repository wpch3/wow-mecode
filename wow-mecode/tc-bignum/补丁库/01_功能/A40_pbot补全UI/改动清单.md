================================================================

================================================================
 改动二：公会签名钩子
================================================================

问题根源（F07 早就查过）：

    服务端【没有任何字段】记录"这个人正被要求签名"。
    邀请方点"要求签名"时，服务端只是给目标发一个包。
    bot 没客户端 -> 包被丢弃 -> bot 永远不知道有人要它签名。
    客户端在等 bot 回 SMSG_PETITION_SIGN_RESULTS，等不到就一直灰着。

所以轮询做不到，必须用钩子 —— 和 step57 交易钩子一模一样的套路。

文件 D:\TrinityCore\src\server\game\Handlers\PetitionsHandler.cpp

搜索原文（约 585 行，HandleOfferPetitionOpcode 的最后一句）：

    SendPetitionSigns(petition, player);
}

替换为：

    SendPetitionSigns(petition, player);

    // A40: PlayerBot 没有客户端，收不到 SendPetitionSigns 发的包，
    // 也就永远不会回 CMSG_PETITION_SIGN -> 邀请方的按钮一直是灰的。
    // 这里替它直接签名。判断依据是"没有真实网络连接"（m_Socket 为空），
    // 这个特征不依赖任何内存标志，重启也不会失效。
    if (player->GetSession() && player->GetSession()->PlayerDisconnected())
    {
        uint32 botAccount = player->GetSession()->GetAccountId();
        if (petition->OwnerGuid != player->GetGUID() &&
            !petition->IsPetitionSignedByAccount(botAccount))
        {
            const_cast<Petition*>(petition)->AddSignature(botAccount, player->GetGUID(), false);

            CharacterDatabasePreparedStatement* stmt =
                CharacterDatabase.GetPreparedStatement(CHAR_INS_PETITION_SIGNATURE);
            stmt->setUInt32(0, petition->OwnerGuid.GetCounter());
            stmt->setUInt32(1, petitionGuid.GetCounter());
            stmt->setUInt32(2, player->GetGUID().GetCounter());
            stmt->setUInt32(3, botAccount);
            CharacterDatabase.Execute(stmt);

            WorldPacket data(SMSG_PETITION_SIGN_RESULTS, 8 + 8 + 4);
            data << petitionGuid;
            data << player->GetGUID();
            data << uint32(PETITION_SIGN_OK);
            SendPacket(&data);

            ChatHandler(this).PSendSysMessage(
                "|cff00ff00[%s]|r 在你的请愿书上签了名。", player->GetName().c_str());
        }
    }
}

需要的 include（文件开头确认有，缺就加）：

 改动三：加个开关（可选）
================================================================

如果你希望能单独关掉自动签名：

文件 pbot_autoaccept.h

搜索：

    PBOT_AUTO_RELEASE   = 0x40,     // 死后自动释放尸体变鬼魂

在下面加：

    PBOT_AUTO_PETITION  = 0x80,     // 自动在公会请愿书上签名

然后把 PBOT_AUTO_DEFAULT 和 PBOT_AUTO_ALL 里也加上 PBOT_AUTO_PETITION。

不过改动二的钩子在 PetitionsHandler.cpp 里，读不到 g_pbots 的开关，
要做开关得多绕一层。建议先不加，直接always on。
