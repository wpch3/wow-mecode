# G23-P3A Lua服务器助手与完整GM帮助：安装、验收与回滚

更新时间：2026-08-22  
目标根：`D:\TC-Build\bin\RelWithDebInfo`  
前置：P2R1已安装并由用户确认`.tp`分类菜单恢复正常

## 1. 本批功能

### `.server`统一助手

```text
.server
.server status
.server commands [页]
.server daily
.server tp
.server gmhelp
.server health       GM2
```

`.server info`、`.server motd`、`.server restart`、`.server shutdown`、`.server set`及未来未知原生子命令都显式透传给TrinityCore，不被Lua助手抢占。控制台命令也全部透传。

### `.gmhelp`完整化

旧C++ `.gmhelp`只有固定旧目录，遗漏了后续加入的`.combo/.buff/.setup`、PBot/Bot、剧情、世界工具、P2/P3 Lua等大量指令。

P3A在Lua命令钩子中提供新版`.gmhelp`：

- 153条去重项目/常用核心中文目录，覆盖当前项目所有已识别顶层自建指令；
- 11个无状态Gossip分类，不保存跨Lua state会话；
- `.gmhelp find <关键词>`同时搜索项目中文目录和真实`world.command`；
- `.gmhelp core <关键词>`只搜索核心数据库命令帮助；
- `.gmhelp cat`、`.gmhelp list <分类> [页]`、`.gmhelp all [页]`；
- `.gmhelp verify`显示静态目录数量及当前`world.command`条目数；
- 菜单只展示说明，不自动执行重启、关服、reload等危险指令。

旧C++ `.gmhelp`文件不修改、不重新编译；Lua只在游戏内优先接管`.gmhelp`。回滚后会自然恢复旧C++行为。

## 3. 唯一安装顺序

1. 双击`G23P3A_Check.cmd`，必须看到：

```text
G23P3A_STATE=READY_TO_APPLY
G23P3A_SQL_REQUIRED=False
G23P3A_COMPILE_REQUIRED=False
G23P3A_RELOAD_ELUNA_ALLOWED=False
```

2. 从worldserver控制台正常停服。
3. 双击`G23P3A_Apply.cmd`，必须看到：

```text
G23P3A_APPLY=PASS
G23P3A_FINAL_STATE=POST
```

4. 正常启动worldserver。

**无需SQL、无需VS2022编译，禁止执行`.reload eluna`。**

## 4. 简短验收

只需确认：

1. `.server`显示统一助手；
2. `.server info`仍显示TrinityCore原生服务器信息；
3. `.gmhelp`打开11类菜单；
4. `.gmhelp find pbot`能看到PlayerBot相关目录；
5. `.gmhelp core reload`能返回`world.command`中的核心帮助。

如第5项提示`world.command当前不可读`，新版静态项目目录仍可用；回传该行即可，不要手工改数据库。

## 5. 回滚

仅在出现新问题时，正常停服后双击`G23P3A_Rollback.cmd`。它恢复P2版`G23Core.ext/custom_welcome.lua`并删除两个P3A新脚本；P2R1传送、P2 SQL及F45均不受影响。
