## 根因1：`bot_ai.h` 少了两行声明

### 这是第3步「改动四」漏做了

`bot_ai.cpp:20942` 写了 `uint8 bot_ai::GetGiftNeedState(...) const`，
但 `bot_ai.h` 里没有对应声明 -> 编译器认为它不是 `bot_ai` 的成员
-> 函数体里的 `me`、`HasRealEquipment()` 全部失效。

### 修法

文件：`D:\TrinityCore\src\server\game\AI\NpcBots\bot_ai.h`

**Ctrl+F 搜这一行**（第2步加的，全文件唯一）：

```text
uint32 GetGiftRejectText(uint8 reason) const;
```

你会看到（周围是第2步加的三行）：

```cpp
    uint8 CheckGiftItem(Item const* item) const;
    uint8 ClassifyGiftItem(Item const* item) const;
    uint32 GetGiftRejectText(uint8 reason) const;
```

**在 `GetGiftRejectText` 那行下面加两行**，变成：

```cpp
    uint8 CheckGiftItem(Item const* item) const;
    uint8 ClassifyGiftItem(Item const* item) const;
    uint32 GetGiftRejectText(uint8 reason) const;
    uint8 GetGiftNeedState(uint8 itemKind) const;
    uint8 GetBondTierWith(Player const* player) const;
```

## 根因2：第4步「修正版」的第一段没插进去

### 报错位置

```text
bot_ai.cpp:9690  C2065 "giftItemId": 未声明的标识符
bot_ai.cpp:9690  C2065 "gainPoints": 未声明的标识符
bot_ai.cpp:9691  C2065 "giftZoneId": 未声明的标识符
```

说明 `RecordGift(...)` 那段（用这三个变量的）**插进去了**，
但**定义这三个变量的那段没插**。

### 修法

文件：`D:\TrinityCore\src\server\game\AI\NpcBots\bot_ai.cpp`

**Ctrl+F 搜这一行**（在 `GOSSIP_SENDER_GIFT_ITEM` 分支里，全文件唯一）：

```text
uint8 giftKind  = ClassifyGiftItem(item);
```

你现在应该看到（第3步装的原样）：

```cpp
            uint8 giftKind  = ClassifyGiftItem(item);
            uint8 needState = GetGiftNeedState(giftKind);
            uint8 bondTier  = GetBondTierWith(player);
            bool useNow = (needState == 1) &&
```

**在 `uint8 bondTier = GetBondTierWith(player);` 那行下面，
插入这 8 行**：

```cpp
            uint32 todayCnt = BotCompanionMgr::GetTodayGiftCount(
                me->GetEntry(), 0, player->GetGUID().GetCounter());
            int16 gainPoints = BotCompanionMgr::CalcGiftPoints(
                giftKind, item->GetTemplate()->Quality, item->GetTemplate()->ItemLevel,
                needState, todayCnt);
            uint32 giftItemId = item->GetTemplate()->ItemId;
            uint32 giftZoneId = me->GetZoneId();
```

### 插入后应该长这样

```cpp
            uint8 giftKind  = ClassifyGiftItem(item);
            uint8 needState = GetGiftNeedState(giftKind);
            uint8 bondTier  = GetBondTierWith(player);

            uint32 todayCnt = BotCompanionMgr::GetTodayGiftCount(
                me->GetEntry(), 0, player->GetGUID().GetCounter());
            int16 gainPoints = BotCompanionMgr::CalcGiftPoints(
                giftKind, item->GetTemplate()->Quality, item->GetTemplate()->ItemLevel,
                needState, todayCnt);
            uint32 giftItemId = item->GetTemplate()->ItemId;
            uint32 giftZoneId = me->GetZoneId();

            bool useNow = (needState == 1) &&
                (giftKind == BOT_GIFT_KIND_FOOD || giftKind == BOT_GIFT_KIND_DRINK || giftKind == BOT_GIFT_KIND_POTION);
```

**关键**：这段必须在 `player->DestroyItem(...)` 和
`MoveItemFromInventory(...)` **之前**，因为那两个调用之后
`item` 指针就失效了，再读 `item->GetTemplate()` 会崩。
