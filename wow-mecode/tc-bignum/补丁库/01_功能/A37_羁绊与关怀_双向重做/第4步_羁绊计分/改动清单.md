## 计分规则（已真编译验证）

### 基础分

| 物品类型 | 基础分 |
|---|---|
| 食物 / 水 | 2 |
| 药水 | 3 |
| 装备 | 5 |
| 珍稀（紫色以上） | 15 |
| 灰色垃圾 | 1 |
| 其它 | 2 |

### 加成

```text
紫色以上(quality>=4)  +10
蓝色(quality==3)      +4
灰色(quality==0)      -1（但最低保留 1 分）
物品等级>=200         +5
物品等级>=100         +2

【正需要时】总分 x2      <- 这是"你懂我"的核心
```

### 防刷（当日累计次数）

```text
第 1-4 次    全额
第 5-9 次    减半
第 10-19 次  只给 1/4
第 20 次以后 0 分
```

单次上限 100 分。

### 等级门槛

| 累计点数 | 等级 | tier |
|---|---|---|
| 0-39 | 0 | 1 生疏 |
| 40-149 | 1 | 1 生疏 |
| 150-399 | 2 | 2 熟悉 |
| 400-999 | 3 | 2 熟悉 |
| 1000-1999 | 4 | 3 深交 |
| 2000+ | 5 | 3 深交 |

**送 20 次面包（每次2分）到 1 级，送一件紫装（30分）顶 15 次面包。**
设计意图：**质量比数量重要**，鼓励送"对方需要的好东西"而不是刷垃圾。

// ---------------------------------------------------------------------------
//  A37 第4步：计算这次赠予值多少羁绊点
// ---------------------------------------------------------------------------
int16 BotCompanionMgr::CalcGiftPoints(uint8 giftKind, uint8 quality, uint32 itemLevel,
                                      uint8 needState, uint32 todayCount)
{
    int32 base = 0;
    switch (giftKind)
    {
        case 1: case 2: base = 2;  break;   // 食物 / 水
        case 3:         base = 3;  break;   // 药水
        case 4:         base = 5;  break;   // 装备
        case 5:         base = 15; break;   // 珍稀
        case 6:         base = 1;  break;   // 垃圾
        default:        base = 2;  break;
    }

    if (quality >= ITEM_QUALITY_EPIC)
        base += 10;
    else if (quality == ITEM_QUALITY_RARE)
        base += 4;
    else if (quality == ITEM_QUALITY_POOR)
        base = std::max(1, base - 1);

    if (itemLevel >= 200)
        base += 5;
    else if (itemLevel >= 100)
        base += 2;

    if (needState == 1)
        base = base * 2;

    if (todayCount >= 20)
        base = 0;
    else if (todayCount >= 10)
        base = base / 4;
    else if (todayCount >= 5)
        base = base / 2;

    if (base < 0)
        base = 0;
    if (base > 100)
        base = 100;

    return int16(base);
}

// ---------------------------------------------------------------------------
//  A37 第4步：累计点数换算羁绊等级 0-5
// ---------------------------------------------------------------------------
uint8 BotCompanionMgr::CalcBondLevel(uint32 points)
{
    if (points >= 2000) return 5;
    if (points >= 1000) return 4;
    if (points >= 400)  return 3;
    if (points >= 150)  return 2;
    if (points >= 40)   return 1;
    return 0;
}

// ---------------------------------------------------------------------------
//  A37 第4步：查今天已经收了几次（防刷）
// ---------------------------------------------------------------------------
uint32 BotCompanionMgr::GetTodayGiftCount(uint32 botId, uint8 botKind, uint32 ownerGuid)
{
    uint32 dayStart = uint32(GameTime::GetGameTime()) - 86400;

    QueryResult res = CharacterDatabase.PQuery(
        "SELECT COUNT(*) FROM npcbot_gift_log WHERE bot_id = {} AND bot_kind = {} "
        "AND owner_guid = {} AND direction = 0 AND give_time > {}",
        botId, uint32(botKind), ownerGuid, dayStart);

    return res ? res->Fetch()[0].GetUInt32() : 0;
}

// ---------------------------------------------------------------------------
//  A37 第4步：记流水 + 累加羁绊
// ---------------------------------------------------------------------------
void BotCompanionMgr::RecordGift(uint32 botId, uint8 botKind, uint32 ownerGuid,
                                 uint32 itemEntry, uint32 itemCount, int16 points,
                                 uint8 disposal, uint32 zoneId)
{
    uint32 now = uint32(GameTime::GetGameTime());

    CharacterDatabase.PExecute(
        "INSERT INTO npcbot_gift_log (bot_id, bot_kind, owner_guid, item_entry, item_guid, "
        "item_count, give_time, points, direction, disposal, zone_id) "
        "VALUES ({}, {}, {}, {}, 0, {}, {}, {}, 0, {}, {})",
        botId, uint32(botKind), ownerGuid, itemEntry,
        itemCount, now, int32(points), uint32(disposal), zoneId);

    CharacterDatabase.PExecute(
        "INSERT INTO npcbot_bond (bot_id, owner_guid, bot_kind, gift_points, gifts_to_bot, "
        "last_gift_entry, last_gift_time, first_met) "
        "VALUES ({}, {}, {}, {}, 1, {}, {}, {}) "
        "ON DUPLICATE KEY UPDATE "
        "gift_points = gift_points + {}, "
        "gifts_to_bot = gifts_to_bot + 1, "
        "last_gift_entry = {}, "
        "last_gift_time = {}",
        botId, ownerGuid, uint32(botKind), uint32(points > 0 ? points : 0),
        itemEntry, now, now,
        uint32(points > 0 ? points : 0), itemEntry, now);

    CharacterDatabase.PExecute(
        "UPDATE npcbot_bond SET bond_points = gift_points, "
        "bond_level = CASE "
        "WHEN gift_points >= 2000 THEN 5 "
        "WHEN gift_points >= 1000 THEN 4 "
        "WHEN gift_points >= 400 THEN 3 "
        "WHEN gift_points >= 150 THEN 2 "
        "WHEN gift_points >= 40 THEN 1 "
        "ELSE 0 END "
        "WHERE bot_id = {} AND owner_guid = {}",
        botId, ownerGuid);
}

// ---------------------------------------------------------------------------
//  A37 第4步：读羁绊等级
// ---------------------------------------------------------------------------
uint8 BotCompanionMgr::GetBondLevel(uint32 botId, uint8 botKind, uint32 ownerGuid)
{
    QueryResult res = CharacterDatabase.PQuery(
        "SELECT bond_level FROM npcbot_bond WHERE bot_id = {} AND bot_kind = {} AND owner_guid = {}",
        botId, uint32(botKind), ownerGuid);

    return res ? res->Fetch()[0].GetUInt8() : 0;
}

## 设计说明

### 为什么用 `ON DUPLICATE KEY UPDATE`

`npcbot_bond` 主键是 `(bot_id, owner_guid)`，第一次送东西时还没有行。
用 `INSERT ... ON DUPLICATE KEY UPDATE` 一条语句搞定"有就更新、没有就新建"，
不用先 SELECT 再判断。

### 为什么分三条 SQL

1. 写流水（`npcbot_gift_log`）
2. 累加点数（`npcbot_bond`）
3. 重算等级（`UPDATE ... CASE WHEN`）

第 3 条用 SQL 的 `CASE WHEN` 而不是在 C++ 里算，
是因为**这样即使你手动改了 `gift_points`，下次送东西时等级会自动修正**。

### 为什么 `bot_kind` 传 0

`0=NPCBot 1=PlayerBot`。第6步做 PlayerBot 版时传 1，
表结构和函数签名现在就留好了位置。
