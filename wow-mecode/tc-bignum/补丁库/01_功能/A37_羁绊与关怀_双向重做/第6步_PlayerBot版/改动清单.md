# A37 第6步：PlayerBot 版（A37 收官）

把前五步的羁绊+关怀全部搬到 PlayerBot 上，
**同时解决 G12 的两个缺口**（`.pbot 接受` 不收物品 + 让 pbot 给你东西）。

**共 4 处改动，全部在 `pbot_autoaccept.cpp`，不用重跑 CMake。**

## 这一步做完你能做什么

```text
1. 跟 pbot 交易给它东西 -> 它会【真的点接受】，并说一句反馈
2. 给它东西会【累积羁绊】，和 NPCBot 共用一套分数
3. 它饿了/受伤了/装备快坏了 -> 会私聊你要东西
4. .pbot give <角色名> <物品ID> [数量]  -> 让它把东西给你
```

## 为什么能大量复用

第4/5步我把数据层接口的第二个参数设计成 `bot_kind`：

```cpp
static uint8 GetBondLevel(uint32 botId, uint8 botKind, uint32 ownerGuid);
static void RecordGift(uint32 botId, uint8 botKind, ...);

```

```text
botKind = 0  ->  NPCBot，botId 是 creature entry
botKind = 1  ->  PlayerBot，botId 是角色 guid
```

**所以数据层一行都不用改**，只需要在 PlayerBot 侧调用时传 1。

台词表 `npcbot_gift_text` / `npcbot_request_text` 也完全共用。

### 整个函数替换为

```cpp
static void TryAcceptTrade(Player* bot)
{
    TradeData* trade = bot->GetTradeData();
    if (!trade)
        return;

    Player* trader = trade->GetTrader();
    if (!trader)
        return;

    // ---- 距离自愈（F26）：只按纯距离，不掺相位 ----
    if (bot->GetMapId() != trader->GetMapId())
    {
        bot->TradeCancel(true);
        return;
    }

    float const cancelDist = TRADE_DISTANCE * 3.0f;
    if (bot->GetExactDist2d(trader) > cancelDist)
    {
        bot->TradeCancel(true);
        return;
    }

    // ---- A37 第6步：对方点了接受，bot 也点接受 ----
    TradeData* hisTrade = trader->GetTradeData();
    if (!hisTrade || !hisTrade->IsAccepted() || trade->IsAccepted())
        return;

    // 成交前先把物品信息记下来，成交后 Item* 就不属于对方了
    struct GiftInfo { uint32 entry; uint32 quality; uint32 ilvl; uint32 count; };
    std::vector<GiftInfo> incoming;
    for (uint8 i = 0; i < TRADE_SLOT_TRADED_COUNT; ++i)
    {
        Item* it = hisTrade->GetItem(TradeSlots(i));
        if (!it || !it->GetTemplate())
            continue;
        incoming.push_back({ it->GetTemplate()->ItemId,
                             it->GetTemplate()->Quality,
                             it->GetTemplate()->ItemLevel,
                             it->GetCount() });
    }

    WorldPacket acceptPkt(CMSG_ACCEPT_TRADE, 0);
    bot->GetSession()->HandleAcceptTradeOpcode(acceptPkt);

    if (incoming.empty())
        return;

    uint32 botId = bot->GetGUID().GetCounter();
    uint32 ownerGuid = trader->GetGUID().GetCounter();
    uint8 bondLvl = BotCompanionMgr::GetBondLevel(botId, 1, ownerGuid);
    uint8 tier = BotCompanionMgr::BondLevelToTier(bondLvl);

    for (GiftInfo const& g : incoming)
    {
        uint8 kind = BOT_GIFT_KIND_GENERIC;
        if (g.quality >= ITEM_QUALITY_EPIC)
            kind = BOT_GIFT_KIND_RARE;
        else if (g.quality == ITEM_QUALITY_POOR)
            kind = BOT_GIFT_KIND_JUNK;

        uint32 todayCnt = BotCompanionMgr::GetTodayGiftCount(botId, 1, ownerGuid);
        int16 pts = BotCompanionMgr::CalcGiftPoints(kind, g.quality, g.ilvl, 0, todayCnt);
        BotCompanionMgr::RecordGift(botId, 1, ownerGuid, g.entry, g.count, pts, 0, 0);
    }

    CompanionGiftText const* gt = sBotCompanionMgr->PickGiftText(
        BOT_GIFT_KIND_GENERIC, 0, tier, 0, 0);

    if (gt && trader->GetSession())
    {
        std::string msg = BotCompanionMgr::FormatGiftText(
            gt->Text, "", trader->GetName(), uint32(incoming.size()));
        ChatHandler(trader->GetSession()).PSendSysMessage(
            "|cff00ff00[%s]|r %s", bot->GetName().c_str(), msg.c_str());
    }
}
```

### 关键点说明

```text
1. hisTrade->IsAccepted() && !trade->IsAccepted()
   -> 只在【你点了接受、bot还没点】时才动作，避免死循环

2. 先记录 incoming 再调 HandleAcceptTradeOpcode
   -> 成交后物品已经易手，Item* 读不到原主人的数据了

3. RecordGift 的第2个参数传 1 = PlayerBot
   -> 和 NPCBot 共用一套 npcbot_bond 表，靠 bot_kind 区分
```

## 改动三 / 共4处 —— PlayerBot 主动索要

### 在 `TryAutoRelease` 函数**之前**整段插入

```cpp
// ---------------------------------------------------------------------------
//  A37 第6步：PlayerBot 主动索要
// ---------------------------------------------------------------------------
static uint8 PBotDecideRequest(Player* bot)
{
    uint32 broken = 0;
    uint32 lowDura = 0;
    for (uint8 i = EQUIPMENT_SLOT_START; i < EQUIPMENT_SLOT_END; ++i)
    {
        Item* eq = bot->GetItemByPos(INVENTORY_SLOT_BAG_0, i);
        if (!eq)
            continue;
        uint32 maxDura = eq->GetUInt32Value(ITEM_FIELD_MAXDURABILITY);
        if (!maxDura)
            continue;
        uint32 curDura = eq->GetUInt32Value(ITEM_FIELD_DURABILITY);
        if (curDura == 0)
            ++broken;
        else if (curDura * 100 / maxDura < 30)
            ++lowDura;
    }

    if (broken > 0 || lowDura >= 2)
        return BOT_REQUEST_REPAIR;

    float hpPct = bot->GetHealthPct();
    if (hpPct < 35.0f)
        return BOT_REQUEST_BANDAGE;
    if (hpPct < 60.0f)
        return BOT_REQUEST_FOOD;

    if (bot->GetMaxPower(POWER_MANA) > 1 && bot->GetPowerPct(POWER_MANA) < 40.0f)
        return BOT_REQUEST_DRINK;

    return BOT_REQUEST_NONE;
}

static void TryBotRequest(Player* bot, uint32 diff)
{
    ObjectGuid bguid = bot->GetGUID();

    uint32& timer = _pbotRequestTimer[bguid];
    if (timer > diff)
    {
        timer -= diff;
        return;
    }
    timer = 0;

    if (!bot->IsInWorld() || !bot->IsAlive() || bot->IsInCombat())
        return;

    Group* grp = bot->GetGroup();
    if (!grp)
    {
        timer = 60000;
        return;
    }

    Player* owner = ObjectAccessor::FindPlayer(grp->GetLeaderGUID());
    if (!owner || owner == bot || !owner->IsInWorld() || owner->IsInCombat())
    {
        timer = 60000;
        return;
    }

    if (bot->GetMapId() != owner->GetMapId() || bot->GetExactDist2d(owner) > 40.0f)
    {
        timer = 60000;
        return;
    }

    uint8 reqType = PBotDecideRequest(bot);
    if (reqType == BOT_REQUEST_NONE)
    {
        timer = 30000;
        return;
    }

    uint8& lastReq = _pbotLastRequest[bguid];
    if (reqType == lastReq && urand(0, 2))
    {
        timer = 60000;
        return;
    }

    uint32 botId = bguid.GetCounter();
    uint32 ownerGuid = owner->GetGUID().GetCounter();
    uint8 bondLvl = BotCompanionMgr::GetBondLevel(botId, 1, ownerGuid);
    uint8 tier = BotCompanionMgr::BondLevelToTier(bondLvl);

    CompanionRequestText const* rt = sBotCompanionMgr->PickRequestText(reqType, tier, 0);
    if (!rt)
    {
        timer = 120000;
        return;
    }

    if (owner->GetSession())
        ChatHandler(owner->GetSession()).PSendSysMessage(
            "|cffffff00[%s]|r %s", bot->GetName().c_str(), rt->Text.c_str());

    BotCompanionMgr::RecordRequest(botId, 1, ownerGuid, reqType);

    lastReq = reqType;
    timer = BotCompanionMgr::CalcRequestCooldown(tier, urand(180000, 300000));
}

```

## 设计说明

### 为什么用队长而不是"主人"

PlayerBot **没有主人概念**，它就是个普通 Player。
所以用**队伍队长**作为"跟谁建立羁绊"的对象。

这也符合直觉：一起组队冒险的人，才会有羁绊。

### `.pbot give` 为什么不走交易

走交易要模拟一大堆包，而且会卡在"等对方点接受"。
GM 指令直接 `DestroyItemCount` + `StoreNewItem` 更干脆。

如果你想要"bot 主动发起交易"那种沉浸感，
那是 G11（自主社交）的范畴，第6步不做。

### 索要为什么用 PSendSysMessage 而不是私聊

PlayerBot 发真正的私聊需要构造 `CMSG_MESSAGECHAT` 包，
容易出问题。`PSendSysMessage` 直接在你聊天框显示，效果一样且稳定。
