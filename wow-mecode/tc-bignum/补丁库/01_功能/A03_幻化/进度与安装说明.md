### 为什么不做 Gossip 菜单（已论证）

| | 候选集 | 需要输入 | 菜单合适吗 |
|---|---|---|---|
| 套装菜单（已装） | ItemSet.dbc 约 150 套 | 不用，点击即完成 | ✅ **正确用法** |
| 幻化 | item_template **38608 件** | 必须打 ID | ❌ 不适用 |

- Gossip 硬上限 32 条/页（`GossipDef.cpp:41` 是 **ASSERT，超了崩服**），38608 件要 **1332 页**
- Eluna 回调拿不到输入框（`GossipHooks.cpp:81-88` 只推 6 个参数，`menu_id` 恒为 nil）
- 就算做出来，最后一步还是得手打 ID —— 菜单只是在指令前面加了四步

**判断标准**：候选集能否 5 页内列完 + 点击即完成 → 用菜单，否则用指令。

**套装菜单没装错**，那是 Gossip 的教科书用法，继续用。

## 二、方案原理（已逐行核实）

### 唯一插入点

全服只有 `Player::SetVisibleItemSlot()`（**Player.cpp:12170**）一处写外观字段：

```cpp
SetUInt32Value(PLAYER_VISIBLE_ITEM_1_ENTRYID + (slot * 2), pItem->GetEntry());
SetUInt16Value(PLAYER_VISIBLE_ITEM_1_ENCHANTMENT + (slot * 2), 0, ...);
```

调用点仅 **5 处**：12205 / 12287 / 12417 / 17279 + 定义本身。

在这一处插「查幻化缓存」，**所有场景自动生效**：登录 / 换装 / 跨图 / 进副本 / 别人看你。

### 为什么必须用内存缓存（关键发现）

`Player.cpp:17279` 在 `LoadFromDB` 内会遍历 19 个槽位调 `SetVisibleItemSlot(slot, nullptr)`，
随后 **17764 行**才 `_LoadInventory()` 填回装备。

而 `PlayerScript::OnLogin` 钩子在**整个 LoadFromDB 之后**才触发 ——
**若靠 OnLogin 查库，登录瞬间外观是空的，必须换装才显示。**

因此改用「服务器启动时全量载入内存」：
- 零 DB 查询（`GetFakeEntry` 是纯 `unordered_map` 查找）
- 零时序问题
- 跨图不失效

## 五、指令用法

```
.transmog                        帮助
.transmog find <词> [品质] [页]  搜外观，输出可点击链接  ← 新增
.transmog preview <物品ID>       试穿，15秒自动恢复      ← 新增
.transmog restore                立即结束试穿            ← 新增
.transmog slot <槽位> <物品ID>   幻化指定槽位（槽位支持中文）
.transmog copy <物品ID>          自动识别部位并幻化  ← 最省事
.transmog remove <槽位>          移除单槽
.transmog clear                  清空全部
.transmog list                   查看当前幻化（带真实装备对照）
.transmog slots                  查看可用槽位名
.transmog save <名字>            保存方案
.transmog load <名字>            载入方案
.transmog del <名字>             删除方案
.transmog sets                   列出所有方案
```

**槽位名支持 71 条中英文别名**：

```
.transmog slot 头盔 12640
.transmog slot 头   12640
.transmog slot head 12640
.transmog slot 0    12640     ← 都等价
```

**最省事的用法**（不用记槽位）：

```
.transmog copy 12640     ← 自动识别这是头盔，幻化到头部
```

### 完整工作流（解决「不知道哪个ID好看」）

```
.transmog find 头盔 紫        搜紫色头盔，按品质+装等排序，15条/页
    ↓ 看到中意的，鼠标悬停可看模型和属性
.transmog preview 12640       试穿，15秒后自动恢复
    ↓ 满意
.transmog copy 12640          正式幻化
```

`find` 的输出是客户端原生 `|Hitem|h` 链接，**悬停看图标属性、Shift点击插入聊天框**。

品质词支持：`灰 白 绿 蓝 紫 橙 神器` / `poor common uncommon rare epic legendary`（大小写不限）

### 指令层做的安全检查

| 检查 | 行为 |
|---|---|
| 槽位无装备 | 拒绝并提示（空槽幻化客户端不显示） |
| 物品不存在 / 无模型 | 拒绝 |
| 项链/戒指/饰品 | 拒绝（3.3.5 客户端不显示这些外观） |
| 收集模式开启时 | 检查背包 `HasItemCount` |
| 有费用时 | 检查 `HasEnoughMoney` 后扣款 |
| 删除角色 | `OnDelete` 自动清数据（防 GUID 复用顶到别人幻化） |
