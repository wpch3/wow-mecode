## 零、为什么官方指令不够用

我先查了现成的，**官方确实有两个相关指令，但都差一口气**：

| 官方指令 | 位置 | 为什么不够 |
|---|---|---|
| `.npcbot recall` | botcommands.cpp:2937 | `owner->GetBotMgr()->GetBot(guid)` —— **只能召自己雇的**，游荡bot没owner |
| `.npcbot list spawned free` | botcommands.cpp:3959 | 能列出无主bot，但只给 entry/名字/等级/区域名，**没有坐标和距离** |

所以：**你知道有哪些游荡bot，但不知道它在哪，也叫不过来。**

`.bf` 就是补这一口气。

## 一、用法

```
.bf                    列出【本地图】游荡bot，带距离，按远近排序
.bf all                列出【全服】
.bf near <码>          只看这个距离内的（不填默认200码）

.bf come               把【最近的一个】叫到身边      <- 测试最常用
.bf come <数量>        把最近的N个叫来（上限10）
.bf come entry <ID>    把指定entry的叫来（可跨地图）

.bf goto               传送到最近的游荡bot那里
.bf goto entry <ID>    传送到指定bot
```

## 三、可能的编译问题

这个文件 include 了 NpcBots 的头：

```cpp
#include "botdatamgr.h"
#include "botmgr.h"
#include "bot_ai.h"
```

**如果报找不到头文件**，说明 scripts 项目没有把 NpcBots 目录加进 include 路径。

**解决**：在 `src/server/scripts/CMakeLists.txt` 里找到 `target_include_directories`，
加一行：

```cmake
  ${CMAKE_SOURCE_DIR}/src/server/game/AI/NpcBots
```

> 官方的 `cs_npc.cpp` 之类如果已经引用过 bot 头文件，那就不用改。
> **先直接编译试，报错了再改。**

## 七、和后续 `.bots` 批量指令的关系

`.bf` 只管**游荡bot**（无主的）。
你要的"一键组团本""一键清空无主bot"是另一批，见下一节排期。

**已有的官方指令可以先用**：

| 你想要的 | 官方现成的 | 够用吗 |
|---|---|---|
| 清空无主bot | `.npcbot delete free` | **够用**，botcommands.cpp:631 |
| 列出无主bot | `.npcbot list spawned free` | 不够（没坐标）-> `.bf` 补上了 |
| 召回自己的bot | `.npcbot recall` | **够用** |
| 一键组团本 | 无 | 要做 |
| 一键配队伍预设 | 无 | 要做 |
