## 一、好消息：汉化不用改代码

**NPCBot 的所有界面文本都不在代码里，而是查数据库**：

```cpp
// bot_ai.cpp:215
const std::string& bot_ai::LocalizedNpcText(Player const* forPlayer, uint32 textId)
{
    LocaleConstant loc = forPlayer ? forPlayer->GetSession()->GetSessionDbLocaleIndex() : ...;

    if (GossipText const* nt = sObjectMgr->GetGossipText(textId))     // 查 world.npc_text
    {
        NpcTextLocale const* ntl = sObjectMgr->GetNpcTextLocale(textId);  // 查 world.npc_text_locale
        if (loc != DEFAULT_LOCALE && ntl && ...)
            return ntl->Text_0[0][loc];      // <- 优先返回本地化版本
        else
            return nt->Options[0].Text_0;    // <- 没有才用英文原文
    }
}
```

**所以：往 `npc_text_locale` 插中文 = 界面变中文。不用编译。**

## 五、怎么自己继续汉化

SQL 文件末尾有一条**自查语句**，执行后会列出**还没汉化的条目**：

```sql
SELECT t.`ID`, LEFT(t.`text0_0`, 60) AS `英文原文`
FROM `world`.`npc_text` t
LEFT JOIN `world`.`npc_text_locale` l
       ON l.`ID` = t.`ID` AND l.`Locale` = 'zhCN'
WHERE t.`ID` BETWEEN 70001 AND 70700
  AND l.`ID` IS NULL
ORDER BY t.`ID`;
```

**看到哪条想翻译，就加一行**：

```sql
INSERT INTO `world`.`npc_text_locale` (`ID`, `Locale`, `Text0_0`) VALUES
(70XXX, 'zhCN', '你的中文');
```

**改完重启即可，永远不用编译。**

## 六、关于「指令」的汉化

你说的"指令也要中文"，这个要分开看：

| 类型 | 能不能汉化 | 说明 |
|---|---|---|
| **界面文本**（本次做的）| **能**，纯SQL | 菜单、提示、按钮 |
| **指令名**（如 `.npcbot`）| **不建议** | 中文指令名要在聊天框切输入法，反而慢 |
| **指令帮助文本** | **能**，但在代码里 | 需要改 `botcommands.cpp`，工作量大 |

**我的建议**：
- 界面汉化（本次）已经解决 90% 的"看不懂"问题
- 指令名保持英文，但可以**加中文别名**（像我们 `.emote 跪下` 那样）
- 如果你觉得某个指令特别常用，告诉我，我单独给它加中文别名

## 七、如果发现漏翻或翻错

**直接改数据库就行**：

```sql
UPDATE `world`.`npc_text_locale`
SET `Text0_0` = '新的翻译'
WHERE `ID` = 70XXX AND `Locale` = 'zhCN';
```
