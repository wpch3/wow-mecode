# NPCBot 批次0 —— 开启闲逛 bot（改一个数字）

## 一、改哪里

`D:\TC-Build\bin\RelWithDebInfo\configs\worldserver.conf`（或 `worldserver.conf.d/` 里的对应文件）

**第 4856 行**：

```
NpcBot.WanderingBots.Continents.Count = 0
```

改成一个非 0 的数，比如：

```
NpcBot.WanderingBots.Continents.Count = 100
```

**改完必须重启 worldserver**（不是 reload）。

---

## 二、【重要】填太大会直接崩服

`botdatamgr.cpp:1876-1886`：

```cpp
uint32 maxbots = sBotGen->GetSpareBotsCount();
uint32 enabledbots = sBotGen->GetEnabledBotsCount();

if (maxbots < wandering_bots_desired)
{
    BOT_LOG_FATAL("server.loading", "Only {} out of {} bots ... Aborting!", ...);
    ASSERT(false);          // <- 直接崩，不是警告
}
```

**填的数超过可用 bot 数 = 启动时 ASSERT 崩溃。**

### 你的安全上限

预置 bot 模板总数（`sql/custom/world/npcbot_2000_00_00_00_creature_template.sql`）：

```
370 个    entry 范围 70000 - 70595
```

但**可用数 = 370 - 已被玩家雇佣的 - 未启用职业的**：

- `_spareBotIdsPerClassMap` 会 `erase` 掉已占用的 entry（`botdatamgr.cpp:368/474`）
- 你 conf 里 19 个职业全开，所以职业侧不减

**建议**：

| 起步值 | 说明 |
|---|---|
| **50** | 最保险，先看效果 |
| 100 | 比较热闹 |
| 200 | 上限的一半多，仍有余量 |
| 300+ | 接近上限，如果你雇了很多 bot 就有崩服风险 |

**我建议先填 50 试**，确认能正常启动、能在野外看到 bot 之后再往上加。

## 三、还有一个会静默失效的坑

`botconfig.cpp:587-592`：

```cpp
if (_enabled_wander_node_maps.empty())
{
    BOT_LOG_ERROR("server.loading",
        "NpcBot.WanderingBots.Continents.Maps does not provide any valid maps! "
        "Wandering bots will not be spawned!");
    _desiredWanderingBotsCount = 0;      // <- 被强制归零
}
```

如果 `Continents.Maps` 里没有合法的大陆地图 ID，
**Count 会被强制改成 0，改了等于没改**。

你的 conf 第 4874 行：

```
NpcBot.WanderingBots.Continents.Maps = 0,1,530,571
```

`0`=东部王国 `1`=卡利姆多 `530`=外域 `571`=诺森德 —— **全部合法，没问题**。

## 六、出问题怎么办

| 现象 | 原因 | 解法 |
|---|---|---|
| 启动崩溃，日志有 "Aborting!" | Count 填太大 | 调小，从 50 起 |
| 启动正常但野外看不到 bot | Maps 配置被判非法 | 检查日志有没有 "does not provide any valid maps" |
| 日志显示 spawn 了但找不到 | bot 分散在四大陆 | 多跑几个地方，或先只填 `Maps = 0` 集中在东部王国 |
