# 打过补丁的 exe 到底给了你什么

> 日期：2026-07-31
> 起因：用户自己找到一个补丁 exe，装上能跑，问"这有什么用"

---

## 一、先说结论：它解锁了三件你【原本做不了】的事

**"能运行"只说明它没坏，不说明它给了你什么。**

补丁 exe 通常是多个独立补丁的组合，常见五项：

| 功能 | 你原本 | 打完之后 | 对你的价值 |
|---|---|---|---|
| **1. 文件夹当 MPQ** | 每改一个文件要重打包 | **直接改文件夹里的文件** | **开发效率质变** |
| **2. Allow Interface Edits** | 改不了登录界面/GlueXML | **能改** | **解锁种族扩展**（见下）|
| 3. 自定义物品修复 | 自制物品显示红问号 | 正常显示图标 | 你有 800000+ 装备，用得上 |
| 4. 4GB RAM (LAA) | 32 位客户端只能用 2G | 能用 4G | 装一堆 HD 包后**防崩溃** |
| 5. Disable Cache | 每次改数据都要删 Cache | 不写 WDB 缓存 | **省掉"删 Cache"这一步** |

---

## 二、最重要的一条：第 2 项解锁了种族扩展

我在 `规划-高版本种族移植.md` 里写过一个卡点：

> **卡点**：改 `CharacterCreate.lua` 的 MAX_RACES 需要 Allow Interface Edits 的 exe。
> 变通方案：不改 Interface，写个 `.race` GM 指令。

**如果你的补丁 exe 带这一项，这个卡点就没了。**

意味着 12-21 那十个预留种族（邪兽人、娜迦、破碎者、维库人、海象人、
森林巨魔、牦牛人、冰霜巨魔等）**可以正常出现在角色创建界面**，
而不是只能靠 GM 指令改。

**这是整个种族扩展方案从"变通"变成"正规"的关键。**

---

## 三、第 1 项对你眼下最实用

你刚折腾完 MPQ 打包，应该有体会：改一个贴图要重打一次包。

**有了文件夹补丁**：

```
Data\zhCN\patch-zhCN-Z.MPQ\        <- 是文件夹，不是文件
    Character\
        Human\Female\
            HumanFemaleSkin00_00.blp    <- 直接改这个文件，存盘即生效
```

改完存盘，重进游戏就能看。**不用打包，不用删 Cache（如果还带第 5 项）。**

调贴图/模型时这是天壤之别。

---

## 四、怎么知道你的 exe 带了哪几项

**"能运行"不代表五项全有。** 三个测试，各一分钟。

### 测试 A：文件夹补丁（第 1 项）

```
1. 在 Data\ 下新建【文件夹】，命名 patch-9.MPQ
2. 里面建目录 Sound\Music\GlueScreenMusic\
3. 放一个改名成 WotLK_main_title.mp3 的任意 mp3
4. 删 Cache，启动游戏听登录音乐
```

| 听到你的歌 | 有第 1 项 |
| 没听到 | 没有 |

### 测试 B：Interface Edits（第 2 项）

```
1. 从客户端 MPQ 提出 Interface\GlueXML\GlueStrings.lua
2. 找到 GAME_VERSION_LABEL 或任意一条字符串，改掉文字
3. 打包成 patch-9.MPQ（或放进上面的文件夹）
4. 删 Cache，看登录界面那行字变没变
```

| 字变了 | 有第 2 项 |
| 没变 | 没有 |

### 测试 C：Disable Cache（第 5 项）

```
1. 删掉 Cache 文件夹
2. 启动游戏，进入角色选择界面，退出
3. 看 Cache 文件夹有没有被重新创建
```

| 没重建 | 有第 5 项 |
| 重建了 | 没有 |

### 第 3、4 项怎么看

- **第 4 项（4GB）**：右键 exe → 属性，或用 `client_check.sh` 看文件头。
  更简单的判据：装一堆 HD 包后进达拉然**不崩**，基本就是有。
- **第 3 项（物品修复）**：造一个自定义 entry 的装备，看图标是不是红问号。

---

## 五、有了这个 exe，之前几个卡点的状态更新

| 之前的结论 | 现在 |
|---|---|
| 「exe 打不了补丁，文件夹方式用不了」 | **可能可以了**，测 A |
| 「改 Interface 需要补丁 exe，你没有」 | **可能有了**，测 B |
| 「种族扩展只能靠 .race 指令变通」 | **可能能走正规路线**，看测 B |
| 「每次改动都要删 Cache」 | **可能不用了**，测 C |

**注意**：这些都取决于你那个 exe 具体打了哪几项。做完三个测试才知道。

---

## 六、一个提醒

**备份你原来的 exe。**

```
Wow.exe          <- 补丁版
Wow.exe.orig     <- 原版，留着
```

补丁 exe 出问题（比如某些 MPQ 读不了、崩溃）时，换回去立刻恢复。

另外 **realmlist 要确认还指向你的服务器**：
```
Data\zhCN\realmlist.wtf
set realmlist 127.0.0.1
```
有些补丁 exe 会改读取路径。

---

## 七、结论

> **能运行 = 没坏。**
> **有没有用 = 看它带了哪几项，三个测试一分钟一个。**
>
> **最值钱的是第 2 项（Interface Edits）** ——
> 它把种族扩展从"变通方案"变成"正规方案"。
>
> **最实用的是第 1 项（文件夹补丁）** ——
> 以后改贴图存盘即生效，不用重打包。
