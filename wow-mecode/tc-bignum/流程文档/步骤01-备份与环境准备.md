## 0-1. 备份三个数据库（最重要，别跳过）

打开 CMD（不是 PowerShell，避免编码问题），假设 MySQL 装在默认路径：

```cmd
cd /d C:\
mkdir wow_backup_20260726
cd wow_backup_20260726

"C:\Program Files\MySQL\MySQL Server 8.0\bin\mysqldump.exe" -u root -p --single-transaction world > world_full.sql
"C:\Program Files\MySQL\MySQL Server 8.0\bin\mysqldump.exe" -u root -p --single-transaction characters > characters_full.sql
"C:\Program Files\MySQL\MySQL Server 8.0\bin\mysqldump.exe" -u root -p --single-transaction auth > auth_full.sql
```

> 路径按你实际的 MySQL 版本改。如果用的是 HeidiSQL / Navicat，
> 直接右键数据库 → 导出为 SQL 文件也一样。

**单独再备份两张最关键的表**（回滚时更快）：

```cmd
"C:\Program Files\MySQL\MySQL Server 8.0\bin\mysqldump.exe" -u root -p world item_template > item_template.bak.sql
"C:\Program Files\MySQL\MySQL Server 8.0\bin\mysqldump.exe" -u root -p characters item_instance > item_instance.bak.sql
```

✅ **验证**：`dir` 看一下，5 个 .sql 文件都不是 0 KB。
`world_full.sql` 通常几百 MB 到 1 GB 以上，太小说明导出失败了。

## 0-2. 备份编译好的服务端（能秒回滚）

把你**现在能正常跑**的服务端整个复制一份：

```cmd
xcopy /E /I /Y "C:\你的服务端目录" "C:\wow_backup_20260726\server_working"
```

至少要包含 `worldserver.exe`、`authserver.exe`、`worldserver.conf`、`authserver.conf`。

> 万一新编译的版本起不来，直接把这份拷回去就能开服，不影响玩家。

## 0-3. 源码目录做个 Git 分支（关键，方便回滚补丁）

进你的源码目录：

```cmd
cd /d D:\git\TrinityCore-NPCBOT-Eluna-zhCN
git status
```

**情况 A：显示 `nothing to commit, working tree clean`**

干净，直接建分支：

```cmd
git checkout -b bignum-mod
```

**情况 B：显示有一堆修改过的文件**

说明你之前改过源码。**先保存这些改动**，否则后面会冲突：

```cmd
git add -A
git commit -m "我改造前的存档"
git checkout -b bignum-mod
```

**情况 C：提示 `not a git repository`**

说明你是下载 zip 解压的，没有 git 历史。那就手工复制一份源码目录做备份：

```cmd
xcopy /E /I /Y "D:\git\TrinityCore-NPCBOT-Eluna-zhCN" "C:\wow_backup_20260726\src_backup"
```

（这种情况下，第 1 步我会给你**手工改代码**的版本，不用 `git apply`。
 记得告诉我你是情况 C。）

✅ **验证**：`git branch` 能看到 `* bignum-mod`（情况 C 跳过）。

## 0-4. 确认编译环境

**检查 Visual Studio 版本**：开始菜单搜 "Visual Studio Installer" → 已安装 → 记下版本。
- 需要 **VS 2019 或 VS 2022**
- 必须勾选了 **"使用 C++ 的桌面开发"** 工作负载

**检查 CMake**：

```cmd
cmake --version
```

需要 3.16 以上。没有的话去 cmake.org 下载安装，安装时选 "Add to PATH"。

**确认依赖库路径**（TrinityCore 3.3.5 需要）：
- Boost（通常在 `C:\local\boost_1_8x_0`）
- MySQL 或 MariaDB 的 include/lib
- OpenSSL

> 如果你之前**已经成功编译过一次**这个源码，那这些肯定都齐了，跳过这项即可。

✅ **验证**：你之前编译成功过 = 环境没问题。
