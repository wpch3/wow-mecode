## 第 2 步：`.gmhelp` 指令便利化 —— 已交付

### 解决你说的痛点

> 「输入一个官方的让体型变大的指令要先去查询，然后还要输入」

现在直接搜：

```
.gmhelp find 体型
  角色调整  体型大小  .modify scale
     用法：.modify scale 2
     说明：1=正常 0.5=一半 2=两倍 10=巨大
```

**搜中文、搜别名、搜英文都行。** 实测：

| 搜什么 | 找到 |
|---|---|
| `体型` / `变大` | `.modify scale` |
| `传送` | 5 条（tele/appear/summon/go/recall） |
| `无敌` | `.cheat god` |
| `冷却` | `.speed` + `.cheat cooldown` |
| `技能书` | `.spell clean` |
| `scale` / `god` / `tele` | 同样命中 |

### 全部用法

```
.gmhelp find <关键词>   搜索指令       ← 最常用
.gmhelp menu            分类菜单（可点击）
.gmhelp cat             显示所有分类
.gmhelp list 角色调整   列出某分类全部指令
.gmhelp <关键词>        不写 find 也能直接搜
```

### 指令库规模

**69 条指令，8 个分类**：

| 分类 | 条数 |
|---|---|
| 角色调整 | 15 |
| **本服自定义** | 13 |
| 传送移动 | 9 |
| 作弊开关 | 9 |
| 物品装备 | 8 |
| NPC与生物 | 7 |
| 副本相关 | 4 |
| 其他 | 4 |

> **本服自定义那 13 条**是你自己做的功能（gearset/speed/spell clean/
> reloaditem/add/spawn/bigtest 等），以后不用记，搜就行。

### 加新指令很简单

`cs_gmhelper.cpp` 里 `Library()` 函数加一行：

```cpp
{ ".新指令", "中文名", "别名1 别名2 alias", ".新指令 用法", "说明", CAT_CUSTOM },
```

## 第 3 步：装 AoE Loot 模块

### 为什么最急需

你掉落倍率是 **5-10 倍**（`Rate.Drop.Item.Epic = 5`、`Legendary = 10`），
不装群体拾取会捡到手软。这个模块还带「背包满自动邮寄」。

### 步骤

```bash
# 1. 先备份（重要）
cd /d/TrinityCore
git add -A
git commit -m "before aoe-loot"

# 2. 加远程仓库
git remote add tccc https://github.com/TrinityCore/TrinityCoreCustomChanges.git
git fetch tccc

# 3. 先合前置依赖（wiki 说明其他分支都依赖它）
git merge tccc/3.3.5-base_patch

# 4. 再合 AoE Loot
git merge tccc/3.3.5-aoe-loot-mail-excess
```

### 冲突怎么办

社区反馈 **NPCBots 跟其他模块极易在 `Player.cpp` 冲突**。
如果 merge 报冲突：

```bash
git status                    # 看哪些文件冲突
# 打开冲突文件，找 <<<<<<< ======= >>>>>>> 标记
# NPCBot 的代码块通常有 //npcbot ... //end npcbot 注释包裹，保留它
# 两边的改动通常可以【都保留】，不是二选一
git add <解决后的文件>
git commit
```

**冲突了把第一个冲突文件发给我**，我帮你看怎么合。

### 装完后 conf 加配置

模块会带自己的配置项，装完看它的 `.conf.dist` 文件，
把需要的项加到 `worldserver.conf.d\aoeloot.conf`（新建一个文件）。

## 第 4 步：装 Portal Master（纯SQL，最简单）

### 为什么先装这个

**纯 SQL，不用编译，不会冲突。** 130+ 个传送点，覆盖全大陆。

### 步骤

1. 下载 Portal Master 的 SQL 文件
2. 按你 SQL 客户端的脾气执行（一条一条跑）
3. 游戏内 `.npc add <NPC entry>` 把传送 NPC 刷出来

> 这个模块的 SQL 通常是一大串 INSERT，
> 如果你客户端只跑光标所在语句，可能要分批执行。
> 遇到问题告诉我，我帮你拆成单语句版本。

    RBAC_PERM_COMMAND_RELOAD_ITEM_TEMPLATE                   = 71007,
    RBAC_PERM_COMMAND_GMHELPER                               = 71008,
