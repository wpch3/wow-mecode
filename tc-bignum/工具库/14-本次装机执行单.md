## 零、先纠正你的计划

你说"装 1.2.3.4"，两头都要改：

| 批次 | 你的计划 | 应该 | 原因 |
|---|---|---|---|
| **0** | 漏了 | **必须装** | 只要 10 分钟，而且 `client_check.sh` 是后面所有步骤的前置 |
| 1 | 装 | 装 | 对主线 `.emote`/`.say` 有直接帮助 |
| 2 | 装 | 装 | 你的模型补丁必须用它打包 |
| 3 | 装 | 装 | 补丁可能要改 DBC |
| **4** | 装 | **先别装** | 见下 |

### 批次 4 为什么现在不要碰

**这是唯一可能把你现在能玩的客户端搞坏的一批。**

三个理由：

1. **你的 exe 是整合包作者改过的。** anzz1 的 patcher 要求输入干净未改的
   `Wow.exe`，会直接报 `invalid or corrupt`。喂不进去。
2. **你根本不一定需要它。** `client_check.sh` 会告诉你 exe 有没有打过文件夹补丁。
   如果已经打过，批次 4 的主要好处你已经有了。
3. **装模型补丁不需要它。** 原版 exe 就能加载 `patch-X.MPQ` 真文件
   （见 `00` 篇勘误）。

**做完批次 2 的活体测试，再回头决定要不要 4。** 那时候你有实测数据，不用猜。

## 第 5 步 · 查补丁冲突（5 分钟，最关键）

**这一步很多人跳过，然后花几小时排查"为什么我的模型没生效"。**

你的整合客户端**很可能已经装了人物模型包**。两个包同时存在会打架。

### 怎么查

用 MPQ Editor 挨个打开第 1 步记下的那些 `patch-*.MPQ`，
看根目录有没有 **`Character`** 文件夹。

### 三种结果

| 结果 | 处理 |
|---|---|
| **没有任何包含 `Character\`** | 干净，直接装你的 |
| **有一个包含 `Character\`** | **必须处理**，见下 |
| 有多个 | 整合包本身就乱，建议只保留一个 |

### 如果发现冲突

**不要删文件。** 改名禁用：

```
patch-W.MPQ  ->  patch-W.MPQ_
```

加个下划线，客户端就不认了。想恢复去掉下划线即可。

> Warmane 论坛的标准做法就是这个。装 Leeviathan 的人物包要先禁用
> Warmane 自带的 `patch-w.mpq` 和 `Data\enUS\patch-enUS-w.mpq`。
> **注意 locale 目录里也可能有一份。**

## 第 6 步 · 验模型版本（1 分钟）

**装之前一定要跑这个。** 你说是"别人做好的成品、全身都变了"——
听起来对，但**成品也分给哪个版本做的成品**。

### 有 Python 就用这个

```bash
python 工具库/tools/patch_scan.py "D:/下载/你的补丁目录"
```

### 没装 Python 就用这个（Git Bash 自带命令，零依赖）

```bash
bash 工具库/tools/m2ver.sh "/d/下载/你的补丁目录"
```

### 看结论那一行

| 输出 | 含义 | 下一步 |
|---|---|---|
| **`可以直接用`** | 全是 MD20 v264 | 继续第 7 步 |
| `不能直接用` | 有 MD21 分块格式 | **停**，看 `13` 篇第六节 |
| `需要转换` | MD20 但版本不对 | **停**，看 `13` 篇 |

**只有第一种才继续。** 后两种硬装会崩溃。

> 你说"还是原模型的底子"——如果作者是在 3.3.5 原版模型上改的，
> 那版本号就是 264，会直接通过。这是最好的情况。

## 第 7 步 · 装模型补丁（10 分钟）

### 7.1 确认目录结构

补丁解压后，**第一层应该就是 `Character`**：

```
Character\
  Human\
    Female\
      HumanFemale.m2
      HumanFemale00.skin
      HumanFemaleSkin00_00.blp
  NightElf\
  Orc\
  ...
```

如果外面还套了一层（比如 `全种族模型v3\Character\...`），
**打包时从 `Character` 那层开始**，别把外层文件夹打进去。

### 7.2 打包

用第 1 步拿到的空字母，假设是 `Y`：

```
MPQ Editor -> MPQs -> New MPQ
  文件名: patch-Y.MPQ      <- 扩展名必须大写
  一路 Next 到底
把 Character 文件夹整个拖进去
补丁带 .dbc 的话，另建 DBFilesClient 文件夹放进去
保存
```

**或者**（如果第 1 步显示你的 exe 打过文件夹补丁）：
直接在 `Data\` 下建**文件夹**叫 `patch-Y.MPQ`，内容丢进去，**不用打包**。

### 7.3 放进 Data

```
<客户端>\Data\patch-Y.MPQ
```

### 7.4 【必做】删 Cache

```
删掉 <客户端>\Cache\  整个文件夹
```

**90% 的"装了没变化"都是这步没做。**

### 7.5 验收

进游戏，**先看角色选择界面**（模型加载最快，不用进世界）。

## 第 8 步 · WDBX Editor（只在需要时）

### 什么时候需要

**第 6 步的脚本会告诉你补丁带没带 DBC。**

| 情况 | 要装吗 |
|---|---|
| 补丁自带 `.dbc` | **不用**，作者处理好了 |
| 补丁没带，但第 7 步验收成功 | **不用** |
| 补丁没带，且人物没变化 | **要装** |

### 装法

前置 **.NET Framework 4.6.1**（和 .NET 8 是两个东西，Win10/11 一般自带）

```
https://ci.appveyor.com/api/projects/majorcyto/wdbxeditor/artifacts/WDBXEditor.zip
```

### 要改什么

从客户端 MPQ 提出这两个文件，改完放进你的 `patch-Y.MPQ` 的 `DBFilesClient\`：

- **CharSections.dbc** —— 贴图路径加 `_HD` 后缀
- **ChrRaces.dbc** —— 第 25、26 列（兽人从 25=1,26=1 改成 25=2,26=0）

详见 `13-模型补丁安装与BfA降版本.md` 第五节。

## 二、出问题的对照表

| 现象 | 最可能的原因 |
|---|---|
| **进游戏毫无变化** | **没删 Cache**（先查这个）|
| 只有部分种族变了 | 缺 DBC，或没打全 |
| 人物白模/无贴图 | Reload UI 导致 MPQ 没加载 → **重登** |
| 贴图错位（脸贴胳膊） | 贴图和模型不配套 |
| **直接崩溃** | MD21 格式，第 6 步应该拦住的 |
| 游戏起不来 | 字母冲突 → 你的包改名加下划线 |
| 达拉然报错 | 内存不足 → 4GB Patch（`ntcore.com/files/4gb_patch.zip`）|

**通用回退**：出任何问题，把 `patch-Y.MPQ` 改成 `patch-Y.MPQ_`，
客户端立刻恢复原样。**不用删文件，不用重装。**
