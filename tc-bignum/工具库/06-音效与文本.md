# 音效与文本工具

---

## 一、WoW 的音频格式

| 格式 | 用途 |
|---|---|
| **MP3** | 音乐（背景音乐、登录界面音乐）|
| **WAV** | 音效（技能、生物叫声、UI 音）|
| **OGG** | 部分音效 |

存放路径：

```
Sound/
├── Music/
│   ├── GlueScreenMusic/     登录界面音乐
│   ├── ZoneMusic/           区域音乐
│   ├── CityMusic/           城市音乐
│   └── ...
├── Creature/                生物叫声
│   └── <生物名>/
├── Spells/                  法术音效
├── Character/               角色语音
└── Interface/               UI 音效
```

## 二、【重要】两种替换方式

### 方式一：MPQ 补丁（标准做法）

打包进 `patch-4.MPQ`，路径和原文件一致。

```
patch-4.MPQ/
└── Sound/
    └── Music/
        └── GlueScreenMusic/
            └── WotLK_main_theme.mp3    ← 你的音乐，改成这个名字
```

### 方式二：Data\Sound 文件夹（更简单，官方支持）

**暴雪官方允许玩家替换音频**，客户端会先检查 `Data\Sound\` 目录：

```
World of Warcraft/
└── Data/
    └── Sound/
        └── Music/
            └── ZoneMusic/
                └── Dalaran/
                    └── DC_IntroUni01.mp3    ← 直接放这
```

**不用打包 MPQ，不用改 exe**。想还原就删掉文件。

> 这条对**音频**有效。模型、贴图、DBC 仍然需要 MPQ 或打过补丁的 exe。

## 三、格式限制（踩坑点）

WotLK Modding Wiki 明确写了：

> Please note that you **cannot rename .wav or .ogg files without converting
> them to .mp3 first**.

**换句话说**：不能简单改扩展名，必须真的转格式。

| 要替换的原文件 | 你的文件必须是 |
|---|---|
| `.mp3` | 真 MP3 |
| `.wav` | 真 WAV |
| `.ogg` | 真 OGG（或转成对应格式）|

**转换工具**：
- **Audacity**（免费，图形界面，够用）
- **ffmpeg**（命令行，批量转最快）

ffmpeg 批量转 MP3：
```bash
ffmpeg -i input.wav -codec:a libmp3lame -b:a 128k output.mp3
```

## 四、实战：换登录界面音乐

1. **找到原文件**
   MPQ Editor 打开 → `Sound\Music\GlueScreenMusic\`
   会看到四个 mp3：
   - `WotLK_main_theme.mp3` —— WotLK 登录音乐
   - `BC_main_theme.mp3` —— TBC
   - `wow_main_theme.mp3` —— 正传
   - （还有一个）

2. **准备你的音乐**，转成 MP3

3. **改名**成 `WotLK_main_theme.mp3`

4. **放进** `Data\Sound\Music\GlueScreenMusic\`
   （或打包进 patch-4.MPQ 的同路径）

5. 重启游戏

## 五、静音某个音效（实用技巧）

不想听某个生物的叫声？**不用做静音文件**，把它改名就行：

在 MPQ 里把 `IrSpider.wav` 改成 `IrNoSpider.wav` ——
游戏找不到文件就不播了。

> 这招在自定义 MPQ 里也能用：放一个同名的**空文件**或极短静音文件。

## 六、找音效文件路径

### 方法一：wow.export

Audio 标签，可以**直接预览播放**，找到了再导出。这是最方便的。

### 方法二：MPQ Editor

打开所有 MPQ，按路径浏览。缺点是不能试听。

### 方法三：社区音效列表

WoWInterface 上有完整的音效路径清单（搜 "WoW sound list"）。

## 七、文本与本地化

### 客户端文本

| 位置 | 内容 |
|---|---|
| `DBFilesClient\*.dbc` | 物品名、法术名、区域名等（在 DBC 里）|
| `Interface\FrameXML\*.lua` | 界面文本、Lua 脚本 |
| `Interface\FrameXML\GlobalStrings.lua` | **全局字符串表** |

**改界面文本**：改 `GlobalStrings.lua`，打包进 patch。

**改物品/法术名**：改对应 DBC（见 `04-DBC编辑器.md`）。

### 服务端文本（对你项目更相关）

| 表 | 内容 |
|---|---|
| `creature_template.name` / `subname` | NPC 名字 |
| `creature_template_locale` | NPC 名字本地化 |
| `item_template.name` | 物品名 |
| `item_template_locale` | 物品名本地化 |
| `npc_text` + **`npc_text_locale`** | 对话文本 |
| `gossip_menu_option` + `_locale` | 菜单选项 |
| `quest_template` + `_locale` | 任务文本 |
| `trinity_string` | 服务端系统消息 |

> **NPCBot 中文化**就是往 `npc_text_locale` 灌 427 条 zhCN 记录，
> 详见 `参考资料/NPCBot资料汇总与闲逛诊断.md`。

### 服务端消息中文化

`trinity_string` 表存所有 `.命令` 的反馈消息。
你自己写的指令用的是 `PSendSysMessage` 硬编码中文，不走这张表。

## 八、给你项目的建议

| 优先级 | 做什么 | 成本 |
|---|---|---|
| **高** | NPCBot 菜单中文化（427 条 SQL）| 低，纯 SQL |
| 中 | 换登录音乐做"你的服"的标识 | 极低，放个文件 |
| 中 | 自定义装备/法术的中文名 | 低，改 DBC 或服务端表 |
| 低 | 全套音效替换 | 高，工作量大 |

**登录音乐是性价比最高的** —— 五分钟的事，但玩家一进游戏就感觉"这是个用心的服"。
