# 贴图与纹理工具

---

## 一、BLP 是什么

WoW 所有图片都是 **BLP 格式**（Blizzard Picture）——暴雪自有格式，
Photoshop / GIMP 默认打不开。

用到的地方：
- `Interface\Icons\` —— 所有物品/法术图标
- 模型贴图 —— 生物、装备的皮肤
- UI 元素 —— 界面图片
- 登录界面、加载屏

**做自定义物品必然要碰它**（至少要做个图标）。

---

## 二、方案一：Photoshop BLP 插件（推荐）

**最省事的方案** —— 装了之后 Photoshop 能**直接打开和保存** BLP，
不用来回转格式。

### 安装

1. 下载 BLP 插件（论坛常见资源，搜 "Photoshop BLP plugin"）
2. 丢进 Photoshop 的插件目录：
   ```
   <Photoshop 安装目录>\Plug-ins\File Formats\
   ```
3. 重启 Photoshop

大多数 Photoshop 版本都能用。

### 用法

直接 File → Open 打开 .blp，改完 File → Save As 存成 .blp。

**注意保存参数**：
- 图标类：256 色带 alpha
- 模型贴图：看原图格式，别改分辨率

---

## 三、方案二：wow.export 转换（不装插件）

wow.export **导出贴图时自动转 PNG**，改完再转回 BLP。

### 导出

1. wow.export → Textures 标签
2. 搜索（如 `inv_sword`）
3. 选中 → Export（默认输出 PNG）

### 转回 BLP

wow.export 支持**拖拽转换**：把 PNG 拖到程序窗口上。

或者用专门的转换工具（见下）。

---

## 四、方案三：独立转换工具

| 工具 | 说明 |
|---|---|
| **BLPConverter** | 命令行，适合批量。BLP <-> PNG/TGA |
| **BLP Lab** | 图形界面，可预览 |
| **Wow BLP Converter** | 老工具，简单够用 |

**批量转换场景**：你要做一整套自定义图标时，命令行工具更快。

## 五、图标规范（做自定义物品图标必读）

WoW 图标的标准规格：

| 项 | 值 |
|---|---|
| 尺寸 | **64×64**（也有 32×32 的小图标）|
| 格式 | BLP，通常 DXT1 或 256 色调色板 |
| 命名 | `inv_<类型>_<名称>` 是惯例，非强制 |
| 路径 | `Interface\Icons\<图标名>.blp` |

### 做自定义图标最快的方法

1. wow.export 导一个**风格接近**的现成图标（PNG）
2. Photoshop 改色/加元素
3. 存成 BLP
4. 放进 `patch-4.MPQ\Interface\Icons\`
5. DBC 里 `InventoryIcon` 填图标名（**不带扩展名**）

**不要从零画** —— 用现成的改，风格才统一。

## 六、模型贴图（换装备/生物皮肤）

### 找到模型用的贴图

1. WMV 里选中模型，右侧面板能看到用了哪些贴图
2. 或者 wow.export 导出模型时勾选"一并导出贴图"

### 改色（最常见需求）

比如把一件蓝色装备改成红色：

1. 导出原贴图 PNG
2. Photoshop → 图像 → 调整 → **色相/饱和度**，拖色相滑块
3. 存回 BLP
4. **改名**（不要覆盖原文件，否则所有用这贴图的都变色）
5. DBC 的 `ModelTexture_1` 指向新贴图名

### 常见故障

| 现象 | 原因 |
|---|---|
| 模型变**纯绿** | 贴图路径/名字错，游戏找不到 |
| 模型变**方格** | 同上，或贴图格式不对 |
| 贴图错位 | UV 不匹配，你改了尺寸 |
| 半透明处发黑 | alpha 通道丢了 |

## 八、给你项目的具体建议

你现在有 **entry 800000-899999 的自造装备**。如果想给它们做专属外观：

**最小成本方案**（不做新模型，只改图标）：
1. wow.export 导 20 个风格接近的图标
2. Photoshop 批量改色，做出一套"你的服专属"配色
3. 打包进 patch
4. `ItemDisplayInfo.dbc` 里指向新图标

这样装备一眼就能看出是自定义的，而且工作量很小。

**进阶方案**（改模型贴图）：
挑几件顶级装备，改贴图颜色做成"传说品质"专属外观。
