> 日期：2026-07-31
> 起因：用户四连问 —— 种族上限、补丁不生效、exe 换不了、两个补丁能否融合

---

## 问题一：补丁不生效 —— 【最可能是这个原因】

### 你可能踩了 locale 目录优先级的坑

MPQ 加载优先级有一条**很多人不知道的规则**：

```
Data\<locale>\  【整体】优先于  Data\
```

**注意"整体"两个字。** 这不是按字母比，是**整个目录压过整个目录**：

```
Data\zhCN\patch-zhCN-4.MPQ     ← 优先级【高】
        ↑ 压过 ↑
Data\patch-Z.MPQ               ← 优先级【低】，哪怕字母是 Z
```

### 这意味着什么

如果你的 HD 人物模型包装在 **`Data\zhCN\`** 里，
而你把裸补丁放在 **`Data\`** 里 ——

**无论你用什么字母，都会被 zhCN 里的包盖掉。** 用 `patch-Z.MPQ` 也没用。

### 怎么确认

```bash
bash 工具库/tools/client_check.sh "/d/你的魔兽目录"
```

看第 4 段，脚本会**分别**列出 `Data\` 和 `Data\zhCN\` 两组字母占用图。

如果 `Data\zhCN\` 那组里有占用的字母，用 MPQ Editor 打开看看
有没有 `Character\` 开头的内容。**有的话就是它盖了你的补丁。**

### 解法

**把你的补丁也放进 locale 目录，用更靠后的字母**：

```
Data\zhCN\patch-zhCN-Z.MPQ
```

这是全客户端**优先级最高**的位置，没有任何东西能盖过它。

> 注意命名格式：locale 目录里是 `patch-<locale>-<字母>.MPQ`，
> 中间要带 `zhCN`，不是 `patch-Z.MPQ`。

## 问题一之二：内衣是独立几何体（geoset），换贴图没用

你的判断**方向是对的**，但机制比你想的更麻烦。

### 原版模型 vs HD 模型的区别

| | 3.3.5 原版模型 | WoD/Legion HD 模型 |
|---|---|---|
| 内衣怎么实现 | **画在皮肤贴图上** | **独立的几何体(geoset)** |
| 去掉内衣的办法 | **换贴图就行** | **必须改模型或 skin 文件** |

**这就是为什么高版本的裸补丁必须带 `.m2` 和 `.skin`** ——
它要关掉那几个内衣 geoset，光换贴图关不掉。

### 对你补丁的判断

你的补丁只有 **3 个 m2**，而且全是熊猫人/恶魔猎手（3.3.5 没有的）。
**说明它没有覆盖任何 3.3.5 种族的模型。**

两种可能：

| 可能 | 说明 | 结果 |
|---|---|---|
| A. 贴图是给**原版模型**做的 | 内衣画在贴图上，换贴图就能去掉 | **能用**，问题在优先级 |
| B. 贴图是给 **HD 模型**做的，但作者假设你已装带 geoset 修改的 HD 包 | 需要配套的 m2/skin | **缺件**，光有贴图不够 |

**跑这个能确定**：

```bash
python 工具库/tools/texplan.py "D:/r18/ralia-nude-patch"
```

看第 2 段的 `_HD` 统计。

## 问题二：能不能把 PNG 塞进 HD 补丁

### 两个纠正

**纠正 1：PNG 不行，游戏不认。**

WoW 客户端只认 **BLP** 和 **TGA**，**不读 PNG**。
（WoWInterface 论坛原话：客户端能识别 PNG 文件，但**没实现**把它当贴图读。）

你要塞的话必须先转成 BLP。不过你的补丁**本来就是 693 个 BLP**，
直接用就行，不用转。

**纠正 2：不需要"融合进 HD 补丁"，用优先级就够了。**

这是关键 —— **你想做的"融合"，MPQ 机制天生就支持**：

```
Data\zhCN\patch-zhCN-W.MPQ    HD 模型包（作者的）
Data\zhCN\patch-zhCN-Z.MPQ    你的裸贴图    ← 字母更后，自动覆盖
```

**两个包共存，Z 里有的用 Z 的，Z 里没有的用 W 的。**
这就是"融合"，而且**不用动别人的包**。

### 为什么不建议直接改 HD 包

| 做法 | 问题 |
|---|---|
| 把文件塞进别人的 HD MPQ | 改坏了没法还原，得重新下载几个 G |
| 用更高字母的独立包 | **随时改名禁用，零风险** |

**除非**你发现 HD 包在 locale 目录而你没法用更高字母
（比如 Z 已经被占了），才需要考虑合并。

## 问题三：exe 换不了 —— zhCN 客户端不能用 enUS 的 exe

### 你遇到的现象是正常的，不是你操作错了

**证据**：官方指纹表（`anzz1/wow-client-checksums`）里，
3.3.5.12340 的 `Wow.exe` 有七个语种共用**同一个** MD5：

```
deDE / enGB / enUS / esES / esMX / frFR / ruRU
MD5: 45892bdedd0ad70aed4ccd22d9fb5984
```

**但这张表里【没有 zhCN 和 zhTW】。**

这说明：**中文版的 exe 和欧美版本来就不是同一个二进制。**

原因：中文版由不同代理商（第九城市/网易）发行，
内容有本地化改动（骷髅模型换成非骨骼、去血等），exe 也跟着不同。

### 所以

| 你做的 | 结果 |
|---|---|
| 拿 enUS 的干净 exe 替换 zhCN 客户端的 | **报客户端损坏，正常现象** |
| 拿 patcher 打你现有的 zhCN exe | **报 corrupt，因为整合包作者改过** |

**两条路都堵死了 —— 但这不重要。**

### 关键：你根本不需要打这个 exe 补丁

回到 `00` 篇的勘误：

> **原版 exe 本来就能加载 `patch-X.MPQ` 真文件。**
> 打补丁的 exe 只多给三个特性：文件夹补丁 / 自定义物品图标 / 改 Interface。

**装模型贴图补丁，一个都用不上。**

### 如果以后真的需要

只有两条路：

| 方案 | 说明 | 难度 |
|---|---|---|
| **找 zhCN 专用的打好补丁的 exe** | 中文魔改圈有人做，但不好找 | 中 |
| **换成 enUS 整客户端** | 不是只换 exe，**是换整个客户端**（含 Data\enUS）| 大 |

**第二条要注意**：换客户端会丢掉你现在的中文界面和中文语音。
而且你的服务端是 zhCN 汉化的（`npc_text_locale` 那 427 条），
客户端换成 enUS 后**服务端发的中文文本还是中文**，但界面变英文，会很割裂。

**我的建议：这条线先放弃。** 收益（文件夹补丁的开发便利）
远小于成本（客户端换语种）。

## 问题四：两个补丁能"融合"吗

**能，而且不用做任何特殊操作 —— 这就是 MPQ 的原生行为。**

### 机制

客户端找一个文件时：

```
按优先级从高到低查，第一个找到的就用，找到就停。
```

所以：

```
patch-zhCN-Z.MPQ  有 HumanFemaleSkin00_00.blp  → 用这个
patch-zhCN-W.MPQ  也有                          → 忽略
patch-zhCN-W.MPQ  有 HumanFemale.m2             → Z 里没有，用 W 的
```

**结果就是：你的贴图 + 他的模型，自动融合。**

### 文件夹补丁能不能混用

可以。**文件和文件夹在优先级上是平等的**，都按字母排：

```
Data\zhCN\patch-zhCN-W.MPQ     ← 文件
Data\zhCN\patch-zhCN-Z.MPQ\    ← 文件夹（需要打过补丁的 exe）
```

但你的 exe 打不了补丁，**文件夹方式用不了**，老老实实打包 MPQ。
