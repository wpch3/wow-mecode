# 你这个补丁的处置方案（ralia-nude-patch）

> 分析日期：2026-07-31
> 数据来源：用户实跑 `patch_scan.py` 的输出

---

## 一、先看清楚：这不是"全种族模型包"

体检数据：

```
.m2   模型   : 3          <- 只有 3 个
.skin 网格   : 16
.blp  贴图   : 693        <- 主体是这个
```

**3 个模型 vs 693 个贴图 —— 这是一个【贴图补丁】，不是模型包。**

它替换的是**皮肤纹理**，不是人物的多边形网格。这跟我之前假设的
"BfA 全种族模型移植"是两回事，处置方式完全不同。

---

## 二、【关键发现】那 3 个模型全都是废件

看名字：

| 模型 | 是什么 | 3.3.5 有吗 |
|---|---|---|
| `pandarenfemale.m2` | 熊猫人女性 | **没有**，MoP 5.0 才加的种族 |
| `demonhuntergeosets_be_f.m2` | 血精灵恶魔猎手部件 | **没有**，Legion 7.0 才加的职业 |
| `demonhuntergeosets_ni_f.m2` | 暗夜精灵恶魔猎手部件 | **没有**，同上 |

**三个全都是 3.3.5 里根本不存在的种族/职业。**

### 这意味着什么

回到你上一个问题的答案：**客户端是按需索取的**。

3.3.5 的客户端：
- 没有熊猫人这个种族，**永远不会去请求** `pandarenfemale.m2`
- 没有恶魔猎手这个职业，**永远不会去请求** `demonhuntergeosets_*`

所以这三个 MD21 格式的文件，**放着也不会被加载，删掉也毫无影响**。

**「不能直接用」这个结论，对你的实际使用场景是【误报】。**
脚本按通用规则判的，没考虑"这些模型压根用不上"。

> 我已经写了新脚本 `texplan.py` 专门处理这种情况。

## 三、真正决定成败的是另一件事

**693 个贴图，是给【原版模型】做的，还是给【HD 模型】做的？**

这决定了你装上去有没有效果：

| 贴图类型 | 文件名特征 | 前提条件 |
|---|---|---|
| 给**原版模型** | `HumanFemaleSkin00_00.blp` | **无**，直接装 |
| 给 **HD 模型** | `HumanFemaleSkin00_00_HD.blp` | **必须先装 WoD/Legion 人物模型包** |

**为什么关键**：HD 模型和原版模型的 UV 展开不一样。
给 HD 做的贴图贴到原版模型上，会**错位或根本不显示**。

### 怎么查

```bash
python 工具库/tools/texplan.py "D:/r18/ralia-nude-patch"
```

看第 2 段的输出：

```
  含 _HD 后缀 : 516 个
  不含 _HD    : 177 个

  >> 这是给【HD 模型】(WoD/Legion 移植版) 做的贴图
     必须【先装 HD 人物模型包】，否则贴图无处可贴。
```

### 三种结果

| 输出 | 含义 |
|---|---|
| **不含 _HD 占多数** | 给原版模型做的，**直接装，最省事** |
| **含 _HD 占多数** | **必须先装 HD 人物模型包**，否则白装 |
| 混合 | 两套都覆盖了，装不装 HD 包都能用 |

> **补充判据**：那三个废模型是 BfA (v274) 格式，说明作者的工作环境是高版本，
> 贴图**大概率也是给 HD 模型做的**。但以脚本实测为准。

## 四、安装步骤

### 第 1 步：删掉那三个废模型和对应的 skin

```
删除：
  Character\Pandaren\Female\pandarenfemale.m2
  Character\Pandaren\Female\pandarenfemale*.skin
  Character\...\demonhuntergeosets_be_f.m2
  Character\...\demonhuntergeosets_be_f*.skin
  Character\...\demonhuntergeosets_ni_f.m2
  Character\...\demonhuntergeosets_ni_f*.skin
```

`texplan.py` 会把完整路径列给你，照着删。

**删了不影响任何东西** —— 3.3.5 里这些种族/职业根本不存在。

> 也可以不删（客户端会忽略），但删掉更干净，包也更小，
> 而且避免以后自己看到 MD21 又困惑。

### 第 2 步：确认 HD 模型前提

如果 `texplan.py` 说是给 HD 模型做的：

```bash
# 查你的客户端有没有装 HD 人物模型包
bash 工具库/tools/client_check.sh "/d/你的魔兽目录"
```

然后用 MPQ Editor 打开现有的 `patch-*.MPQ`，看有没有
`Character\Human\Female\HumanFemale_HD.m2` 这类文件。

| 有 | 没有 |
|---|---|
| 前提满足，继续 | **先装 HD 模型包**，否则这个补丁装了没效果 |

### 第 3 步：定位打包根目录

```bash
bash 工具库/tools/findroot.sh "/d/r18/ralia-nude-patch"
```

### 第 4 步：打包

```
MPQ Editor -> MPQs -> New MPQ
  命名 patch-Y（用 client_check.sh 给的字母）
  勾 "Build the MPQ archive from a file or directory"
  选 findroot.sh 给的目录
  Game Compatibility 改成 World of Warcraft
  Next -> Next -> Finish
```

### 第 5 步：装 + 删缓存

```
复制 patch-Y.MPQ 到 <客户端>\Data\
删掉 <客户端>\Cache\ 整个文件夹
进游戏
```

## 五、关于你说的"单个补丁不行，他只认目录的文件"

你第一次跑脚本给的是这个路径：

```
/c/Users/Administrator/Downloads/Compressed/1
```

结果 `其他: 1`，说明那个目录里**只有 1 个文件**，
大概率是**还没解压的压缩包本身**（`.rar` / `.7z` / `.zip`）。

**脚本读的是解压后的文件，不会自动解压。**

正确做法：
```
1. 先用 7-Zip / WinRAR 解压
2. 再把【解压出来的文件夹】路径给脚本
```

你第二次给 `D:/r18/ralia-nude-patch` 就对了，读出了 693 个 BLP。

## 六、贴图编码检查（顺带确认）

```
DXT / DXT1   417 个
DXT / DXT3   210 个
DXT / DXT5    66 个
```

**全部是 3.3.5 支持的编码**：
- 没有 BC5（DX10 格式，3.3.5 读不了）
- 没有非 2 的幂尺寸
- 没有超大贴图警告

**贴图这部分零问题，可以直接用。**

## 七、总结

| 项 | 状态 |
|---|---|
| 693 个贴图编码 | **全部合法**，直接可用 |
| 3 个 MD21 模型 | **全是 3.3.5 不存在的种族/职业，删掉即可** |
| 16 个 skin | 属于那 3 个模型，一起删 |
| **HD 模型前提** | **要查**，决定装了有没有效果 |
| DBC | 没有，不用担心 |

**结论：这个补丁能用，删三个废文件就行。
唯一要确认的是你的客户端有没有装 HD 人物模型包。**

## 八、脚本更新说明

新增 `工具库/tools/texplan.py`，专门处理贴图类补丁：

- 识别 **3.3.5 不存在的种族/职业**（内置 15 种：熊猫人、狼人、恶魔猎手、
  夜之子、至高岭、光铸、虚空精灵、黑铁、玛格汉、赞达拉、库尔提拉斯、
  机械侏儒、沃姆斯、龙希尔等），标记为"可直接删除"
- 自动关联要删的 `.skin`
- **判断贴图是给原版模型还是 HD 模型做的**
- 按种族统计覆盖范围
- 给出具体安装步骤

**它不会把该保留的说成可删** —— 如果是人类、暗夜精灵这些 3.3.5 有的种族
的模型格式不兼容，它会明确说"不能简单删掉"。
