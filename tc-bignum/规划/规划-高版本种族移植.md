## 一、先纠正我之前说的"编号有上限"

我之前说得含糊。查证后的准确情况：

### 上限不是一个，是四个，分布在四个地方

| 上限 | 位置 | 原始值 | 能改吗 |
|---|---|---|---|
| **服务端枚举** | `SharedDefines.h` 的 `enum Races` | 到 11 (德莱尼) | **能**，改源码 |
| **服务端 MAX_RACES** | `SharedDefines.h` | 12 | **能**，改源码 |
| **客户端 Lua** | `CharacterCreate.lua` 的 `MAX_RACES` | 10 | **能**，改 MPQ 里的 Lua |
| **客户端 exe 硬编码** | `Wow.exe` 二进制 | **约 20** | **难**，要 hex 改 exe |

### 关键：3.3.5 其实预留了种族槽位

`SharedDefines.h` 里这些是**注释掉的，不是不存在**：

```cpp
RACE_GOBLIN             = 9,
RACE_BLOODELF           = 10,
RACE_DRAENEI            = 11,
//RACE_FEL_ORC          = 12,
//RACE_NAGA             = 13,
//RACE_BROKEN           = 14,
//RACE_SKELETON         = 15,
//RACE_VRYKUL           = 16,
//RACE_TUSKARR          = 17,
//RACE_FOREST_TROLL     = 18,
//RACE_TAUNKA           = 19,
//RACE_NORTHREND_SKELETON = 20,
//RACE_ICE_TROLL        = 21
```

**12-21 这十个槽位是暴雪自己留的**，模型和骨骼客户端里就有。
去掉注释就能用，**不需要动 exe**。

这是**成本最低的一批** —— 娜迦、破碎者、维库人、海象人、
森林巨魔、牦牛人、冰霜巨魔，共 10 个。

### 超过 21 之后

要改 `Wow.exe`。wowmodding.net 上有人卖
"32 races limited unlock" 的改好 exe，说明：

- **技术上可行**，上限能推到 32
- **但要改 exe** —— 而你的 zhCN exe 改不了（见 `18` 篇）

**所以对你来说，现实的天花板是 21 号种族，共 10 个新槽位。**

## 二、加一个种族要改多少东西（完整清单）

这是我为什么建议**先做主线**的原因 —— 工作量比想象大。

### A. 服务端源码（3 处）

```
src/server/game/Miscellaneous/SharedDefines.h
  1. enum Races           取消对应种族的注释
  2. MAX_RACES            改成 最大种族号 + 1
  3. RACEMASK_ALL_PLAYABLE 把新种族加进位掩码
```

**改完要重编译。** 你的 `D:\TC-Build` 全量编译一次的时间要算进去。

### B. 客户端 DBC（5 张表）

| DBC | 改什么 |
|---|---|
| `ChrRaces.dbc` | 加一行：种族 ID、名字、模型 ID、派系 |
| `CharBaseInfo.dbc` | 种族-职业对应表，决定这个种族能玩什么职业 |
| `CharStartOutfit.dbc` | 初始装备（男女各一行）|
| `CharSections.dbc` | 脸/发型/肤色的贴图路径 |
| `CharHairGeosets.dbc` | 发型几何体 |

**用 WDBX Editor（批次 3）。**

### C. 客户端 Lua/XML（3 个文件）

```
Interface\GlueXML\CharacterCreate.lua   MAX_RACES 数字 + RACE_ICON_TCOORDS 图标坐标
Interface\GlueXML\CharacterCreate.xml   加种族按钮
Interface\GlueXML\GlueStrings.lua       种族名称字符串（这里要写中文）
```

**注意**：改 Interface 文件**需要打过补丁的 exe**（Allow Interface Edits）。
你的 exe 打不了 —— **这是个卡点**，见第四节。

### D. 客户端贴图（1 个）

```
Interface\GLUES\CHARACTERCREATE\UI-CHARACTERCREATE-RACES.blp
```
角色创建界面的种族头像图集，要 P 上新种族的图标。

### E. 数据库（6 张表）

```
playercreateinfo              出生点、初始状态
playercreateinfo_item         初始物品
playercreateinfo_spell_custom 初始法术
playercreateinfo_action       初始动作条
player_levelstats             1-80 级各项属性  ← 数据量最大
player_classlevelstats        职业成长
```

**`player_levelstats` 一个种族 × 10 职业 × 80 级 = 800 行**，
一般是复制现有种族的数据改 race 字段。

## 四、你的 zhCN exe 是个卡点

> **【状态更新 2026-07-31】用户自己找到了一个能用的补丁 exe。**
> **如果它带 Allow Interface Edits，本节的卡点就不存在了，**
> **方案 C（.race 变通）可以降级为备选。**
> **测法见 `工具库/19-补丁exe到底给了你什么.md` 的测试 B。**

批次 A/B 里有两件事要改 Interface：

- `CharacterCreate.lua` 的 `MAX_RACES`
- `CharacterCreate.xml` 的种族按钮

**改 Interface 文件需要 "Allow Interface Edits" 补丁的 exe。**

### 三条路

| 方案 | 说明 | 评价 |
|---|---|---|
| A. 找 zhCN 版打好补丁的 exe | 中文魔改圈有，不好找 | **首选，继续找** |
| B. 换 enUS 整客户端 | 丢中文界面和语音 | 成本高 |
| C. **不改 Interface** | 种族能创建但**创建界面看不到按钮** | 见下 |

### 方案 C 的变通

**不改 Lua，改用 GM 指令改种族。**

玩家先创建一个普通种族，然后：
```
.character changerace   （或自己写个 .race 指令）
```

**优点**：完全绕过客户端 Interface 限制
**缺点**：不能在创建界面直接选

**这条路对你其实挺合适** —— 你本来就在做 GM 指令工具链，
加一条 `.race` 指令是熟练活。

## 五、和主线的关系

**这个项目和 `.emote` / `.say` 完全无关，不要交叉做。**

建议排序：

```
1. 剧情工具链（.emote / .say / .follow / ...）   ← 当前主线
2. NPCBot 中文化（427 条 SQL，零风险）
3. NPCBot 数量扩容
4. 【本项目】批次 A：跑通 1 个种族
5. 【本项目】批次 B：补齐 12-21
6. 客户端改造批次（血量 int64 等）
```

**理由**：种族移植要改源码 + 重编译 + 改 DBC + 改 SQL + 可能改 exe，
是目前所有待办里**跨度最大**的一个。主线没稳之前不适合开这个头。

## 六、立项前要先确认的三件事

| 待确认 | 怎么查 | 影响 |
|---|---|---|
| zhCN 版打好补丁的 exe 存不存在 | 中文魔改论坛搜 | 决定能不能改 Interface |
| 你的整合客户端有没有动过 GlueXML | MPQ Editor 看现有补丁 | 可能已经有人改过 MAX_RACES |
| 客户端里那 10 个预留种族的模型完整度 | WoW Model Viewer 逐个看 | 有些可能缺动画 |

**第三条特别重要**：预留种族虽然模型在，但**未必有全套动画**
（比如坐下、施法、游泳）。缺动画的种族玩起来会很怪。

**WMV（批次 5）就是查这个用的。**
