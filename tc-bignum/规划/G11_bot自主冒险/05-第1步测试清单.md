## 测试2：满足索要有奖励（重点，还没测）

这是第1步的另一半，**你还没测过**。

### 步骤

```text
1. 等 pbot 索要食物（聊天框出现"我有点饿了..."）
2. 【10分钟内】给它食物
   - PlayerBot：跟它交易，放食物进去
   - NPCBot：右键 -> 赠予物品 -> 选食物
3. 立刻查数据库
```

### 查询1：索要被标记为已满足

```sql
SELECT id, bot_id, bot_kind, request_type, ask_time, answered, answer_time
FROM `characters`.`npcbot_request_log`
ORDER BY id DESC LIMIT 5;
```

**预期**：最新那条 `answered` 从 **0 变成 1**，`answer_time` 有值。

### 查询2：多加了 15 分

```sql
SELECT bot_id, bot_kind, bond_level, bond_points, gift_points, requests_met
FROM `characters`.`npcbot_bond`;
```

**预期**：
- `requests_met` **+1**
- `gift_points` 比平时多 **15**

### 怎么知道"比平时多15"

做个对照：

```text
A. 先在【没有索要】的时候给一次食物，记下 gift_points 增加了多少
   （食物基础分 2，不需要时不翻倍，所以大概 +2）

B. 等它索要食物，再给一次
   （2 + 15 = 17）
```

**差值 15 就对了。**

## 快速验证脚本

一次看全部状态：

```sql
SELECT '=== 1.主键 ===' AS `项`;
SELECT COLUMN_NAME FROM `information_schema`.`STATISTICS`
WHERE TABLE_SCHEMA='characters' AND TABLE_NAME='npcbot_bond' AND INDEX_NAME='PRIMARY'
ORDER BY SEQ_IN_INDEX;

SELECT '=== 2.索要记录 ===' AS `项`;
SELECT id, bot_id, bot_kind, request_type, answered, answer_time
FROM `characters`.`npcbot_request_log` ORDER BY id DESC LIMIT 10;

SELECT '=== 3.羁绊 ===' AS `项`;
SELECT bot_id, bot_kind, bond_level, bond_points, gift_points,
       gifts_to_bot, requests_met
FROM `characters`.`npcbot_bond`;

SELECT '=== 4.满足率 ===' AS `项`;
SELECT
    COUNT(*) AS `总索要次数`,
    SUM(CASE WHEN answered=1 THEN 1 ELSE 0 END) AS `被满足次数`,
    SUM(CASE WHEN answered=0 THEN 1 ELSE 0 END) AS `没理它`
FROM `characters`.`npcbot_request_log`;
```
