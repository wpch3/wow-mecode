```cpp
// G19第3步：算出 bot 当前所处的场景类别
//   0=未知 1=副本 2=团本 3=主城 4=小镇 5=野外 6=战场 7=圣所
//   用 FindMap()(Object.h:468 无断言) 而不是 GetMap()(Object.h:467 有 ASSERT)
uint8 bot_ai::GetCurrentScene() const
{
    Map const* map = me->FindMap();
    if (!map)
        return 0;

    if (map->IsBattlegroundOrArena())
        return 6;
    if (map->IsRaid())
        return 2;
    if (map->IsDungeon())
        return 1;

    if (AreaTableEntry const* area = sAreaTableStore.LookupEntry(me->GetAreaId()))
    {
        if (area->Flags & AREA_FLAG_CAPITAL)    return 3;
        if (area->Flags & AREA_FLAG_SANCTUARY)  return 7;
        if (area->Flags & AREA_FLAG_TOWN)       return 4;
    }
    return 5;
}
```

## 我的两条教训（已入坑表）

`18796` 那个 `}` 缩进 4 空格，在编辑器里和顶格的 `}` **肉眼几乎一样**。
应该直接给命令让用户定位：


`PickGiftText` 包含子串 `PickText`，搜索会一并命中。
