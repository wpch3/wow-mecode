## 一、先厘清一个概念错误

### Arctium 不是服务端，是启动器

`github.com/Arctium/WoW-Launcher` 的自我定位原文：

> A game launcher for World of Warcraft that **allows you to connect to custom servers**.

**它做的事只有一件**：改内存，让**正式版客户端**能连非官方服务器
（绕过 Blizzard 的证书校验和 portal 锁定）。

**它不提供**：世界逻辑、生物 AI、任务、副本、掉落、战斗计算 —— 一样都没有。

正确的关系是：

```
正式客户端  →  Arctium 启动器（让它能连）  →  真正的服务端
                                              ↑
                                    TrinityCore master / CypherCore
```

**你要的服务端还得是 TrinityCore 或 CypherCore。**

### 支持的客户端版本（README 实录）

| 分支 | 最低 | 最高 |
|---|---|---|
| Mainline（正式服）| 10.1.5 | **12.0.5** |
| Classic Era | 1.14.4 | * |
| Classic | 3.4.2 | 5.5.3 |

**注意**：这里的 Classic 3.4.2 是 **WotLK Classic**，
和你的 **3.3.5a (12340)** 不是一回事，两者客户端不通用。

## 二、换到 12.x 意味着什么 —— 三个致命问题

### 问题 1：NPCBot 永久没有，作者明确拒绝

这是**最硬的一条**。

NPCBot 作者 trickerer 在自己仓库 issue 里的原话（2023，俄语）：

> Было это давно, в конце концов пришлось дропнуть, так как не было возможности их поддерживать.
> С тех пор мало что изменилось, **никакими другими версиями кроме 3.3.5 я заниматься не планирую**

翻译：
> 那是很久以前的事了，最后不得不放弃，因为没能力维护。
> 从那以后没什么变化，**除了 3.3.5 之外我不打算做任何其他版本**。

仓库标题也写死了：**「NPCBots for TrinityCore and AzerothCore 3.3.5」**

**这意味着**：
- 你的 370 个 bot 模板、5098 个闲逛路径点 —— **全部作废**
- `规划-NPCBot增强总蓝图.md` 整个方案 —— **作废**
- playerbot 同理，也只有 3.3.5 / AzerothCore

**你说过"我在 playerbot 都是 1000 个 bot 起步"** ——
换版本之后，**一个都没有**。

### 问题 2：master 分支内容严重缺失

TrinityCore 官方 wiki 自己写的：

| 分支 | 官方描述 |
|---|---|
| **3.3.5** | targeting original 2010 wow 3.3.5a，**best for starters** |
| **master** | usually targeting current retail version. **a lot of missing content** |

> It is absolutely normal to have no content, remember **master branch is experimental**,
> if you wanna play something stable **use 3.3.5 branch instead**

生物 AI 在 master 上根本没实现。你会得到一个**能跑但空荡荡**的世界。

## 三、但你的诉求是合理的 —— 换个方式满足

回头看你**真正想要什么**：

| 你想要的 | 3.3.5 能不能给 |
|---|---|
| 高版本的**人物模型**（好看）| **能** —— HD 模型包移植成熟 |
| 高版本的**种族** | **部分能** —— 12-21 十个预留槽位免费 |
| 高版本的**坐骑/生物模型** | **能** —— Finsternis 等包 |
| 高版本的**地图**（如库尔提拉斯）| 难，要 Noggit + 重提 mmaps |
| 高版本的**职业机制**（恶魔猎手等）| 难，要写全套技能 |
| 正式服的**完整内容** | **不能** —— 但 master 也给不了 |

**关键发现**：你实际在追求的是**视觉层面的现代化**，
而这**恰恰是 3.3.5 移植做得最成熟的部分**。

而换到 12.x 你会得到：完整的现代视觉 + **空荡荡的世界** + **没有 bot** + **一切重来**。

## 五、还有一个技术障碍：客户端改造难度剧增

| | 3.3.5 | 现代版本 |
|---|---|---|
| 数据格式 | **MPQ** | **CASC** |
| 加自定义文件 | 丢个 `patch-Y.MPQ` 就行 | 要 Arctium 的**文件映射**机制 |
| 工具成熟度 | 十几年积累，遍地教程 | 少，且经常因版本更新失效 |
| DBC/DB2 | 简单定长表 | 复杂，稀疏表、外部 ID |

Arctium 的自定义文件加载要这样配：

```
mappings/  放 fileId;filePath 映射表
files/     放你的自定义文件
```

**要用 FileDataID（纯数字）而不是路径**，
而 FileDataID 要从社区 listfile 查。比 MPQ 麻烦一个数量级。

**你刚在 3.3.5 上折腾 MPQ 优先级就卡住了** ——
CASC 只会更难。

**留在 3.3.5，理由按重要性排：**

1. **NPCBot 作者明确永不支持其他版本** —— 这是不可逆的、无替代方案的损失
2. **master 分支官方自己说 "a lot of missing content"** —— 换过去内容更少
3. **4000+ 行代码成果作废**，且要在每天变动的代码基上重写
4. **你要的视觉现代化，3.3.5 移植方案很成熟**
5. **客户端魔改难度从 MPQ 跳到 CASC**，你现在的工具链全部失效

**你想玩最新版的话，用你已有的 12.x repack 直接玩，别在上面魔改。**
