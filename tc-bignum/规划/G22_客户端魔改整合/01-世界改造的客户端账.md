## 一、先分清：哪些不用动客户端，哪些必须动

这是整个方案的**成本分水岭**。

| 改造内容 | 客户端 | 为什么 |
|---|---|---|
| NPC 进驻、守卫刷新 | **不用** | `creature` 表，服务端下发 |
| 相位切换（废墟/建成） | **不用** | `phaseMask` 是 3.3.5 原生 |
| 进度公告、指令、任务 | **不用** | 纯服务端 |
| 放置**已有**的建筑模型 | **不用** | `gameobject` 表引用客户端已有的 M2/WMO |
| **移除**废墟建筑 | **必须动** | 废墟是地图 ADT 的一部分，不是可删的对象 |
| **地形改造**（填坑、铺路） | **必须动** | ADT 高度图在客户端 |
| **新建筑模型** | **必须动** | 客户端没有就显示不出来 |
| 新地图（时间线副本） | **必须动** | 要新 ADT + Map.dbc |

**关键结论**：

```
「往废墟里【加】东西」   -> 纯服务端能做
「把废墟【变】完好」     -> 必须动客户端
```

## 二、这决定了 G20 的实现路线要改

### 2.1 原方案的问题

我在 `G20/01-总体设计.md` 里写「建筑模型逐步替换」，
**当时没意识到那要改 ADT**。洛丹伦废墟的断壁残垣是**地形数据的一部分**，
服务端删不掉。

### 2.2 修正后的三条路线

| 路线 | 做法 | 客户端 | 成本 | 效果 |
|---|---|---|---|---|
| **路线1 遮蔽式** | 在废墟上**盖新建筑**遮住 | **不用** | 低 | 能看，但穿帮 |
| **路线2 换地** | 在废墟**旁边**建新城 | **不用** | 低 | 合理（"重建在旧址旁"） |
| **路线3 真改地形** | Noggit 改 ADT + MPQ 补丁 | **必须** | 高 | 完美 |

### 2.3 我的建议：路线2 起步，路线3 收尾

**路线2「在旧址旁重建」在叙事上完全说得通**：

```
洛丹伦王城废墟保留（作为纪念/警示）
在它旁边的平地上建"新洛丹伦"
玩家看到的是：断壁残垣旁边，一座新城拔地而起
```

**这比"废墟凭空变完好"更有味道**，而且**零客户端改动**。

等玩法验证好玩了，再用路线3 做真正的地形改造。

## 三、时间线玩法的客户端账

### 3.1 三种实现，成本差 10 倍

| 方案 | 客户端 | 说明 |
|---|---|---|
| **A. 相位（phase）** | **不用** | 同一地图，切 phaseMask 换 NPC/建筑 |
| **B. 复制现有副本地图** | 不用 | 用现成副本地图当"时间线容器" |
| **C. 新建地图** | **必须** | 新 ADT + Map.dbc + MPQ |

### 3.2 你的"渴魔症精灵"用方案A 就够

```
银月城周边（zone 3430 永歌森林 / 3431 银月城）
  phase 1  正常时间线
  phase 2  渴魔症时间线
           - 换掉 NPC（血精灵变成魔瘾失控状态）
           - 加新怪物（吸取魔力的畸变体）
           - 换 gossip 文本
```

**全部是 SQL，零客户端改动。**

进入方式：找一个 NPC 对话 -> `SetPhaseMask(2)` -> 眼前的世界变了。

> **实证**：`phaseMask` 在 3.3.5 是原生机制，
> 客户端只是"看不到不同 phase 的对象"，不需要任何补丁。

## 五、和现有客户端改造线的关系

工作区已有的客户端线（`工具库/` 25篇 + 3份规划）：

```
规划-数值天花板与客户端改造.md      大数值的客户端限制
```

**G22（本文档）补上第4条：世界地形改造。**

### 现有结论仍然有效

`规划-突破上限后续阶段与客户端兼容性.md` 的核心判断：

> 现有 patch 95%+ 是纯服务端逻辑，不受客户端魔改影响。
> **真正的风险是客户端MPQ和服务端DBC不一致**，必须同一套。

**这条对 G20/G22 同样适用** —— 如果做路线3，
服务端 `dbc/` 目录和客户端 `Data/` 里的 MPQ 必须同步更新。

## 七、一个重要提醒：客户端补丁的分发问题

如果走路线3，你要面对：

```
玩家（哪怕只有你自己）必须装 patch-X.MPQ
  -> 每次改地形都要重新分发
  -> 服务端 DBC 和客户端 MPQ 版本必须严格对应
  -> 版本错位 = 掉线/看不到建筑/坐标错乱
```

**建议**：如果做，**一次做完再发布**，不要边玩边改。
