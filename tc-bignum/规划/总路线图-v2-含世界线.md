## 一、项目的真实全貌：三条线，不是一条

```
主线 · 真龙史诗（剧情/ 目录，三线并行架构）
   ├─ 天意线（真龙）      11章 30%
   ├─ 尘世线（部落联盟）  篇幅最大
   └─ 噩梦线（世界自身）
        ↑ 这是【故事】，写完了但玩家参与不进去

支撑它的两条【可玩】线：
   A. bot 线      —— 陪你玩的人像不像
   B. 世界线      —— 有什么可玩（G20）
```

**我之前的错误**：只做 A 线，把 B 线当"额外想法"。
实际上**主线要落地，必须靠 B 线**——否则真龙史诗永远只是 txt 文件。

## 四、【新增】B 线：世界内容（G20）

### 为什么它和主线强绑定

| G20 玩法 | 对应主线 | 玩家做什么 |
|---|---|---|
| **修复失落城市** | 尘世线《携手》卷 | 亲手重建洛丹伦，看部落联盟从对立到合作 |
| **时间线分支** | 噩梦线（世界之魂受创） | 见证"如果历史拐了个弯" |
| **均衡律账单** | 天意线（真龙代天收账） | 替真龙处理他不能亲自出手的事 |
| **龙眠观测台** | 三线交汇点 | 一个能看到全局的中枢 |

**关键设计**：真龙的**代偿值机制**（`剧情/技术可行性-真龙能力清单.md:7`）
决定了他不能全干预 —— **所以必须靠凡人**。这就是玩家的位置。

### B 线执行顺序

```
[ ] B1  通希尔重建（小村试点）        1周   验证手感
[ ] B2  龙眠观测台（内容中枢）        3天   给玩家一个"我在参与什么"的入口
[ ] B3  洛丹伦完整版                  2-3周
[ ] B4  时间线试点（银月城渴魔症）    2周
[ ] B5  均衡律周期事件                1周
```

**先做 B1 而不是 B3**：修复城市好不好玩取决于**手感**
（进度反馈是否及时、材料获取是否枯燥）。小地图试错成本低。

## 五、我认为计划里还缺的（你问的核心问题）

盘完整个项目，我认为有 **6 个真空区**：

### 缺口1【最严重】· 主线没有任何游戏内载体

```
现状：剧情/ 目录有 4.3 万字的故事，但游戏里一个字都看不到
```

**最小可行方案**（1周）：

```
- 做 10-20 个"世界文本"NPC，散落在关键地点
- 玩家对话能读到主线片段
- 配合 A08 的 .say 工具链，不用新写系统
```

**这个成本极低但意义大** —— 让故事从 txt 变成"我在游戏里读到的"。

### 缺口2 · bot 不会自我维护

```
[ ] 自动修装备      耐久掉光=裸奔，带bot玩两小时就废
[ ] 背包满卖垃圾    背包满了不拾取，等于白打
[ ] 自动学技能      升级不学技能，越升越弱
```

**这是 A 线的地基**，不做的话后面所有"像人"都是空中楼阁。

### 缺口3 · 没有"目标感"系统

```
现状：玩家上线不知道该干什么
```

缺一个**任务/成就/进度**的统合入口。G20 的观测台可以兼任。

### 缺口4 · 经济是单向的

```
现状：AHBot 凭空造货 -> 玩家买
缺失：bot 打怪 -> 挂拍卖 -> 玩家买 -> bot 收钱（G16第4步）
```

**没有这一步，"经济"就只是个自动商店。**

### 缺口5 · 没有回归测试

```
现状：改A坏B，靠你手动进游戏发现
```

已在 v1 提过，但一直没做。**建议每个补丁带验收清单**（我最近的文档已经在做）。

### 缺口6 · 上游合并风险

```
已改 10+ 个上游文件：
  botmgr.cpp / bot_ai.cpp / Map.cpp / GroupHandler.cpp / Group.cpp
  PetitionsHandler.cpp / TradeHandler.cpp / MiscHandler.cpp
  SpellInfo.cpp / Player.cpp（计划）
```

**建议加标记注释** `// >>> TCMOD F40 begin ... // <<< end`，
将来 merge 上游时能一眼找出我们的改动。

## 七、我还想到的新点子（你问"还有没有其他想法"）

按"和主线的契合度 × 实现成本"排序：

### 7.1 【推荐】bot 会谈论世界事件

```
洛丹伦重建到50% -> 人类bot："听说那边在重建，我想去看看。"
时间线开启      -> 法师bot："时间的流向不对劲，你感觉到了吗？"
```

**成本极低** —— A42 台词表加个 `event_id` 字段就行，
但效果是**把两条线缝在一起**。

### 7.2 遗物系统（叙事道具，不破坏数值）

```
修复城市/完成事件 -> 获得遗物
  洛丹伦王冠碎片：人类NPC对你态度不同
  太阳井残晶：血精灵区域声望加成
集齐一套 -> 解锁一段主线剧情
```

### 7.3 bot 的"来历"

```
每个bot随机一个背景故事（从表里抽）：
  "我是洛丹伦难民，家没了。"
  "我在诺莫瑞根待过，那味道现在还记得。"
羁绊到一定程度才会说出来
```

**这让 A42 的种族台词有了纵深** —— 不只是种族，还有个人史。

### 7.4 世界状态影响 bot 行为

```
洛丹伦重建完成 -> 人类bot 会主动提议去那边
时间线危机     -> bot 会说"我们该做点什么"
```

### 7.5 【务实】.story 指令

```
.story          查看主线进度
.story 1        阅读第一卷
.story where    提示下一个剧情点在哪
```

**成本一天** —— 但解决了"故事在txt里没人看"的问题。
