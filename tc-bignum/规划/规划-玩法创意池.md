## 技术底座：我确认过的可用钩子

这些决定了哪些玩法能做。Eluna 提供的关键事件：

```
PLAYER_EVENT_ON_KILL_CREATURE      7    击杀怪物
PLAYER_EVENT_ON_GIVE_XP           12    获得经验（可改数值）
PLAYER_EVENT_ON_LEVEL_CHANGE      13    升级
PLAYER_EVENT_ON_MAP_CHANGE        28    切换地图（进副本）
PLAYER_EVENT_ON_EQUIP             29    装备物品
PLAYER_EVENT_ON_ENTER_COMBAT      33    进入战斗
PLAYER_EVENT_ON_REPOP / RESURRECT 35/36 死亡与复活
PLAYER_EVENT_ON_LOOT_ITEM         32    拾取物品
CREATURE_EVENT_ON_DAMAGE_TAKEN     9    怪物受伤（可改伤害）
CREATURE_EVENT_ON_DIED             4    怪物死亡
MAP_EVENT_ON_PLAYER_ENTER         21    玩家进图
MAP_EVENT_ON_UPDATE               23    地图定时器
```

**`ON_DAMAGE_TAKEN` 和 `ON_GIVE_XP` 能改传入值**，这是很多玩法的基础。

## 一、和你「大数值改造」直接联动的（最推荐）

### 1. ⭐ 无尽塔 / 试炼之塔

一层比一层强，测试你的十亿装备到底能打多深。

```
第 1 层    怪物属性 x1
第 10 层   怪物属性 x10
第 50 层   怪物属性 x1000
第 100 层  怪物属性 x100000
```

- 每层随机 BOSS + 随机词缀（狂暴/分裂/吸血/反伤）
- 通关记录排行榜
- 层数越高掉落越好

**为什么推荐**：你把装备做到 10 亿，需要一个能匹配的挑战场。
普通副本你一刀秒，塔能无限延伸难度。

**技术**：`MAP_EVENT_ON_PLAYER_ENTER` + 动态刷怪 + `ON_DAMAGE_TAKEN` 缩放。

### 2. ⭐ 装等自适应难度

怪物强度跟随你的装备，永远不会「一刀秒」也不会「打不动」。

```lua
玩家平均装等 200  -> 怪物属性 x1
玩家平均装等 1000 -> 怪物属性 x50
玩家平均装等 9999 -> 怪物属性 x5000
```

**为什么推荐**：解决大数值改造最大的问题——**内容瞬间失去挑战**。

### 3. 成长型装备（武器觉醒）

武器随击杀数升级，属性动态成长。

```
击杀 100  只 -> 武器 +10% 属性，名称变金色
击杀 1000 只 -> 武器 +50%，附带特效
击杀 10000只 -> 觉醒，解锁专属技能
```

**技术**：`ON_KILL_CREATURE` 累加计数存自定义表，用 `SetStatFlatModifier` 加成。
配合你已做的大数值，成长空间极大。

## 二、单人/小队体验（配合 NPCBot）

### 4. ⭐ Solocraft — 单人进副本自动加成

进 5 人本自动获得 5 倍属性，进 25 人团本获得 25 倍。

```
5人本   -> 血量 x5,  伤害 x3
10人团  -> 血量 x10, 伤害 x6
25人团  -> 血量 x25, 伤害 x15
```

**为什么推荐**：你有 NPCBot，但 bot AI 毕竟不如真人。
这个能让你**真正单刷**所有内容。

**技术**：`ON_MAP_CHANGE` 判断 `map:IsDungeon()` / `IsRaid()` + 挂光环。

### 5. Bot 指挥系统增强

```
.bot formation 阵型名     切换队形（分散/集中/包围）
.bot focus                 集火我的目标
.bot retreat               全体后撤
.bot save 配置名           保存当前bot组合
.bot load 配置名           一键召唤整套队伍
```

**技术**：需要 C++（Eluna 无 NPCBot 接口，已核实）。

## 三、增加新鲜感的日常玩法

### 6. 每日轮换世界 Buff

每天 0 点随机一个全服增益，登录就有。

```
周一：经验 x2
周二：掉落 x2
周三：移动速度 +50%
周四：所有伤害 +30%
周五：金币 x3
周末：全部效果减半但同时生效
```

**技术**：`SERVER_EVENT_ON_UPDATE` 定时器 + 全服光环。

### 7. 随机世界事件

```
- 随机地点刷世界BOSS（全服公告坐标）
- 流星雨：地图随机掉落宝箱
- 亡灵入侵：主城被围攻
- 商人来访：限时特殊商店
```

**技术**：定时器 + `SummonCreature` + 全服广播。

### 8. 连杀奖励系统

```
连杀 5  -> 攻速 +10%
连杀 10 -> 全属性 +20%，屏幕特效
连杀 25 -> "无双"状态，伤害翻倍
被击杀  -> 连杀清零
```

**技术**：`ON_KILL_CREATURE` / `ON_KILLED_BY_CREATURE`。

## 四、探索与收集

### 9. 装备图鉴 / 收藏系统

```
.codex                    打开图鉴
.codex 武器               查看武器收集进度
收集度 10%  -> 全属性 +1%
收集度 50%  -> 解锁专属称号
收集度 100% -> 解锁隐藏坐骑
```

**技术**：`ON_LOOT_ITEM` + `ON_EQUIP` 记录，存自定义表。

### 10. 探索奖励

```
发现新区域      -> 经验 + 金币
探索完整张地图  -> 永久属性加成
到访所有主城    -> 解锁传送特权
```

### 11. 钓鱼/采集大师

```
钓到稀有鱼 -> 随机获得强力Buff
采集稀有草 -> 制作专属药水
```

## 五、战斗玩法深化

### 12. 词缀系统（借鉴暗黑/大秘境）

给怪物随机加词缀，同一个副本每次体验不同。

```
[狂暴]   血量低于30%时伤害翻倍
[分裂]   死亡时分裂成两只小怪
[吸血]   造成伤害的50%回复自身
[反伤]   受到伤害的20%反弹
[护盾]   每10秒获得一次吸收盾
[疾风]   移动和攻击速度 +50%
```

**技术**：`CREATURE_EVENT_ON_SPAWN` 随机挂光环 + `ON_DAMAGE_TAKEN` 判定。

### 13. 天赋重铸 / 装备洗练

```
.reforge 力量 敏捷        把装备的力量洗成敏捷
.enchant random           随机附魔，可能出极品
```

配合你的大数值，洗练出十亿属性会很有成就感。

### 14. 处决 / 斩杀特效

```
血量低于20%的敌人 -> 显示可处决标记
处决成功 -> 全屏特效 + 短暂无敌
```

## 六、社交与便利

### 15. 传送大厅 NPC

替代 `.tele`，做成对话菜单：

```
[时空引导者]
  > 主城          -> 暴风城/奥格瑞玛/达拉然...
  > 副本门口      -> 按等级分类
  > 我的锚点      -> 自定义传送点（最多10个）
  > 上次位置
```

### 16. 个人仓库扩展

```
.vault                    打开个人无限仓库
.vault deposit all        一键存入所有装备
.vault search 战刃        搜索仓库物品
```

### 17. 离线收益

```
离线 1 小时 -> 获得少量经验和金币
离线挂机点 -> 收益翻倍
```

## 七、我个人最推荐的组合

如果只做 3 个，我会选：

| 优先级 | 玩法 | 理由 |
|---|---|---|
| 🥇 | **装等自适应难度** | 解决大数值改造后「秒杀一切」的根本问题 |
| 🥈 | **无尽塔** | 给十亿装备一个真正的舞台，有明确目标感 |
| 🥉 | **Solocraft** | 配合 NPCBot，真正实现单人通关所有内容 |

**这三个组合起来**：你的装备越强 → 世界越强 → 塔能爬更高 → 掉更好装备。
形成正向循环，不会出现「改完大数值反而没得玩」的空虚感。
