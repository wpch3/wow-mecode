## 一、三道门的完整实证

### 门1：`SpellInfo::CheckLocation`

```cpp
// SpellInfo.cpp:1562
SpellCastResult SpellInfo::CheckLocation(uint32 map_id, uint32 zone_id, uint32 area_id, Player const* player, bool strict) const
{
    ...
    // continent limitation (virtual continent)
    if (HasAttribute(SPELL_ATTR4_CAST_ONLY_IN_OUTLAND))      // :1585
    {
        if (strict)
        {
            AreaTableEntry const* areaEntry = sAreaTableStore.LookupEntry(area_id);
            if (!areaEntry)
                areaEntry = sAreaTableStore.LookupEntry(zone_id);

            if (!areaEntry || !areaEntry->IsFlyable() || !player->CanFlyInZone(map_id, zone_id, this))
                return SPELL_FAILED_INCORRECT_AREA;          // :1594
        }
        else
        {
            uint32 const v_map = GetVirtualMapForMapAndZone(map_id, zone_id);
            MapEntry const* mapEntry = sMapStore.LookupEntry(v_map);
            if (!mapEntry || mapEntry->Expansion() < 1 || !mapEntry->IsContinent())
                return SPELL_FAILED_INCORRECT_AREA;
        }
    }
```

**关键**：整个飞行限制的开关就是 `SPELL_ATTR4_CAST_ONLY_IN_OUTLAND` 这个属性。
**去掉它，门1和门2一起消失**（因为 `IsFlyable()` 只在这个 if 里被调用）。

### 门2：`IsFlyable`

```cpp
// DBCStructure.h:205
    bool IsFlyable() const
    {
        if (Flags & AREA_FLAG_OUTLAND)
        {
            if (!(Flags & AREA_FLAG_NO_FLY_ZONE))
                return true;
        }
        return false;
    }
```

东部王国/卡利姆多的区域**没有 `AREA_FLAG_OUTLAND` 标志**，所以返回 false。

**但它只被门1调用** —— 去掉门1的属性，这道门就走不到了。

### 门3：寒冷天气飞行

```cpp
// Player.cpp:24963
bool Player::CanFlyInZone(uint32 mapid, uint32 zone, SpellInfo const* bySpell) const

    uint32 v_map = GetVirtualMapForMapAndZone(mapid, zone);

```

`571` = 北裂境。**学会 54197 即可**，或者也去掉属性。

## 二、推荐方案：纯 SQL（零编译）

**原理**：把飞行坐骑法术的 `SPELL_ATTR4_CAST_ONLY_IN_OUTLAND` 属性去掉。

TrinityCore 有一张 `spell_dbc` 表可以覆盖 DBC 数据，但 3.3.5 更常用的是
**直接改 `Spell.dbc`**，或者用**更简单的办法**：

### 方案 A：给自己学「寒冷天气飞行」+ 用 GM 命令（最快，5秒）

```
.learn 54197          学会寒冷天气飞行（解决门3）
```

这只解决北裂境。旧世界仍然不能飞。

### 方案 B：SQL 改属性（推荐，零编译，全世界生效）

**飞行坐骑法术的 Attributes 字段在 `Spell.dbc`**，
但 TrinityCore 支持用 `spell_custom_attr` 之类的表覆盖部分字段。

**3.3.5 最可靠的做法是改 DBC 文件本身**，需要：
1. 用 DBC 编辑器（如 `WDBXEditor`）打开 `Spell.dbc`
2. 找到飞行坐骑法术
3. 清掉 `AttributesEx4` 的 `0x80000000`（`SPELL_ATTR4_CAST_ONLY_IN_OUTLAND`）
4. **服务端 DBC 和客户端 MPQ 都要改**（坑表铁律：两边必须一致）

> **这条我要如实说明**：改 DBC 要动客户端，
> 和你「客户端魔改兼容性」的既有结论一致 —— 属于数据配置不是代码。

### 方案 C：改代码（一行，最彻底）

**文件**：`D:\TrinityCore\src\server\game\Spells\SpellInfo.cpp`

搜索原文（`:1585`）：

```cpp
    // continent limitation (virtual continent)
    if (HasAttribute(SPELL_ATTR4_CAST_ONLY_IN_OUTLAND))
    {
```

改成：

```cpp
    // continent limitation (virtual continent)
    // G17: 全世界飞行 —— 直接跳过外域限制检查。
    //   原逻辑要求区域有 AREA_FLAG_OUTLAND（DBCStructure.h:205 IsFlyable），
    //   旧世界区域没有这个标志，所以东部王国/卡利姆多不能飞。
    //   改成 false 等于对所有区域放行。
    if (false && HasAttribute(SPELL_ATTR4_CAST_ONLY_IN_OUTLAND))
    {
```

**同时处理门3**（北裂境），文件 `Player.cpp:24963`：

```cpp
bool Player::CanFlyInZone(uint32 mapid, uint32 zone, SpellInfo const* bySpell) const
{
    // G17: 全世界飞行 —— 取消寒冷天气飞行的技能要求
    return true;

    // 以下为原逻辑，保留备查
    /*
    uint32 v_map = GetVirtualMapForMapAndZone(mapid, zone);
    if (v_map == 571 && !bySpell->HasAttribute(SPELL_ATTR7_IGNORE_COLD_WEATHER_FLYING))
        if (!HasSpell(54197))
            return false;

```

> **为什么用 `if (false && ...)` 而不是直接删**：
> 保留原代码，将来上游合并时冲突好处理，也方便你随时改回去。
> 编译器会优化掉，零性能损耗。

## 三、副作用与注意（必读）

| 副作用 | 说明 | 建议 |
|---|---|---|
| **副本/战场里能飞** | 会破坏副本设计，可能卡进地形 | 见下方补充判断 |
| **卡进未加载地形** | 旧世界很多地方没做飞行高度的地图数据 | 正常玩不会遇到 |
| **PVP 平衡** | 战场飞行 = 破坏平衡 | **建议加战场排除** |

把方案 C 的第一处改成：

```cpp
    // G17: 全世界飞行，但排除副本和战场

            g17_allowFly = false;
    }

    if (!g17_allowFly && HasAttribute(SPELL_ATTR4_CAST_ONLY_IN_OUTLAND))
    {
```

> **注意用 `FindMap()` 不是 `GetMap()`** —— 坑表里那条：
> `Object.h:467 GetMap()` 内部有 `ASSERT(m_currMap)`，
