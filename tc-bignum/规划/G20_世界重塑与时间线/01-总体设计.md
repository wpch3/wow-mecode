## 零、先确认：这两个想法和主线是什么关系

我重读了 `剧情/_本次修订说明.md`，主线是**三线并行**：

```
天意线（真龙）      11章  30%   —— 真龙以真身出手 ≤12章，多数时候是伪装/旁观
尘世线（部落联盟）  篇幅最大    —— 旧账 -> 被迫合作 -> 真和解
噩梦线（世界自身）              —— 世界之魂受创
```

**你这两个新想法，正好是尘世线缺的那一块 —— "玩家能做什么"。**

| 想法 | 挂在哪条线 | 为什么契合 |
|---|---|---|
| **修复失落城市** | 尘世线《携手》卷 | 部落联盟真和解的**具体载体**。不是喊口号，是一砖一瓦重建 |
| **不同时间线** | 噩梦线 + 天意线 | 世界之魂受创 -> 时间线分岔。**真龙"看着万物"的视角天然能解释多时间线** |

**关键**：这两个不是"外挂玩法"，而是**让玩家参与主线的手段**。
主线现在是"故事"，加上这两个才变成"你的故事"。

## 一、修复失落城市（可行性最高，建议先做）

### 1.1 为什么这个想法好

- **有明确目标感**：进度条从 0% 到 100%，看得见
- **契合"携手"主题**：需要部落和联盟同时贡献才能推进
- **技术上全是现成 API**：刷 NPC、换建筑模型、区域公告

### 1.2 候选城市

| 城市 | 地图 | 现状 | 修复后 |
|---|---|---|---|
| **洛丹伦废墟** | 东部王国 | 幽暗城地表，一片废墟 | 人类王都重建，联盟据点 |
| **达拉然陨坑** | 东部王国 | 紫罗兰之眼，法师封锁 | 地面达拉然复原 |
| **奎尔萨拉斯** | 东部王国 | 天灾破坏的血精灵领土 | 太阳井周边重建 |
| **奥格瑞玛旧址** | 卡利姆多 | —— | 兽人传统风格重建 |
| **通希尔** | 东部王国 | 提瑞斯法的废弃村庄 | 恢复人烟 |
| **安多哈尔** | 东部王国 | 三方争夺的废墟 | 中立自由城 |

**建议先做洛丹伦** —— 它是"部落联盟旧账"的象征，修复它最有戏剧张力。

### 1.3 玩法设计

```
阶段0  探索      找到废墟里的"重建蓝图"（任务物品）
阶段1  清理      清空区域里的天灾/野怪，进度 0-25%
阶段2  物资      上交木材/石料/布匹（可从拍卖行买 -> 联动 G16 经济）
阶段3  建设      NPC 工匠进驻，建筑模型逐步替换，进度 50-75%
阶段4  守卫      抵御反扑波次，进度 100%
完成            城市可用（旅店/银行/拍卖/传送），玩家名字刻在纪念碑上
```

**关键设计：进度全服共享。** 你和 bot 一起打的贡献都算数，
这样单人服也能推进（bot 会帮你收集材料 —— 联动 G16 第5步"打工层"）。

### 1.4 技术路径（全部实证过的 API）

| 需求 | API | 出处 |
|---|---|---|
| 进度存档 | 自定义表 `world_rebuild_progress` | — |
| 建筑替换 | `creature`/`gameobject` 表 + `phaseMask` | 相位切换 |
| NPC 进驻 | `SummonCreature` / `creature` 表 | A08 已用过 |
| 区域公告 | `sWorld->SendZoneText` | — |
| 进度查询 | `.rebuild status` 指令 | 仿 A08 |
| 阶段触发 | `WorldScript::OnUpdate` 轮询 | A27 已用 |

**最省事的实现：用 phase（相位）**

```
phase 1   废墟状态（所有人默认看到）
phase 2   建设中（贡献过的玩家看到脚手架）
phase 4   完成（全服切换）
```

phaseMask 是 3.3.5 原生支持的，**不用改客户端**。

### 1.5 和 bot 的联动（这是我们的特色）

```
bot 会说："这里以前是洛丹伦，我父亲在这儿战死的。"     <- 人类bot
         "兽人不该为几百年前的事一直背债。"            <- 兽人bot
         "我见过它完好的样子。"                        <- 暗夜bot（活得久）

bot 会帮忙：自动去采集/购买重建物资（G16 第5步打工层）
```

**这让 A42 的种族台词有了用武之地** —— 不同种族对同一座城的态度完全不同。

## 二、时间线玩法（野心大，但要分期）

### 2.1 你的想法很有意思

> 「有些时间线部落没有来入侵，但是拥有渴魔症的精灵吸取生物的魔力」

这本质是**"如果历史拐了个弯"**。而且它和主线咬合得很好：

```
噩梦线：世界之魂受创
     -> 时间的织物出现裂痕
     -> 出现"本不该存在"的分支
天意线：真龙"看着万物"
     -> 他能看见所有分支，但不能全部干预（代偿值机制）
     -> 玩家的选择决定哪条分支成为现实
```

**真龙的"代偿值"设定（`技术可行性-真龙能力清单.md:7`）在这里刚好用上** ——
他每干预一次就付出代价，所以只能靠凡人。

### 2.2 三条候选时间线

| 时间线 | 分岔点 | 世界什么样 |
|---|---|---|
| **无兽人时间线** | 黑暗之门未开 | 人类繁荣但内斗；暗夜精灵仍闭关；**渴魔症失控的高等精灵成为主要威胁** |
| **天灾胜利线** | 阿尔萨斯未被阻止 | 东部王国全境天灾；幸存者据点求生 |
| **上古之战延续线** | 燃烧军团未被击退 | 卡利姆多仍在燃烧；上古之神苏醒 |

**你提的"渴魔症精灵"正好是第一条的核心冲突** ——
没有兽人入侵，奎尔萨拉斯不会被毁，但**魔瘾无人制约，反而演化成吸取生灵魔力的灾难**。

这个设定很好，因为它说明：**历史的伤痛未必是最坏的结局。**

### 2.3 技术实现：用地图副本

```
做法A（推荐）：自定义副本地图
  - 复制一张现有地图（如东部王国）作为"时间线副本"
  - 里面的 NPC/怪物/建筑全部换成分支版本
  - 通过传送门/NPC 进入
  - 技术上就是一个大型副本，全是数据配置

做法B：phase 切换
  - 同一张地图，用 phaseMask 区分时间线
  - 省事，但同一时间只能在一条线上
  - 适合小范围实验
```

**建议先用做法B 做一个小区域试点**（比如只做"银月城周边的渴魔症危机"），
验证玩法有意思了，再考虑做法A 铺开。

## 三、我的补充想法（你问"还有没有其他的"）

按和主线的契合度排序：

### 3.1 【强烈推荐】龙眠神殿观测台 —— 时间线的枢纽

**一个中枢地点，把所有内容串起来。**

```
玩家在这里能看到：
  - 各条时间线的现状（进度/危机等级）
  - 自己在每条线上的贡献
  - 真龙留下的"批注"（用主线文本，不用真龙出场）

作用：把"修复城市"和"时间线"两个玩法收拢到一个入口
```

**这解决一个实际问题**：内容多了之后，玩家不知道该去哪。

### 3.2 世界事件：均衡律的账单

主线设定里有条**均衡律**（`_本次修订说明.md:41`）：

> 天地生养万物，万物欠天地。真龙代天收账。

**做成周期性世界事件**：

```
每周随机一个"账单"：
  - 某个区域的生态失衡（野怪暴增/资源枯竭）
  - 玩家去平息 -> 全服获得增益
  - 放任不管 -> 该区域恶化，影响相邻区域
```

**好处**：让主线设定变成可玩的机制，而不只是背景文本。

### 3.3 bot 的立场（把 bot 卷进主线）

```
每个 bot 根据种族/职业，对主线事件有【立场】：
  修复洛丹伦   -> 人类bot积极，兽人bot抵触，亡灵bot复杂
  渴魔症危机   -> 血精灵bot"这是我们的家事"
  均衡律账单   -> 德鲁伊bot最热心
```

**技术上就是给 A42 的台词表加一个 `event_id` 维度** ——
和现有系统完全兼容。

### 3.4 遗物与传承

```
修复城市/完成时间线事件 -> 获得"遗物"
遗物不是装备，是【叙事道具】：
  - 洛丹伦王冠碎片：装备后，人类NPC对你态度不同
  - 太阳井残晶：血精灵区域声望加成
  - 收集齐一套 -> 解锁一段主线剧情
```

**用途**：给长期玩法一个收集目标，而且不破坏数值平衡。

### 3.5 【务实向】主城重建的简化版

如果上面的太大，有个**一周就能做出来的版本**：

```
选一个小废墟（如通希尔村）
  - 5 个阶段，每阶段上交一批材料
  - 每阶段刷新 NPC 和建筑
  - 完成后村子有旅店和商人
```

**先做这个验证玩法**，成了再推洛丹伦。

## 五、建议的执行顺序

```
[1] 先做 3.5 简化版（通希尔重建）      1周，验证玩法
[2] 如果好玩 -> 洛丹伦完整版           2-3周
[3] 同时做 3.1 观测台                  作为内容入口
[4] 时间线试点（银月城渴魔症）          2周
[5] 3.2 均衡律世界事件                  和上面并行
```

**为什么先做小的**：修复城市这类玩法，**好不好玩取决于手感**
（进度反馈是否及时、材料获取是否枯燥）。
先用小地图试，调好了再铺开，比一次做大再推翻划算。

## 六、需要你决定的三件事

```
1. 先做哪座城？    我推荐【通希尔】试点 -> 【洛丹伦】正式
2. 时间线做成副本还是相位？   我推荐先用相位做小范围试点
3. 材料从哪来？    纯打怪掉落 / 拍卖行买（联动G16）/ bot帮忙采集
```

第 3 条尤其重要 —— 如果材料只能自己刷，单人服会很枯燥；
**让 bot 能帮忙采集，这个玩法才立得住**（这也是 G16 第5步"打工层"的价值）。
