## 如果你还是想用 .patch 方式

也可以，把 3 个 .patch 复制进 `bignum_patches\` 后：

```bash
cd /d/TrinityCore
git apply --ignore-whitespace bignum_patches/01-objectmgr-item-loader.patch
git apply --ignore-whitespace bignum_patches/03-item-durability-uint32.patch
cd src/server/game/LuaEngine
git apply --ignore-whitespace ../../../../bignum_patches/02-eluna-uint64-checkval.patch
cd /d/TrinityCore
```

⚠️ `--ignore-whitespace` 一个都不能少（你的检出是 CRLF，实测不加必失败）。
