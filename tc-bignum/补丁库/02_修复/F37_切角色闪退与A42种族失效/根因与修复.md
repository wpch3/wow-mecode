# 问题一：切角色闪退

## 一、真因：上游的空指针 bug

```cpp
// botmgr.cpp:178
bool BotMgr::IsWanderingWorldBot(Creature const* bot)
{
    return bot->IsWandererBot() && (!bot->FindMap() || !bot->GetMap()->GetEntry() || bot->GetMap()->GetEntry()->IsWorldMap());
    //                              ^^^^^^^^^^^^^^^     ^^^^^^^^^^^^^
    //                              作者知道会是空       却又用了带 ASSERT 的 GetMap()
}
```

对照两个 getter：

```cpp
// Object.h:467
Map* GetMap() const { ASSERT(m_currMap); return m_currMap; }   // 【内部有断言】
// Object.h:468
Map* FindMap() const { return m_currMap; }                     // 安全版
```

### 为什么"切角色"才触发

```
你下线            -> bot 脱离地图，m_currMap = nullptr
你进另一个角色     -> 世界继续 tick -> 某处调 IsWanderingWorldBot(bot)
                  -> !bot->FindMap() 为 true，短路求值本该到此为止
                  -> 【但 || 右边的表达式在某些路径仍被求值】
                  -> GetMap() 的 ASSERT 炸掉 -> 无提示闪退
```

**关键**：`||` 是短路的，正常情况 `!FindMap()` 为真就不会算右边。
但 bot 在"半脱离"状态时 `m_currMap` 可能非空却已失效，
于是走到 `GetMap()->GetEntry()`，那个 Map 对象已经被销毁 -> 访问违例。

**和你换不换账号无关**，只要队伍里有游荡bot、你切角色，就可能触发。

## 二、修复（一行）

**文件**：`D:\TrinityCore\src\server\game\AI\NpcBots\botmgr.cpp`

搜索原文（`:178-181`，全文件唯一）：

```cpp
bool BotMgr::IsWanderingWorldBot(Creature const* bot)
{
    return bot->IsWandererBot() && (!bot->FindMap() || !bot->GetMap()->GetEntry() || bot->GetMap()->GetEntry()->IsWorldMap());
}
```

替换为：

```cpp
bool BotMgr::IsWanderingWorldBot(Creature const* bot)
{
    // F37: 原版用了 Object.h:467 GetMap()，它内部有 ASSERT(m_currMap)。
    //   玩家切角色时 bot 处于"已离开旧地图、未进新地图"的瞬间，
    //   m_currMap 为空或已失效 -> ASSERT 炸掉 -> 无提示闪退。
    //   改用 Object.h:468 FindMap()（无断言），并把结果存进局部变量，
    //   避免重复调用期间状态变化。
    if (!bot || !bot->IsWandererBot())
        return false;

    Map const* map = bot->FindMap();
    if (!map)
        return true;        // 无地图 = 不在任何副本里，按"世界bot"处理（同原语义）

    MapEntry const* entry = map->GetEntry();
    if (!entry)
        return true;

    return entry->IsWorldMap();
}
```

**改动要点**：
- `GetMap()` -> `FindMap()`（去掉 ASSERT）
- 结果存局部变量，只取一次
- 加 `!bot` 判空

## 三、确认 include

# 问题二：A42 种族台词为什么选不中

## 一、真因：我的评分权重设计错了

我给的评分规则：

```cpp
if (t.ItemKind  == itemKind)  score += 40;   // 精确物品种类
if (t.BotClass  != 0)         score += 20;
if (t.BotRace   != 0)         score += 10;
```

**问题**：我 A42 插的种族台词全部是 `item_kind = 7`（通用），
而 A37 原有台词有精确的 `item_kind`（1食物/2水/3药水...）。

实测（我写了个小程序验证）：

```text
给矮人一个【食物】(itemKind=1)：
  A37「食物通用」(kind=1, race=0)  ->  40 分
  A42「矮人要酒」(kind=7, race=3)  ->  10 分
  -> A37 胜出，种族台词【永远选不中】
```

A37 原有台词的 item_kind 分布：

```
kind=1 食物 10条 / kind=2 水 4条 / kind=3 药水 3条
kind=4 装备 3条  / kind=5 珍稀 3条 / kind=6 垃圾 4条 / kind=7 通用 5条
```

**只要你给的东西属于 1-6 类，就一定有 40 分的对手，种族台词的 10 分毫无胜算。**

## 二、修复：把种族/职业的权重提到物品种类之上

**文件**：`bot_companion.cpp`，`PickGiftText` 函数里

搜索原文：

```cpp
        int score = 0;
        if (t.ItemKind  == itemKind)  score += 40;   // 精确种类 > 通用
        if (t.BotClass  != 0)         score += 20;
        if (t.BotRace   != 0)         score += 10;
        if (t.NeedState != 0)         score += 5;
        if (t.BondTier  != 0)         score += 5;
```

替换为：

```cpp
        // F37 修正：原来 ItemKind 给 40 分，压过了种族(10)和职业(20)，
        //   导致 A42 的种族台词（item_kind=7 通用）永远选不中。
        //   改成【说话人特征优先】：种族 > 职业 > 物品种类。
        //   理由：玩家更在意"这个亡灵怎么说话"，而不是"这是食物还是药水"。
        int score = 0;
        if (t.BotRace   != 0)         score += 100;  // 种族最优先
        if (t.BotClass  != 0)         score += 50;   // 职业次之
        if (t.ItemKind  == itemKind)  score += 20;   // 精确种类再次
        if (t.NeedState != 0)         score += 5;
        if (t.BondTier  != 0)         score += 5;
```

### 改后的优先级

| 台词 | 得分 | 排序 |
|---|---|---|
| 亡灵牧师 + 食物专属 | 100+50+20 = **170** | 最优先 |
| 亡灵 + 食物专属 | 100+20 = **120** | |
| 亡灵通用（A42插的） | **100** | **现在能选中了** |
| 牧师 + 食物专属 | 50+20 = **70** | |
| 食物通用（A37原有） | **20** | 兜底 |

## 三、同样要改 PickText

`PickText`（管闲聊）也有同样问题，但它没有 ItemKind 维度，
只是种族 10 分 vs 职业 20 分 —— **职业压过种族**。

搜索原文：

```cpp
        int score = 0;
        if (t.BotClass != 0) score += 20;
        if (t.BotRace  != 0) score += 10;
```

替换为：

```cpp
        // F37: 种族优先于职业，理由同 PickGiftText
        int score = 0;
        if (t.BotRace  != 0) score += 100;
        if (t.BotClass != 0) score += 50;
```

> **注意**：这样改之后，「亡灵法师」会优先说亡灵台词而不是法师台词。
> 如果你想保留职业味道，就给「亡灵+法师」组合单独写台词（150分，最高）。
> 我 A42 第2步的种族台词都是 `bot_class=0`，所以不会冲突。

# 三、A42 到底怎么测试

## 最快的验证方法（不用进游戏）

```sql
-- 模拟：给一个矮人(race=3)战士(class=1)食物(kind=1)，看会选中什么
SELECT `id`, `item_kind`, `bot_class`, `bot_race`, `text`,
       (CASE WHEN `bot_race`  != 0 THEN 100 ELSE 0 END) +
       (CASE WHEN `bot_class` != 0 THEN 50  ELSE 0 END) +
       (CASE WHEN `item_kind` = 1  THEN 20  ELSE 0 END) AS `得分`
FROM `world`.`npcbot_gift_text`
WHERE `react_type` = 0
  AND (`item_kind` = 1 OR `item_kind` = 7)
  AND (`bot_class` = 0 OR `bot_class` = 1)
  AND (`bot_race`  = 0 OR `bot_race`  = 3)
ORDER BY `得分` DESC
LIMIT 10;
```

**改完代码后，得分最高的应该是 `bot_race=3` 那条（100分）。**

如果查出来最高分是 `item_kind=1, bot_race=0`，说明代码没改对。

## 游戏内测试

```
1. 招一个【矮人】bot（种族要看清楚）
2. 给它一个面包
3. 应该说：「好东西！要是再来杯麦酒就完美了，哈哈！」
4. 换一个【亡灵】bot，给面包
5. 应该说：「……我其实感觉不到太多。但谢谢你还把我当个人看。」
```

**怎么确认 bot 的种族**：右键 bot 看它的种族，或者：

```sql
SELECT e.`entry`, ct.`name`, e.`race`, e.`bclass`
FROM `world`.`creature_template_npcbot_extras` e
JOIN `world`.`creature_template` ct ON ct.`entry` = e.`entry`
WHERE e.`race` = 3;    -- 3=矮人  5=亡灵  10=血精灵
```

## 如果还不生效，插探针

在 `PickGiftText` 的 `return` 之前加：

```cpp
    TC_LOG_ERROR("scripts", "F37-PICK: itemKind={} botClass={} botRace={} bestScore={} poolSize={}",
        uint32(itemKind), uint32(botClass), uint32(botRace), bestScore, uint32(pool.size()));
```
