## 一、确定有问题的：声明被写进了函数体里

### 证据

你的诊断第 2 节：

```
48:void AddSC_botrename_commandscript();
82:void AddSC_pbot_autoaccept();          // step42 PlayerBot自动接受
101:    AddSC_botrename_commandscript();
102:    AddSC_pbot_autoaccept();           // step42 PlayerBot自动接受
```

我对照了上游原文件（共 106 行）：

```
第 19-59 行   声明区
第 63 行      void AddCommandsScripts()      <- 函数从这开始
第 106 行     }                              <- 函数结束
```

**你的 82 行是一句 `void AddSC_pbot_autoaccept();`（带 void、带分号 = 声明），
但那个位置已经在 `AddCommandsScripts()` 函数体内部了。**

### 为什么这是问题

C++ **允许**在函数体内声明函数，所以它能编译通过，不报错。
但那只是个**局部声明**，**不是调用**。

不过你的 101/102 行有真正的调用，所以 `pbot_autoaccept` 实际是能生效的，
82 行那句只是**冗余**。

**它不会导致闪退**，但应该清理掉。

### 修复

打开 `cs_script_loader.cpp`：

1. **删掉第 82 行**那句 `void AddSC_pbot_autoaccept();`
2. 把它**移到第 48 行附近**（和 `AddSC_botrename_commandscript();` 放一起）

改完应该是：

```cpp
// ===== 声明区（第 48 行附近）=====
void AddSC_botrename_commandscript();
void AddSC_pbot_autoaccept();              // step42


// ===== 函数体（第 63 行之后）=====
void AddCommandsScripts()
{
    ...
    AddSC_wp_commandscript();
    AddSC_botrename_commandscript();
    AddSC_pbot_autoaccept();               // step42
}
```

> 【上面这块仅供**核对**，不要复制！】
> 你只需要**移动**那一行，不要再新增。

## 三、顺带确认的：中文别名问题（bug2）

诊断第 5 节：

```
botcommands.cpp : 无BOM      [中文别名会失效]
```

**这条实锤了**我上一轮的判断。

修复（5 分钟，不用重跑 CMake）：

```
VS2022 打开 botcommands.cpp
-> 文件 -> 另存为
-> 保存按钮右边小箭头 -> 编码保存
-> 选 "Unicode (UTF-8 带签名) - 代码页 65001"
-> 覆盖
```

**必须是"带签名"**（签名 = BOM）。项目没开 `/utf-8` 编译选项，
MSVC 只认 BOM。
