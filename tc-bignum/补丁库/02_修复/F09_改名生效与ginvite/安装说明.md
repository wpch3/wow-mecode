## 三、这次改了什么

### 3.1 补上 QueryData 重烤（头顶名字）

改名后原来只有：

```cpp
sObjectMgr->LoadCreatureLocales();
```

现在加了：

```cpp
sObjectMgr->InitializeQueriesData(QUERY_DATA_CREATURES);
```

**为什么必须加**：客户端头顶的名字走 `CMSG_CREATURE_QUERY`，
服务端回的是**启动时预烤好的缓存包**（`QueryHandler.cpp:124`），
`LoadCreatureLocales()` 不会重烤它。

官方 `.reload creature_template`（cs_reload.cpp:453）就记得调这个，
而 `.reload creature_template_locale`（cs_reload.cpp:1005）**忘了** ——
所以这是核心自己的坑，不是你操作错了。

API 已核实：`ObjectMgr.h:1241 InitializeQueriesData(QueryDataGroup)` public(947段)。

### 3.2 补上队伍窗口刷新

新增 `RefreshGroupName()` 函数。

**为什么要这么绕**：队伍成员名是**加入队伍那一刻的快照**
（`Group.cpp:491  member.name = creature->GetName();`），
发包时直接用快照（`Group.cpp:2049  data << citr->name;`），不实时查。

而 `MemberSlot` 外部改不了：
- `Group.h:364 _getMemberWSlot()` 是 **protected**(358段)
- `Group.h:256 GetMemberSlots()` 返回 **const 引用**

**所以走官方路径：踢出 + 重加**，让它重新拍一次快照。

用到的 API（全部实查确认 public）：

```
Group.h:210   RemoveMember(ObjectGuid, ...)   public(185段)
              Group.cpp:695 有 guid.IsCreature() 专用分支，正确处理 bot
Group.h:197   AddMember(Creature*)            public(185段)
Group.h:259   GetMembersCount()               public(185段)
Creature.h:397 GetBotGroup()                  public(78段)
botdatamgr.h:232 BotDataMgr::FindBot(uint32)  public(203段)
```

### 3.3 一个有意的保护

```cpp
if (grp->GetMembersCount() <= 2)
{
    // 只提示，不动手
}
```

**原因**：`Group.cpp:701` 那个判断是

```cpp
if (GetMembersCount() > ((isBGGroup() || isBFGroup()) ? 1u : 2u))
```

人数不够时 `RemoveMember` 会走**解散队伍**的路径。
为了改个名字把队伍弄散了不值得，所以这种情况只提示你手动重加。

## 五、已知的残留问题（先告诉你，别到时候以为是新 bug）

### 5.1 服务器重启后，队伍里的 bot 名字会变回英文

**根因**（上游设计，`Group.cpp:347`）：

```cpp
void Group::LoadCreatureMemberFromDB(uint32 entry, ...)
{
    CreatureTemplate const* ct = sObjectMgr->GetCreatureTemplate(entry);
    member.name = ct->Name;        // <- 用的是英文默认名，不看中文 locale
}
```

重启后从 `characters_npcbot_group_member` 表恢复队伍时，
它直接用 `creature_template.Name`（英文），**不走 locale**。

**两个办法**：

- **办法A（推荐，零风险）**：中英文名都改成「鲤鱼」
  ```
  .botname cn 鲤鱼
  .botname en 鲤鱼
  .reload creature_template <entry>
  ```
  这样不管走哪条路都是「鲤鱼」。

- **办法B（要改上游）**：改 `Group.cpp:347` 让它走 `GetNameForLocaleIdx`。
  能做，但动的是上游队伍代码，风险高。**先用办法A，除非你坚持要B。**

### 5.2 英文名改完仍需手动 reload

```
.botname en <新名>
.reload creature_template <entry>     <- 这步不能省
```

因为 `CreatureTemplate::Name` 在内存里没更新，
光重烤缓存用的还是旧 Name。指令执行后会提示你。
