# F36 · 启动崩服 ASSERTION FAILED（botdatamgr.cpp:1913）

> 2026-08-09
> 用户：「配置好拍卖行的conf后出现了闪退」

---

## 一、先说结论：**和拍卖行无关**

崩溃信息：

```text
Only 801 out of 817 bots of enabled classes aren't spawned.
Desired amount of wandering bots (802) cannot be created. Aborting!
botdatamgr.cpp:1913 ASSERTION FAILED: false
```

这是 **NPCBot 游荡 bot 数量配置**的问题，
你改拍卖行 conf 时**顺手改到了另一个配置项**，或者之前改过没重启所以没暴露。

---

## 二、真因（实查源码）

```cpp
// botdatamgr.cpp:1867
void BotDataMgr::GenerateWanderingBots()
{
    const uint32 wandering_bots_desired = BotCfg::GetDesiredWanderingBotsCount();   // 你配的 802

    if (wandering_bots_desired == 0)
        return;                                    // 配 0 就直接跳过

    uint32 maxbots = sBotGen->GetSpareBotsCount();     // 实际可用 801
    uint32 enabledbots = sBotGen->GetEnabledBotsCount();  // 已启用职业总数 817

    if (maxbots < wandering_bots_desired)          // 801 < 802  -> 成立
    {
        BOT_LOG_FATAL("server.loading", "Only {} out of {} bots of enabled classes aren't spawned...");
        ASSERT(false);                             // :1885  <- 崩在这
    }
```

> 报错提示里的行号 1913 是 Release 编译的偏移，
> **真正的 ASSERT 在 `:1885`**（`GenerateWanderingBots` 里的第一个）。

### `maxbots` 是什么

```cpp
// botdatamgr.cpp:486
uint32 GetSpareBotsCount(TeamId teamId = TEAM_NEUTRAL) const
{
    uint32 count = 0;
    for (auto const& [bot_class, bots] : _spareBotIdsPerClassMap)
        count += bots.size();      // 【没被占用的】bot 模板数量
    return count;
}
```

**`_spareBotIdsPerClassMap` = 空闲模板池。**

一个模板被以下任一情况占用，就会从池子里减少：

```
1. 写进了 characters_npcbot（已招募/已固定的 bot）
2. A35 批量永久化写进了 creature 表
3. 模板本身被禁用（职业没启用）
```

**只差 1 个（801 vs 802）** —— 说明你最近多固定了一个 bot，
或者某个模板被占用了。

---

## 三、修法：改一个数字

**文件**：`D:\TC-Build\bin\RelWithDebInfo\worldserver.conf`

搜索：

```ini
NpcBot.WanderingBots.Continents.Count = 802
```

改成一个**留余量**的值：

```ini
NpcBot.WanderingBots.Continents.Count = 750
```

> **为什么不是改成 801**：你以后每招募/固定一个 bot，
> 空闲池就少一个，配得太满下次还会崩。**留 5%-10% 余量**。

### 你上传的旧 conf 里这个值是 0

```
worldserver.conf.txt:4856   NpcBot.WanderingBots.Continents.Count = 0
```

`0` 表示**完全不生成游荡bot**（`:1871` 直接 return）。
说明你后来改成了 802。如果你不确定要多少，**先改回 0 确认能启动**，
再逐步往上加。

## 五、想知道到底有多少可用模板

```sql
-- 总模板数
SELECT COUNT(*) AS `bot模板总数`
FROM `world`.`creature_template_npcbot_extras`;

-- 已被占用的（招募过的）
SELECT COUNT(*) AS `已占用`
FROM `characters`.`characters_npcbot`;

-- 写进 creature 表的固定bot
SELECT COUNT(*) AS `固定bot`
FROM `world`.`creature` c
JOIN `world`.`creature_template_npcbot_extras` e ON c.`id1` = e.`entry`;
```

**可用数 ≈ 总模板数 - 已占用 - 固定bot**

把 `Count` 配成这个数的 **90%** 比较安全。
