        trader->GetSession()->SendCancelTrade(status);

### 整段替换为

```cpp
void Player::TradeCancel(bool sendback, TradeStatus status /*= TRADE_STATUS_TRADE_CANCELED*/)
{
    if (m_trade)
    {
        Player* trader = m_trade->GetTrader();

        TC_LOG_ERROR("misc", "[F27-2] TradeCancel! 谁调的={} 对方={} sendback={} status={}",
            GetName(), trader ? trader->GetName() : "NULL",
            uint32(sendback), uint32(status));

        if (sendback)
            GetSession()->SendCancelTrade(status);

        trader->GetSession()->SendCancelTrade(status);

        // cleanup
        delete m_trade;
        m_trade = nullptr;
        delete trader->m_trade;
        trader->m_trade = nullptr;
    }
}
```

**改动只有中间那 4 行 `TC_LOG_ERROR`，其它一个字都没动。**

    info.Status = TRADE_STATUS_OPEN_WINDOW;

## 日志怎么看

### 正常应该是这样

```text
[F27-1] InitiateTrade 结尾: 对方=鲤鱼 IsBotSession=1 PlayerDisconnected=1
[F27-1] 钩子【执行】，开始调用 HandleBeginTradeOpcode
[F27-3] BeginTrade: 鲤鱼 发送 OPEN_WINDOW 给双方
[F27-1] 钩子【调用完毕】
```

之后**不应该**再有 `[F27-2] TradeCancel`。

### 对照表

| 日志现象 | 说明 |
|---|---|
| 完全没有 `[F27-1]` | 钩子代码没编译进去，或改错了文件 |
| `IsBotSession=0 PlayerDisconnected=0` | bot 会话不是 bot 态，`.pbot spawn` 有问题 |
| 出现 `钩子【跳过】` | 同上 |
| `[F27-3] m_trade 是空的` | 时序问题，钩子调太早 |
| 有 `OPEN_WINDOW` 但紧接着 `[F27-2]` | **确认是被取消**，看下一行 |
| `[F27-2] 谁调的=鲤鱼` | **bot 侧取消** -> 还是 `pbot_autoaccept` 的逻辑 |
| `[F27-2] 谁调的=你的名字` | **你侧取消** -> 全新路径，我完全没查到的地方 |

`[F27-2]` 那一行的 `谁调的=` 后面是谁，直接决定下一步往哪查。
