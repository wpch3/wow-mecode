## 一、先说结论：是我 step44 文档写错了，不是你贴错

我在 step44 的 `bug1-招募游荡bot闪退.md` 里写了这么一句：

> **botPet 的 UnsetWanderer**：`bpet_ai` 继承自 `bot_ai`，
> 所以加在 `bot_ai` 上它自动就有，不用另外改 bpet_ai.h。

**这句话是错的。我没实查就下了结论。**

实查 `bpet_ai.h:19`：

```cpp
class bot_pet_ai : public CreatureAI
//                        ^^^^^^^^^^ 继承的是 CreatureAI，【不是 bot_ai】
```

`bot_pet_ai` 是**完全独立的一个类**，它自己有一份 `_wanderer`：

```cpp
// bpet_ai.h:59-61   public 段(21段)
    //wandering bots
    bool IsWanderer() const { return _wanderer; }
    void SetWanderer() { if (IAmFree()) _wanderer = true; }

// bpet_ai.h:181
    bool _wanderer{};
```

**它有 `SetWanderer()`，但没有 `UnsetWanderer()`** ——
因为我让你只在 `bot_ai` 上加了，`bot_pet_ai` 那边没加。

所以 `bot_ai.cpp` 里这一行编译不过：

```cpp
    if (botPet)
        botPet->GetBotPetAI()->UnsetWanderer();    // <- C2039
```

## 三、修复：给 bot_pet_ai 补上这个方法（1 行）

### 文件

```
D:\TrinityCore\src\server\game\AI\NpcBots\bpet_ai.h
```

### Ctrl+F 搜（大约第 59-61 行）

```cpp
    //wandering bots
    bool IsWanderer() const { return _wanderer; }
    void SetWanderer() { if (IAmFree()) _wanderer = true; }
```

### 改成（在 SetWanderer 下面加一行）

```cpp
    //wandering bots
    bool IsWanderer() const { return _wanderer; }
    void SetWanderer() { if (IAmFree()) _wanderer = true; }
    void UnsetWanderer() { _wanderer = false; }     // step59: 配合 bot_ai::UnsetWanderer
```

**就这一行。**

### 为什么这样写就够了

对比 `bot_ai::UnsetWanderer()` 要做三件事：

```cpp
_wanderer = false;
_travel_node_last = nullptr;      // 清路点
_travel_node_cur  = nullptr;      // 清路点
```

**但 `bot_pet_ai` 没有 `_travel_node_*` 这两个成员**（我 grep 过，
`bpet_ai.h` 里只有 `_wanderer`，没有任何 travel node）。

宠物不自己走路点，它跟着主人走。所以只清 `_wanderer` 就完整了。

### 访问段确认

```
bpet_ai.h:60  IsWanderer()    落在 段21 public:
bpet_ai.h:61  SetWanderer()   落在 段21 public:
```

新加的这行紧跟其后，**同样在 public 段**，`bot_ai.cpp` 能调到。

## 八、我的错误记录

**「A 继承自 B」这种话，必须 grep `class A` 看到 `: public B` 才能说。**

我 step44 是**看到 `bpet_ai` 里有 `SetWanderer` 就假设它继承自 bot_ai**，
实际上那是**两个同名但独立的方法**，分属两个不相干的类。
