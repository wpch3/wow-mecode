## 一、根因：**我让你手动贴多行代码，这是我的错**

`WANDERING_BOT_SPAWN_DELAY 未声明` 说明那两行 `static` 声明
**编译器没看到** —— 要么漏贴、要么贴到了 `if` 块外面。

933/936 的 C2447 是**连锁反应**：声明缺失 → while 条件编译失败
→ 大括号配对乱掉 → 后面全崩。

**我不该给你一个夹着 11 行中文注释的代码块让你手贴。**
注释一多，很容易只贴到一半。

## 二、正确做法：先还原，再整段替换

### 第1步：把那一段还原成原样

打开 `D:\TrinityCore\src\server\game\AI\NpcBots\botdatamgr.cpp`

**Ctrl+F 搜**：`_botsWanderCreaturesToSpawn.empty()`

到它对应的结束 `}` 之间的所有内容，整个选中删掉**。

（如果你不确定范围，直接从 git 还原这个文件：
`git checkout -- src/server/game/AI/NpcBots/botdatamgr.cpp`
然后重新做第2步。）

### 第2步：贴入下面这段（**注释已精简到3行**）

```cpp
    if (!_botsWanderCreaturesToSpawn.empty())
    {
        // F18: 原为固定 500ms 出 1 个（500个bot要4.2分钟）。
        // 改为可配置批量：默认 50ms 出 10 个 -> 500个约2.5秒。
        // 配置项 NpcBot.WanderingBots.SpawnDelayMs / .SpawnBatch
        static uint32 const WBOT_SPAWN_DELAY = std::max<uint32>(1u, uint32(sConfigMgr->GetIntDefault("NpcBot.WanderingBots.SpawnDelayMs", 50)));
        static uint32 const WBOT_SPAWN_BATCH = std::max<uint32>(1u, uint32(sConfigMgr->GetIntDefault("NpcBot.WanderingBots.SpawnBatch", 10)));

        next_wandering_bot_spawn_delay += diff;

        while (next_wandering_bot_spawn_delay >= WBOT_SPAWN_DELAY && !_botsWanderCreaturesToSpawn.empty())
        {
            next_wandering_bot_spawn_delay -= WBOT_SPAWN_DELAY;

            for (uint32 n = 0; n < WBOT_SPAWN_BATCH && !_botsWanderCreaturesToSpawn.empty(); ++n)
            {
                auto const& p = _botsWanderCreaturesToSpawn.front();
                uint32 bot_id = p.first;
                WanderNode const* spawnLoc = p.second;
                _botsWanderCreaturesToSpawn.pop_front();
                SpawnWandererBot(bot_id, spawnLoc, nullptr);
            }
        }

        return;
    }
```

**改动点**：
- 变量名从 `WANDERING_BOT_SPAWN_DELAY` 改成 **`WBOT_SPAWN_DELAY`**
  （短一点，也避免和残留的旧名冲突）
- 注释压到 3 行
- 两个 `static` 声明各占**一整行**，不换行，不容易贴漏

任何一条不对就是贴错了，别急着编译。

## 四、配置项

worldserver.conf 里加（不加也能跑，用默认值）：

```ini
# 每批出场间隔（毫秒），默认 50
NpcBot.WanderingBots.SpawnDelayMs = 50

# 每批出场几个，默认 10
NpcBot.WanderingBots.SpawnBatch = 10
```

| 配置 | 500个耗时 |
|---|---|
| 50ms / 10个（默认） | 2.5 秒 |
| 100ms / 5个（保守） | 10 秒 |
| 20ms / 25个（激进） | 0.4 秒 |

**启动卡顿就把 Batch 调小。**
