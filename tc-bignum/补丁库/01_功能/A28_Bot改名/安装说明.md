# step43 Bot 改名（支持中英文）—— 安装说明

> 需求：「可以用指令或者sql更改npcbot和playerbot的角色名，包括中英文」
>
> **指令和 SQL 两条路都给了。**

---

## 零、先说三件必须知道的事

### 1. 两种 bot 的名字机制【完全不同】

```
NPCBot    = Creature      名字在 world.creature_template.Name
                          -> 【同 entry 的所有bot共享一个名字】
                          -> 改了 entry=70001，所有 70001 的bot都变

PlayerBot = 真实 Player   名字在 characters.characters.name
                          -> 每个角色独立
```

如果你想让每只 NPCBot 名字都不一样，得给它们**不同的 entry**，那是另一件事。

### 2. 中文名【能用】，这是官方原生支持

我一开始也怀疑中文会被拒，实查后确认可以：

```cpp
// ObjectMgr.cpp:8633  isValidString()
if (strictMask == 0)
{
    if (isExtendedLatinString(wstr, numericOrSpace)) return true;
    if (isCyrillicString(wstr, numericOrSpace))      return true;
    if (isEastAsianString(wstr, numericOrSpace))     return true;   // <- 中日韩
    return false;
}

// Util.h:155  isEastAsianCharacter()
if (wchar >= 0x4E00 && wchar <= 0x9FC3)   // Unified CJK Ideographs
    return true;                          // <- 汉字在这个区间
```

配置默认值就是 0（`worldserver.conf.dist:607  StrictPlayerNames = 0`），
**不用改任何配置**。

> 如果你把 `StrictPlayerNames` 改成 1（只允许基础拉丁字母），中文就会被拒。
> 那是配置问题，不是代码问题。

### 3. 有一条规则你会撞上：**PlayerBot 的名字不能中英混用**

这是**暴雪原版规则**，看上面那段代码就明白 —— 它是「要么全拉丁、要么全东亚」：

| 名字 | 结果 |
|---|---|
| `阿尔萨斯` | 可以 |
| `Arthas` | 可以 |
| `阿尔萨斯X` | **拒绝**（混用） |
| `Bot机器人` | **拒绝**（混用） |

长度上限 **12 个字符**（不是字节），所以中文最多 12 个字。

**NPCBot 没有这个限制** —— Creature 的名字随便写，混用、空格、标点都行，上限 100 字节。

## 三、指令用法

### NPCBot（选中它，或直接给 entry）

```
.botname cn <中文名>              改中文名（zhCN客户端可见）
.botname en <英文名>              改英文名（默认名）
.botname entry <ID> cn <名字>     按entry改，不用选中
.botname entry <ID> en <名字>
.botname show                     看当前中英文名（选中目标）
.botname show <entry>             看指定entry的名字
```

**例子**：

```
选中一个bot，然后：
.botname cn 巫妖王
.botname en The Lich King

或者不用选中：
.botname entry 70001 cn 霜之哀伤
.botname show 70001
```

**中英文可以共存** —— 依据 `Creature.cpp:3093 GetNameForLocaleIdx`：
有中文名就显示中文名，没有才回退到英文名。

### PlayerBot

```
.botname player <旧名> <新名>
```

**例子**：

```
.botname player Evirstara 阿尔萨斯
```

### 中文别名

```
.botname 中文 <名>    = .botname cn
.botname 英文 <名>    = .botname en
.botname 编号 <ID> 中文 <名>  = .botname entry <ID> cn
.botname 查看         = .botname show
.botname 玩家 <旧> <新>       = .botname player
```

**名字可以带空格**：`.botname en The Lich King` 会正确拼成 `The Lich King`。

## 四、SQL 方式

不想用指令就用 `sql/改名模板.sql`，里面每段都有说明。

**关键差异**（这个必须知道）：

| | 指令 | SQL |
|---|---|---|
| NPCBot 中文名 | 自动 reload，立刻生效 | 要手动 `.reload creature_template_locale` |
| NPCBot 英文名 | 提示你 reload | 要手动 `.reload creature_template <entry>` |
| PlayerBot | **在线也能改**，自动更新缓存 | **必须离线 + 重启服务端** |

**为什么 SQL 改 PlayerBot 要重启**：
角色名有内存缓存（`CharacterCache`）。只改库不重启的话，
`/who`、好友列表、组队框还是旧名。
指令会调 `sCharacterCache->UpdateCharacterData()`（CharacterCache.h:50），所以没这问题。

**SQL 改 PlayerBot 前一定要确认 `online = 0`**，
否则内存里还是旧名，登出时会把旧名写回去 —— 白改。
模板里的 UPDATE 加了 `AND online = 0` 做双保险。

## 五、改完客户端还显示旧名字？

**这是正常现象，不是没改成功。**

```
QueryHandler.cpp:119  HandleCreatureQueryOpcode
```

客户端第一次见到某个 NPC entry 时发 `CMSG_CREATURE_QUERY` 问名字，
拿到后**存进本地缓存文件**，之后不再问。

**解决办法**：

1. 关闭客户端
2. 删掉 `你的客户端目录\Cache\WDB\zhCN\creaturecache.wdb`
3. 重新登录

没缓存过这个 entry 的**其他玩家会直接看到新名字**。

PlayerBot（角色名）**没有这个问题**。

## 六、和官方 .character rename 的一个关键区别

官方改在线角色时会**踢下线**：

```cpp
// cs_character.cpp:346
if (WorldSession* session = target->GetSession())
    session->KickPlayer("HandleCharacterRenameCommand GM Command renaming character");
```

踢人是为了让**真人客户端**重新加载角色名。

但 PlayerBot 没有客户端 —— **踢下线等于把 bot 弄没了**。
所以 `.botname player` 故意**不做这一步**，改成「内存 + 数据库同时改」。

**测试过程中的两处自我校正**（没有为了变绿改断言，而是回查源码）：
