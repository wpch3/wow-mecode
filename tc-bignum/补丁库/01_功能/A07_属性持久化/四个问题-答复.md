# 你报的四个问题 —— 逐条答复

---

## 问题 1：`.set clear` 恢复了暴击，没恢复力量

**这不是 bug，是两套独立系统。**

| 指令 | 管什么 | 用什么清 |
|---|---|---|
| `.set crit / hit / haste / expertise ...` | **rating 类**（暴击/命中/急速/精准） | `.set clear` |
| `.modify stat str / agi / sta / int / spi` | **五维**（力量/敏捷/耐力/智力/精神） | **`.modify stat reset`** |

底层用的是完全不同的接口：

```cpp
.set          ->  ApplyRatingMod()          // Player.h:1649
.modify stat  ->  SetStatFlatModifier()     // Unit.h:1521
```

所以清力量要用 **`.modify stat reset`**。

> 如果你希望有一条指令**同时清两者**，我可以加个 `.set clearall`，
> 内部调 `sCustomStatPersist->ClearAll(player)`（`CustomStatPersist.h:92`）——
> 那个接口会把 UNITMOD 和 RATING 两类记录一起撤销并删库。要的话说一声。

## 问题 2：`PlayerStat.Persist = 0` 没生效

**不是编译顺序的问题**（conf 是运行时读的，跟编译无关）。

真正原因：`_enabled` **只在服务器启动时读一次**。

```cpp
void CustomStatPersistMgr::LoadFromDB()   // CustomStatPersist.cpp:69
{
    LoadConfig();          // <- 只有这里读 conf
    ...
}
```

而 `LoadFromDB()` 是在 `World.cpp` 启动流程里调的。

### 所以：改完 conf 必须【重启 worldserver】

`.reload config` **不够** —— 它不会重新调 `LoadConfig()`。

### 另外检查三件事

1. 文件路径：`D:\TC-Build\bin\RelWithDebInfo\worldserver.conf.d\playerstat.conf`
2. 文件**开头必须有 `[worldserver]`**（我给的版本有，别删）
3. 启动日志里应该能看到：
   ```
   >> GM属性持久化：已关闭（PlayerStat.Persist = 0）
   ```
   没看到这行 = conf 没被读到。

## 问题 3：`.gearset 战士 200` 护甲类型不对 ← **这是我的真 bug，已修**

你说得完全对。**3.3.5 的护甲精通是 40 级才学的**：

| 职业 | 1-39 级 | 40 级起 |
|---|---|---|
| 战士 / 圣骑士 | **锁甲** | 板甲 |
| 猎人 / 萨满 | **皮甲** | 锁甲 |
| 死亡骑士 | 出生即 55 级 | 板甲 |
| 盗贼 / 德鲁伊 | 皮甲 | 皮甲 |
| 牧师 / 法师 / 术士 | 布甲 | 布甲 |

旧代码 `GetArmorSubClassForClass()` **写死"战士 = 板甲"**，
所以 20 级战士拿到一身板甲 —— 等级过滤放行了（RequiredLevel 够），
但**护甲精通没学，装备栏里全是灰的**。

### 修法：查玩家实际学没学，而不是写死

新增 `GetArmorSubClassForLevel()`：

```cpp
if (top == ITEM_SUBCLASS_ARMOR_PLATE)
{
    if (p->HasSkill(SKILL_PLATE_MAIL))    // 学了板甲精通
        return ITEM_SUBCLASS_ARMOR_PLATE;
    return ITEM_SUBCLASS_ARMOR_MAIL;      // 没学 -> 退回锁甲
}
```

**为什么查技能而不是判等级 40**：你以后要是改了技能学习等级，
或者加了自定义种族/职业，这套逻辑自动适配，不用再改代码。

API 已核实：
- `Player.h:1785` `HasSkill(uint32)` public
- `SharedDefines.h:3056` `SKILL_PLATE_MAIL = 293`
- `SharedDefines.h:3067` `SKILL_MAIL = 413`

### 现在的表现

```
.gearset 战士 200        （20 级角色）
> 正在挑选 战士 / 坦克 / 装等<=200 的锁甲...
> （20 级还没学会板甲精通，先发锁甲）
```

40 级之后再执行就自动发板甲了。

**实测 20/20 通过**，覆盖 10 个职业 × 各等级边界（39/40 级临界点）。

## 问题 4：`GearSet.MatchLevel = 0` 在哪个 conf

**我的疏漏 —— 这个键之前根本没写进任何 conf 文件。**

代码里 `sConfigMgr->GetBoolDefault("GearSet.MatchLevel", true)` 能读到，
默认 `true` 所以功能正常，但你想关的时候找不到地方。

### 已补上：`conf/worldserver.conf.d/gearset.conf`

```ini
[worldserver]

GearSet.MatchLevel = 1
```

放到 `D:\TC-Build\bin\RelWithDebInfo\worldserver.conf.d\gearset.conf`。

| 值 | 行为 |
|---|---|
| `0` | 不限等级，永远发最好的（80级装备也发给20级号） |
| `1` | 只发当前等级穿得上的（默认） |

> 这个键读的是 `GetBoolDefault`，**支持 `.reload config` 热更**，
> 不像 `PlayerStat.Persist` 要重启。
