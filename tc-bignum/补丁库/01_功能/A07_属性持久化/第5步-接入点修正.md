## 二、已改好的三处

### 改动 1：`SetRating()` 加记录（你贴的那处，位置微调）

放在 `mine[int32(cr)] = want;` **之后** —— 确保内存改成功了才写库，
避免"库里有记录但当场没效果"的不一致。

```cpp
            player->ApplyRatingMod(cr, want, true);
            mine[int32(cr)] = want;

            if (sCustomStatPersist->Enabled())
                sCustomStatPersist->Record(player->GetGUID().GetCounter(),
                    CustomStatPersistMgr::TYPE_RATING, uint8(cr), float(want));
```

> 多包了一层 `Enabled()`：`PlayerStat.Persist = 0` 时完全不写库，
> 保持原版行为（安装说明第 7 步的测试项 7 要用到）。

### 改动 2：`SetClear()` 同步清库 ← **这是你漏的**

**不加会怎样**：`.set clear` 只清内存，库里记录还在 ——
当场看着清干净了，**重登又全冒出来**。

```cpp
        for (auto& kv : mine)
        {
            if (!kv.second)
                continue;
            player->ApplyRatingMod(CombatRating(kv.first), -kv.second, true);

            // 必须同步清库，否则重登复活
            if (sCustomStatPersist->Enabled())
                sCustomStatPersist->Record(player->GetGUID().GetCounter(),
                    CustomStatPersistMgr::TYPE_RATING, uint8(kv.first), 0.0f);

            kv.second = 0;
            ++n;
        }
```

`Record(..., 0)` 表示删除该项（见 `CustomStatPersist.h:86` 注释）。
