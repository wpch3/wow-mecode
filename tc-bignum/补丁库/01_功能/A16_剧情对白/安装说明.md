## 二、怎么用

### 最常用

```
.say 你们终于来了。            选中的NPC说话
.say yell r 40 大家快跑！      周围40码所有NPC一起喊
.say emote 缓缓抬起了头        第三人称描述（橙字）
```

### 完整语法

| 指令 | 效果 |
|---|---|
| `.say <文本>` | 白字说话，近距离 |
| `.say yell <文本>` | 红字喊话，远距离 |
| `.say emote <文本>` | 橙字第三人称描述 |
| `.say boss <文本>` | **全屏BOSS提示**（默认关闭）|
| `.say whisper <文本>` | 密语（只有你看得到）|
| `.say r <半径> <文本>` | 周围所有NPC一起说 |
| `.say entry <ID> <文本>` | 指定entry的NPC说 |
| `.say me <文本>` | 自己说 |
| `.say noemote <文本>` | 不自动配表情 |
| `.say bosson` / `.say bossoff` | 开关全屏BOSS提示 |
| `.say help` | 帮助 |

### 修饰符可任意顺序组合

```
.say yell r 40 大家快跑！
.say r 40 yell 大家快跑！        <- 顺序换了也行
.say noemote entry 1234 沉默不语
.say boss r 50 你们无处可逃！
```

## 三、两个亮点

### 1. 自动配表情（和 step29 联动）

说话时按**末尾标点**自动播一次性动作，不用再敲 `.emote`：

| 结尾 | 自动动作 |
|---|---|
| `?` 或 `？` | 疑问动作 |
| `!` 或 `！` | 惊叹动作 |
| `...` 或 `…` | **不播**（沉思）|
| 其他 | 普通说话动作 |

**中文全角标点也认。** 官方 `.npc say`（cs_npc.cpp:913）
用 `text.back()` 只能判 ASCII —— 中文 `？` 是三字节 `EF BC 9F`，
取最后一个字节拿到的是 `0x9F`，判断必然出错。
本实现按**字节序列**比对，中英文标点都正确。

不想要动作就加 `noemote`。

### 2. 全屏BOSS提示（官方指令没有）

```
Unit.h:1825   TextEmote(text, target, bool isBossEmote = false)
                                      ^^^^^^^^^^^^^^^^ 官方 .npc textemote 没暴露
```

开这个 bool 会走 `CHAT_MSG_RAID_BOSS_EMOTE` —— **全屏红字**，
就是打副本时 BOSS 说话那种效果。

**默认关闭**，因为全屏红字对本地图所有人可见，滥用很吵。

```
.say bosson       开启（本次运行有效）
.say boss 你们无处可逃！
.say bossoff      关掉
```

> 想改默认值：`cs_say.cpp` 顶部 `g_allowBossEmote = false` 改 `true`。

## 四、验收清单（17条）

### 基础

```
1. .say help                     -> 显示帮助
2. 选中NPC，.say 你好            -> 白字说话，NPC播说话动作
3. .say 你是谁？                 -> 说话 + 疑问动作（中文问号）
4. .say 快跑！                   -> 说话 + 惊叹动作（中文叹号）
5. .say 嗯…                      -> 说话，但【不播动作】
6. .say noemote 你好             -> 说话，【不播动作】
7. .say yell 集合！              -> 红字，远处也能看到
8. .say emote 缓缓转过身          -> 橙字第三人称
9. .say whisper 只有你能听到      -> 密语，只有你可见
10. .say me 我自己说              -> 你的角色说话
```

### 批量

```
11. 站人多的地方 .say r 30 撤退！  -> 提示"半径30: N 个目标[说话]"
12. .say entry 1234 你好          -> 只有entry=1234的NPC说
13. .say r 30 entry 1234 你好     -> 半径内且entry匹配的才说
```

### BOSS开关

```
14. .say boss 测试               -> 应提示"当前关闭，用 .say bosson 开启"
15. .say bosson                  -> 提示已开启
16. .say boss 你们无处可逃！      -> 全屏红字
17. .say bossoff                 -> 关闭
```

### 错误处理

```
18. 不选目标直接 .say 你好        -> 提示没选中，并给替代用法
19. .say r                       -> 提示用法
20. .say r 999 你好              -> 提示半径需0-500
21. .say entry abc 你好          -> 提示用法

```

## 六、已知限制

| 限制 | 说明 |
|---|---|
| **不支持延时台词** | GM指令是一次性调用，没有持续Update的宿主。<br>多句台词请手动逐条敲，自动序列留给将来的 `.timeline` |
| 密语只能给自己 | `Whisper` 需要 `Player*`，NPC对NPC密语无意义 |
| `entry` 搜索半径固定200码 | 超范围的同entry NPC不受影响 |
| NPCBot/宠物被排除 | 沿用 `.nst`/`.emote` 的保护 |
| BOSS开关不持久 | 重启服务端后恢复默认关闭 |

### 为什么不做延时（已查证）

| 方案 | 结论 |
|---|---|
| `TaskScheduler` | 存在，但需宿主持续Update |
| Creature内置scheduler | **没有** |
| `events.ScheduleEvent` | 只在CreatureAI内部可用 |
| 注入AI（像`.dummy`）| 会**顶掉NPC原有AI**，副作用大 |
