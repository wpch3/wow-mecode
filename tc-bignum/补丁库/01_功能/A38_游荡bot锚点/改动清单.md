# A38 游荡bot锚点 —— 保持游荡 + move 可定点

目标：bot 仍然是游荡bot（会冒险、会打怪、会走动），
但活动范围被限制在你指定的锚点半径内，
`.npcbot move` 用来设置/移动这个锚点。

零新建表。锚点存在现成的 `characters_npcbot.miscvalues` 字段里，自动落库、重启自动重载。

**共 5 处改动，全部有代码围栏，可直接复制不会错位。**

---

## 为什么原来 move 无效

`bot_ai.cpp:19054-19067`

```cpp
void bot_ai::GetHomePosition(uint16& mapid, Position* pos) const
{
    if (IsWanderer())
    {
        mapid = _travel_node_cur->GetMapId();
        pos->Relocate(homepos);
    }
    else
    {
        CreatureData const* data = me->GetCreatureData();
        mapid = data->mapId;
        pos->Relocate(data->spawnPoint);
    }
}
```

游荡bot只认路点，不读 `creature` 表。move 改的是 `creature` 表。

本补丁的做法：不动这个函数，改为在**选下一个路点**时过滤掉锚点范围外的节点。

## 改动四 / 共5处 —— bot_ai.cpp 让选路点时遵守锚点

文件同上。函数 `bot_ai::GetNextWanderNode`（约 19123-19191 行）

> **【重要】`node_viable` 那个 lambda 完全不要动，保持 `static`。**
>
> 我第一版想给它加 `this` 捕获，用 g++ 实测报错：
>
> ```text
> error: 'node_viable' is not captured
> note: the lambda has no capture-default
> ```
>
> 因为内层 `DoForAllMapWPs` 的 lambda 捕获列表里没有它，
> static 无捕获时能当函数指针用，一旦捕获 `this` 就用不了了。
>
> 正确做法：在 4 个调用点分别加锚点判断，并给 3 个内层 lambda 补 `this` 捕获。

### 4-1 第一个内层 lambda（约 19147-19148 行）

搜索原文：

```cpp
            WanderNode::DoForAllMapWPs(_travel_node_cur->GetMapId(), [&nlinks, lvl = lvl, fac = faction, pos = fromPos](WanderNode const* wp) {
                if (pos->GetExactDist2d(wp) < MAX_WANDER_NODE_DISTANCE && IsWanderNodeAvailableForBotFaction(wp, fac, true) && node_viable(wp, lvl) && !wp->HasFlag(BotWPFlags::BOTWP_FLAG_NOT_A_START_POINT))
```

替换为：

```cpp
            WanderNode::DoForAllMapWPs(_travel_node_cur->GetMapId(), [this, &nlinks, lvl = lvl, fac = faction, pos = fromPos](WanderNode const* wp) {
                if (pos->GetExactDist2d(wp) < MAX_WANDER_NODE_DISTANCE && IsWanderNodeAvailableForBotFaction(wp, fac, true) && node_viable(wp, lvl) && IsNodeWithinAnchor(wp) && !wp->HasFlag(BotWPFlags::BOTWP_FLAG_NOT_A_START_POINT))
```

改了两处：开头加 `this,`，条件里加 `&& IsNodeWithinAnchor(wp)`

### 4-2 第二个内层 lambda（约 19158-19160 行）

搜索原文：

```cpp
        WanderNode::DoForAllMapWPs(_travel_node_cur->GetMapId(), [&node_new, &mindist, lvl = lvl, fac = faction, pos = fromPos](WanderNode const* wp) {
            float dist = pos->GetExactDist2d(wp);
            if (dist < mindist && IsWanderNodeAvailableForBotFaction(wp, fac, false) && node_viable(wp, lvl) && !wp->HasFlag(BotWPFlags::BOTWP_FLAG_NOT_A_START_POINT))
```

替换为：

```cpp
        WanderNode::DoForAllMapWPs(_travel_node_cur->GetMapId(), [this, &node_new, &mindist, lvl = lvl, fac = faction, pos = fromPos](WanderNode const* wp) {
            float dist = pos->GetExactDist2d(wp);
            if (dist < mindist && IsWanderNodeAvailableForBotFaction(wp, fac, false) && node_viable(wp, lvl) && IsNodeWithinAnchor(wp) && !wp->HasFlag(BotWPFlags::BOTWP_FLAG_NOT_A_START_POINT))
```

### 4-3 链接遍历（约 19172 行，这里是普通 for，不是 lambda）

搜索原文：

```cpp
        if (IsWanderNodeAvailableForBotFaction(wpl.wp, faction, false) && node_viable(wpl.wp, lvl))
```

替换为：

```cpp
        if (IsWanderNodeAvailableForBotFaction(wpl.wp, faction, false) && node_viable(wpl.wp, lvl) && IsNodeWithinAnchor(wpl.wp))
```

### 4-4 最后的兜底传送（约 19184-19185 行）—— **此处不要改**

这一处是「找不到可达节点时全图找一个传送过去」，
后面紧跟 `ASSERT(!nlinks.empty())`（`:19189`）。
如果锚点范围内一个 SPAWN 节点都没有，加了过滤会**崩服**。

确认它长这样，**保持原样**：

```cpp
    WanderNode::DoForAllWPs([&nlinks, lvl = lvl, fac = faction](WanderNode const* wp) {
        if (IsWanderNodeAvailableForBotFaction(wp, fac, true) && wp->HasFlag(BotWPFlags::BOTWP_FLAG_SPAWN) && node_viable(wp, lvl) && !wp->HasFlag(BotWPFlags::BOTWP_FLAG_NOT_A_START_POINT))
```

理由：宁可让 bot 偶尔逃生一次，也不能崩服。
实际影响很小：4-1/4-2/4-3 已覆盖正常选点，走到 4-4 说明当前位置已无路可走。

## 使用

设置锚点（bot 仍然游荡，但只在你脚下 250 码内活动）：

```text
选中游荡bot -> .npcbot move
或          -> .npcbot move 70231
```

移动锚点：站到新位置再执行一次 `.npcbot move`

锚点会自动落库（`bot_ai.cpp:17651` 的 5 秒定时器），重启后自动恢复。
