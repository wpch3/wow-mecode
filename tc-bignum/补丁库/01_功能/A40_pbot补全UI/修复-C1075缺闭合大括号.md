修复 C1075「未找到匹配令牌」—— 少了一个 }

================================================================
 一句话根因
================================================================

    C1075 "{": 未找到匹配令牌   pbot_autoaccept.cpp 162

162 行的 TryAcceptGroup 函数【少了结尾的 }】。

后面所有函数都被"吃"进这个没闭合的块里，
所以才有一长串「本地函数定义是非法的」。

那 20 多条 C2267/C2601/C2246 全是连锁反应，
【只要补回一个 } 就全部消失】。

其余 C1069 和 LNK1181 也是连带的，不用管。

================================================================
 怎么发生的
================================================================

A40 改动一让你替换 TryAcceptGroup 的结尾：

    原文最后是：
        if (leader && leader->GetSession())
            ChatHandler(leader->GetSession()).PSendSysMessage(
                "|cff00ff00[%s]|r 接受了你的组队邀请。", bot->GetName().c_str());
    }                                    <<< 这个 } 是函数结尾

替换时如果只粘贴了前面几行、漏了最后那个 }，就会变成现在这样。

================================================================
 修法
================================================================

文件 D:\TrinityCore\src\server\scripts\Commands\pbot_autoaccept.cpp

用 Ctrl+G 跳到 162 行，往下看到 216 行之间。

正确的完整形态应该是这样（从 AddMember 到函数结尾）：

    if (!group->AddMember(bot))                 // Group.h:209 public
        return;

    group->BroadcastGroupUpdate();              // Group.h:350 public

    // A40: bot 不该当队长。
    if (leader && group->IsLeader(bot->GetGUID()) && leader != bot)
        group->ChangeLeader(leader->GetGUID());

    if (leader && leader->GetSession())
        ChatHandler(leader->GetSession()).PSendSysMessage(
            "|cff00ff00[%s]|r 接受了你的组队邀请。", bot->GetName().c_str());
}

static void TryAcceptGuild(Player* bot)
{

注意两点：

    1. PSendSysMessage 那句后面必须有一个单独成行的  }
    2. 紧接着才是 static void TryAcceptGuild(Player* bot)

如果你现在看到的是这样（缺 }）：

            "|cff00ff00[%s]|r 接受了你的组队邀请。", bot->GetName().c_str());

static void TryAcceptGuild(Player* bot)
{

那就在 PSendSysMessage 那行和 static void TryAcceptGuild 之间
补上一个单独成行的  }  和一个空行。

================================================================
 VS 里最快的定位办法
================================================================

方法1：折叠代码块看结构

    Ctrl+M 然后 Ctrl+O    （折叠所有）

    正常情况下每个函数会折叠成一行，长这样：
        static void TryAcceptGroup(Player* bot) {...}
        static void TryAcceptGuild(Player* bot) {...}

    如果 TryAcceptGroup 折叠后【把后面的函数都包进去了】，
    就说明它没闭合。

方法2：点大括号看配对

    把光标点在 162 行那个 { 上，
    VS 会把配对的 } 高亮成灰色。

    如果高亮跑到了文件很后面（比如 750 行），
    说明中间少了一个 }。

================================================================
 这类错误的通用识别法
================================================================

看到一长串「本地函数定义是非法的」(C2601)
或「具有块范围的静态函数非法」(C2267)：

    99% 是【某处少了一个 }】

    直接看错误列表最下面的 C1075，
    它会告诉你【哪一行的 { 没闭合】。

    不要一个个去看那些 C2601，它们全是连锁反应。
