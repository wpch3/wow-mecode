# 游荡 bot 没有窗口 —— 根因分析

> 用户澄清：「游荡的npc完全没有召唤的npc的谈话窗口，
> 召唤的npc像npc一样有谈话窗口而且可以控制」
> 「没有窗口，什么都做不了」

---

## 一、我之前理解偏了

前面几轮我一直在解决"对话框会不会被关掉"（`IsCasting` / 炉石死循环），
**那些确实是真问题，也确实修好了**（用户实测 `.bd` 变绿）。

但用户要的是**窗口里的内容**。
对话框能弹出来 ≠ 里面有东西。

---

## 二、根因：菜单项一个都没有，窗口就自动关

`bot_ai.cpp:7979`（OnGossipHello 结尾）：

```cpp
if (!menus)
{
    player->PlayerTalkClass->SendCloseGossip();   // <- 一个菜单项都没有就直接关窗
    return true;
}

AddGossipItemFor(player, GOSSIP_ICON_CHAT, ..., BOT_TEXT_NEVERMIND, ...);
player->PlayerTalkClass->SendGossipMenu(gossipTextId, me->GetGUID());
```

**`menus` 只在这 7 个地方被置 true**：

| 行号 | 条件 | 游荡bot满足吗 |
|---|---|---|
| 7758 | `player->IsGameMaster()` | GM才行 |
| **7813** | **`... && IAmFree() && !IsWanderer()`** | **不满足（是游荡bot）** |
| 7822 | **`if (_botData->owner)`** 且 `player == master` | **不满足（无主）** |
| 7870/7882/7891 | 在 7822 的 `owner` 块内部 | 同上 |
| 7975 | `_botclass >= BOT_CLASS_EX_START` | 只有特殊职业 |

### 结论

```
游荡bot（无主）
  -> 7813 被 !IsWanderer() 挡住      = 没有【招募】选项
  -> 7822 被 if(_botData->owner) 挡住 = 没有【装备/角色/阵型/技能】等全部控制菜单
  -> menus 始终 false
  -> SendCloseGossip()  窗口一闪而过
```

**这就是"完全没有窗口"的真正原因。**

## 四、用户真正要的是什么

> 「我不只想要谈话窗口，我也想要给他真正玩家的各种ui，
> 比如背包和技能，天赋等」

这是**两个层次的需求**：

### 层次 1：游荡bot要有和雇佣bot一样的完整菜单

雇佣bot（`_botData->owner` 有值）能看到：

```
bot_ai.cpp:7827-7840 附近
  管理装备      GOSSIP_SENDER_EQUIPMENT
  管理角色      GOSSIP_SENDER_ROLES_MAIN
  管理阵型      GOSSIP_SENDER_FORMATION
  管理技能      GOSSIP_SENDER_ABILITIES
  ...
```

**游荡bot一个都看不到。**

### 层次 2：真正的玩家UI（背包/技能/天赋）

这个**比 Gossip 菜单难得多**，因为：

- Gossip 菜单是**服务端发文字列表**，客户端渲染成对话框
- 玩家背包/技能/天赋是**客户端固有UI**，只对 `Player` 对象开放
- NPCBot 是 `Creature`，客户端不会为它开背包界面

**但 NPCBot 已经用 Gossip 模拟了装备管理**（`GOSSIP_SENDER_EQUIPMENT`），
这是可行路线：**用 Gossip 菜单模拟出背包/技能/天赋的界面**。

---

## 五、解法分层

### 第 1 步（本次做）：让游荡bot拥有完整菜单

改 `bot_ai.cpp:7822`：

```cpp
// 原文
if (_botData->owner)

// 改为：游荡bot且开关打开时，也进这个块
if (_botData->owner || (IsWanderer() && BotCfg::IsWanderingBotHireEnabled()))
```

**但块内部有 `if (player == master)` 判定**，
游荡bot没有 master，还要一并处理。

### 第 2 步：验证招募能否成功

游荡bot招募后会变成正常bot，届时所有菜单自动可用。
**如果第1步做完能招募，第2步的问题就自动消失。**

### 第 3 步（长期）：Gossip 模拟玩家UI

- 背包：列出 bot 携带的物品（接 step34 的虚拟背包）
- 技能：列出 bot 会的法术，可开关
- 天赋：列出天赋树，可点

**这三个都是纯数据 + Gossip 菜单，没有引擎墙。**

---

## 六、下一步

**先用 `.bd` 确认招募选项到底有没有出现**，
因为这决定了第1步要改几处。

如果 `.bd` 显示所有条件都通过，但右键还是没窗口，
那就是 `menus` 的问题，按第五章第1步改。
