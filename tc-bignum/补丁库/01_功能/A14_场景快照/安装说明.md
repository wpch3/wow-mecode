# step28 场景快照 `.scene` —— 安装说明

## 一、能做什么

**做剧情的后悔药。** 把一片区域所有 NPC 的完整状态存下来，
之后一条指令完整还原。反复调试不怕改坏。

```
.scene save 酒馆 60      -> 把周围60码所有NPC存成"酒馆"快照
（随便怎么改，摆位置、改状态、换模型...）
.scene load 酒馆         -> 一键回到刚才的样子
```

它是其他剧情工具（`.emote` / `.say` / `.follow` / `.freeze`）的**地基**——
有了后悔药，后面所有调试都放心。

---

## 二、指令

| 命令 | 作用 |
|---|---|
| `.scene save <名字> [半径]` | 存快照（默认 50 码，上限 500）|
| `.scene load <名字>` | 还原 |
| `.scene rebuild <名字>` | 还原，**且重新召唤已被删掉的 NPC** |
| `.scene list` | 所有快照 |
| `.scene info <名字>` | 看快照里有什么 |
| `.scene del <名字>` | 删除 |

中文别名：`保存` `还原` `重建` `列表` `详情` `删除`

**同名快照会直接覆盖**（会提示）。

---

## 三、存了什么（你要求的"全存"）

| 项 | 说明 |
|---|---|
| 位置 x/y/z + 朝向 | 摆位 |
| **unit_flags** | `.nst` 的六档状态就在这里 |
| **faction** | 阵营，和 unit_flags 一起决定能不能打 |
| **react** | 被动/防御/主动 |
| display + scale | 模型和缩放 |
| stand + emote | 站姿和情绪动作 |
| npcflag | 商人/任务给予者等功能位 |
| entry + guid | 身份，guid=0 表示临时召唤物 |

**和 `.nst` 完全打通** —— 你用 `.nst story` 设的剧情档，
存快照会一起存，还原时自动恢复。

## 五、实现要点

### guid = 0 的意思

```cpp
n.guid = uint32(c->GetSpawnId());     // Creature.h:98
```

`GetSpawnId()` 只有**数据库里刷出来的 NPC** 才有值。
`.service` / `.dummy` 这类临时召唤物返回 0。

- **有 guid**：`load` 时用 `Map::GetCreatureBySpawnId()` 精确找回**原来那只**
- **guid=0**：找不回来，只能用 `rebuild` 按 entry **重新召唤一只新的**

存快照时会提示有几个是临时召唤物。

### 为什么位置要用 NearTeleportTo

```cpp
c->NearTeleportTo(n.x, n.y, n.z, n.o);    // Unit.h:1201
```

直接 `Relocate()` 只改服务端坐标，**客户端看到的还在原地**。
`NearTeleportTo` 会正确发同步包。

### 模型要设两个字段

```cpp
c->SetDisplayId(n.display);          // Unit.h:1595
c->SetNativeDisplayId(n.display);    // Unit.h:1598
```

只设第一个，某些刷新路径会把模型回退回模板值。这个坑在 `.dummy` 时踩过。

### SQL 用 fmt 风格占位符

这个版本的 `PQuery`/`DirectPExecute` 是 **`{}` 占位符**，不是 `%u`/`%s`：

```cpp
// DatabaseWorkerPool.h:122
QueryResult PQuery(Trinity::FormatString<Args...> sql, Args&&... args)
```

我一开始按老式 printf 风格写，全部改过来了。

## 六、安全设计

- **NPCBot 绝不入快照**：`IsNPCBotOrPet()` 直接跳过
- 宠物/图腾跳过
- 半径钳到 **500 码**
- 单快照 NPC 上限 **2000**，防手滑存整张地图
- 名字做了 SQL 转义（`Esc()`），含引号也不会注入

## 七、典型用法

**调试剧情场景**

```
.scene save 序章_原始 80        # 先存原始状态
（大改一通）
.scene load 序章_原始           # 不满意，一键还原
```

**做多个版本对比**

```
.scene save 婚礼_方案A 50
（改摆位）
.scene save 婚礼_方案B 50
.scene load 婚礼_方案A          # 来回切换对比
```

**搬运场景**（配合 rebuild）

```
.scene save 营地 60
（去另一张地图）
.scene rebuild 营地             # 按 entry 在新位置重建
```

> 注意 `rebuild` 用的是快照里存的**绝对坐标**，
> 跨地图搬运会还原到原坐标。跨图搬运功能等后续版本。
