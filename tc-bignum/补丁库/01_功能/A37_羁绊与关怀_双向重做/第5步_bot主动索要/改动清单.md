# A37 第5步：bot 主动索要

前四步做的是**你给 bot 东西**。这一步反过来：**bot 会开口向你要**。

这是「关怀双向」的最后一块 —— A20 只有 bot 主动给你，
第2-4步做了你给 bot，现在补上 bot 主动跟你要。

**共 5 处改动，复用 A20 现成的计时器框架，不用重跑 CMake。**

---

## 效果

```text
bot 血量 30%    -> "我这伤口还在流血……有绷带吗？"
bot 装备快断了  -> "我这把剑快断了。"
bot 饿了        -> 生疏时："……你还有吃的吗？"
                   深交时："饿了。你包里肯定还有。"
```

**羁绊越深，说话越随意，而且开口越频繁**（冷却减半）。

台词全在 `world.npcbot_request_text`，**已有 17 条**（第1步就入库了）。

## 索要优先级（已真编译验证）

按紧急程度从高到低判断，命中一个就停：

| 优先级 | 条件 | 索要类型 |
|---|---|---|
| 1 | 有装备已损坏 或 2件以上耐久<30% | 修装备 (4) |
| 2 | 血量 < 35% | 绷带 (3) |
| 3 | 血量 < 60% | 食物 (1) |
| 4 | 有法力且法力 < 40% | 水 (2) |
| 5 | 正在休息 | 想休息 (5) |
| 6 | 最近死过3次以上 | 情绪低落 (6) |
| — | 都健康 | 不索要 |

**无法力职业（战士/盗贼）不会要水** —— 这个专门测过。

// ---------------------------------------------------------------------------
//  A37 第5步：加载索要台词
// ---------------------------------------------------------------------------
void BotCompanionMgr::LoadRequestTexts()
{
    uint32 oldMSTime = getMSTime();
    _requestTexts.clear();

    //                                            0   1             2          3          4     5      6
    QueryResult result = WorldDatabase.Query("SELECT id, request_type, bond_tier, bot_class, text, emote, weight FROM npcbot_request_text");
    if (!result)
    {
        TC_LOG_INFO("server.loading", ">> Loaded 0 npcbot request texts. Table `npcbot_request_text` is empty.");
        return;
    }

    uint32 count = 0;
    do
    {
        Field* fields = result->Fetch();

        CompanionRequestText t;
        t.Id          = fields[0].GetUInt32();
        t.RequestType = fields[1].GetUInt8();
        t.BondTier    = fields[2].GetUInt8();
        t.BotClass    = fields[3].GetUInt8();
        t.Text        = fields[4].GetString();
        t.Emote       = fields[5].GetUInt32();
        t.Weight      = fields[6].GetUInt8();

        if (t.Text.empty())
        {
            TC_LOG_ERROR("sql.sql", "npcbot_request_text id {} has empty text, skipped.", t.Id);
            continue;
        }
        if (t.RequestType == BOT_REQUEST_NONE || t.RequestType >= BOT_REQUEST_MAX)
        {
            TC_LOG_ERROR("sql.sql", "npcbot_request_text id {} has invalid request_type {}, skipped.", t.Id, t.RequestType);
            continue;
        }
        if (t.Weight == 0)
            t.Weight = 1;

        _requestTexts.push_back(std::move(t));
        ++count;
    }
    while (result->NextRow());

    TC_LOG_INFO("server.loading", ">> Loaded {} npcbot request texts in {} ms", count, GetMSTimeDiffToNow(oldMSTime));
}

// ---------------------------------------------------------------------------
//  A37 第5步：选索要台词（三轮放宽，和第3步同款）
// ---------------------------------------------------------------------------
CompanionRequestText const* BotCompanionMgr::PickRequestText(uint8 requestType, uint8 bondTier, uint8 botClass) const
{
    std::vector<CompanionRequestText const*> pool;

    for (CompanionRequestText const& t : _requestTexts)
        if (t.RequestType == requestType && (t.BondTier == bondTier || t.BondTier == 0) && t.BotClass == botClass)
            pool.push_back(&t);

    if (pool.empty())
        for (CompanionRequestText const& t : _requestTexts)
            if (t.RequestType == requestType && (t.BondTier == bondTier || t.BondTier == 0) && t.BotClass == 0)
                pool.push_back(&t);

    if (pool.empty())
        for (CompanionRequestText const& t : _requestTexts)
            if (t.RequestType == requestType && t.BotClass == 0)
                pool.push_back(&t);

    if (pool.empty())
        return nullptr;

    uint32 total = 0;
    for (CompanionRequestText const* t : pool)
        total += t->Weight;

    if (!total)
        return pool[0];

    uint32 roll = urand(0, total - 1);
    for (CompanionRequestText const* t : pool)
    {
        if (roll < t->Weight)
            return t;
        roll -= t->Weight;
    }

    return pool.back();
}

// ---------------------------------------------------------------------------
//  A37 第5步：羁绊越深，越敢开口
// ---------------------------------------------------------------------------
uint32 BotCompanionMgr::CalcRequestCooldown(uint8 bondTier, uint32 baseMs)
{
    switch (bondTier)
    {
        case 3:  return baseMs / 2;
        case 2:  return baseMs;
        default: return baseMs * 2;
    }
}

// ---------------------------------------------------------------------------
//  A37 第5步：记录一次索要
// ---------------------------------------------------------------------------
void BotCompanionMgr::RecordRequest(uint32 botId, uint8 botKind, uint32 ownerGuid,
                                    uint8 requestType)
{
    uint32 now = uint32(GameTime::GetGameTime());

    CharacterDatabase.PExecute(
        "INSERT INTO npcbot_request_log (bot_id, bot_kind, owner_guid, request_type, "
        "ask_time, answered, answer_time) VALUES ({}, {}, {}, {}, {}, 0, 0)",
        botId, uint32(botKind), ownerGuid, uint32(requestType), now);

    CharacterDatabase.PExecute(
        "UPDATE npcbot_bond SET last_request = {} WHERE bot_id = {} AND owner_guid = {}",
        now, botId, ownerGuid);
}

// ---------------------------------------------------------------------------
//  A37 第5步：查这次索要有没有被满足（10分钟内收到对口的东西）
// ---------------------------------------------------------------------------
bool BotCompanionMgr::WasRequestMet(uint32 botId, uint8 botKind, uint32 ownerGuid, uint8 requestType)
{
    uint32 since = uint32(GameTime::GetGameTime()) - 600;

    QueryResult res = CharacterDatabase.PQuery(
        "SELECT COUNT(*) FROM npcbot_request_log WHERE bot_id = {} AND bot_kind = {} "
        "AND owner_guid = {} AND request_type = {} AND answered = 1 AND ask_time > {}",
        botId, uint32(botKind), ownerGuid, uint32(requestType), since);

    return res && res->Fetch()[0].GetUInt32() > 0;
}

uint8 bot_ai::DecideRequestType() const
{
    uint32 brokenCount = 0;
    uint32 lowDuraCount = 0;
    for (uint8 i = BOT_SLOT_MAINHAND; i != BOT_INVENTORY_SIZE; ++i)
    {
        Item const* eq = GetEquips(i);
        if (!eq)
            continue;
        uint32 maxDura = eq->GetUInt32Value(ITEM_FIELD_MAXDURABILITY);
        if (!maxDura)
            continue;
        uint32 curDura = eq->GetUInt32Value(ITEM_FIELD_DURABILITY);
        if (curDura == 0)
            ++brokenCount;
        else if (curDura * 100 / maxDura < 30)
            ++lowDuraCount;
    }

    if (brokenCount > 0 || lowDuraCount >= 2)
        return BOT_REQUEST_REPAIR;

    float hpPct = me->GetHealthPct();
    if (hpPct < 35.0f)
        return BOT_REQUEST_BANDAGE;
    if (hpPct < 60.0f)
        return BOT_REQUEST_FOOD;

    if (me->GetMaxPower(POWER_MANA) > 1 && me->GetPowerPct(POWER_MANA) < 40.0f)
        return BOT_REQUEST_DRINK;

    return BOT_REQUEST_NONE;
}

void bot_ai::UpdateBotRequest(uint32 diff)
{
    if (_requestTimer)
        return;

    if (IAmFree() || !master || !master->IsInWorld())
        return;
    if (!me->IsInWorld() || !me->IsAlive() || me->IsInCombat())
        return;
    if (master->IsInCombat())
        return;
    if (me->GetDistance(master) > 30.0f)
        return;

    uint8 reqType = DecideRequestType();
    if (reqType == BOT_REQUEST_NONE)
    {
        _requestTimer = 30000;
        return;
    }

    if (reqType == _lastRequestType && urand(0, 2))
    {
        _requestTimer = 60000;
        return;
    }

    uint8 tier = GetBondTierWith(master);

    CompanionRequestText const* rt = sBotCompanionMgr->PickRequestText(reqType, tier, uint8(_botclass));
    if (!rt)
    {
        _requestTimer = 120000;
        return;
    }

    BotWhisper(rt->Text, master);
    if (rt->Emote)
        me->HandleEmoteCommand(Emote(rt->Emote));

    BotCompanionMgr::RecordRequest(me->GetEntry(), 0, master->GetGUID().GetCounter(), reqType);

    _lastRequestType = reqType;
    _requestTimer = BotCompanionMgr::CalcRequestCooldown(tier, urand(180000, 300000));
}

## 设计说明

### 为什么不直接给 bot 塞东西

索要**只是说话**，不自动拿你的东西。你听到后自己决定给不给
（用第2步的赠予菜单）。这样才有"互动感"，
而不是 bot 单方面从你背包扣东西。

### `_lastRequestType` 防重复

如果连续两次都想要同一样东西，有 2/3 概率跳过这次，
避免 bot 变成复读机。

### 为什么要判 `me->GetDistance(master) > 30.0f`

太远了喊话没意义。而且这个判断很便宜，能挡掉大部分无谓计算。

### 冷却基数 3-5 分钟

`urand(180000, 300000)` 再按 tier 调整：

```text
深交  1.5-2.5 分钟
熟悉  3-5 分钟
生疏  6-10 分钟
```

不会烦人，但也不会长时间沉默。
