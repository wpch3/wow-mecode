## 一、直接回答：**是的，我根本没做这个功能**

### 1.1 你点的那个按钮是【上游自带的】，不是我做的

`bot_ai.cpp:7833`：

```cpp
AddGossipItemFor(player, GOSSIP_ICON_TALK,
    LocalizedNpcText(player, BOT_TEXT_GIVE_CONSUMABLE),
    GOSSIP_SENDER_USEITEM, GOSSIP_ACTION_INFO_DEF + 1);
```

这是 NPCBot 模块原生的功能。

### 1.2 而且它的真实作用【不是"送东西给bot"】

点进去选一个物品后，走 `GOSSIP_SENDER_USEITEM_USE`（`bot_ai.cpp:10218`），
最后一步是：

```cpp
// bot_ai.cpp:10263-10266
// cast item spell
SpellCastTargets targets;
targets.SetUnitTarget(me);
_castBotItemUseSpell(item, targets);
```

**它是让 bot【当场喝掉/用掉】这个物品，物品直接消失。**

**不是**收进 bot 的背包，**不是**赠予，**没有**任何情感反馈。

功能名 `BOT_TEXT_GIVE_CONSUMABLE` 直译是「给予消耗品」，
实际语义是「**让bot使用一个消耗品**」。

## 二、为什么你点了没反应 —— 列表是空的

`bot_ai.cpp:10281` 的 `is_consumable_item` 过滤器**极其严苛**。

一个物品要出现在列表里，必须**同时满足 7 个条件**：

```cpp
static const auto is_consumable_item = [](Item const* item, Creature const* bot) {
    if (ItemTemplate const* proto = item ? item->GetTemplate() : nullptr)
    {
        if (!(proto->Class != ITEM_CLASS_WEAPON && proto->Class != ITEM_CLASS_ARMOR &&
            (proto->AllowableClass == 0 || (proto->AllowableClass & (1u << (bot->GetBotClass() - 1)))) &&
            proto->RequiredSkill == 0 && proto->RequiredSpell == 0 &&
            bot->GetLevel() >= proto->RequiredLevel))
            return false;
        // ... 还要有非被动法术
        for (auto const& ispell: proto->Effects)
        {
            ...
            if (effect.TargetA.GetTarget() != TARGET_UNIT_CASTER || effect.TargetB.GetTarget() != 0)
                valid_effect = false;      // <-- 【最狠的一条】
            ...
            switch (effect.Effect)
            {
                case SPELL_EFFECT_SUMMON:
                case SPELL_EFFECT_CREATE_ITEM:
                    valid_effect = false;
            }
        }
        return has_spell;
    }
    return false;
};
```

| # | 条件 | 挡掉了什么 |
|---|---|---|
| 1 | 不能是 WEAPON / ARMOR | **所有装备** |
| 2 | AllowableClass 匹配bot职业 | 职业限定物品 |
| 3 | RequiredSkill == 0 | 需要技能的（大部分材料） |
| 4 | RequiredSpell == 0 | 需要配方的 |
| 5 | bot等级 >= RequiredLevel | 高级物品 |
| 6 | **必须有非被动法术，且所有效果 TargetA==TARGET_UNIT_CASTER、TargetB==0** | **所有没有"对自己使用"效果的物品** |
| 7 | 效果不能是 SUMMON / CREATE_ITEM | 召唤物、造物品的 |

### 结果：几乎只有【药水/绷带类】能通过

- **普通食物** -> 很多是 TargetA 不匹配，被条件6挡掉
- **材料/矿石/布** -> 没有法术效果，条件6挡掉
- **装备** -> 条件1挡掉
- **任务物品** -> 条件6挡掉

**你背包里如果没有符合条件的药水，列表就是空的 -> 点了像没反应。**

**语义和"赠予"根本不同**，不能改造，只能**新建通道**。

```

             |
             +-- 列出你背包里【所有可交易物品】（不做严苛过滤）
             |
             +-- 选中 -> bot 收下 -> 存进 bot 的持久化背包
             |
             +-- bot 根据物品类型 + 羁绊等级 给出情感反馈

             +-- 记录进 npcbot_bond.gifts_to_bot
```
