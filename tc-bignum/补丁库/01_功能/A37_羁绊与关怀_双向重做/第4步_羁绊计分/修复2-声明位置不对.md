## 剩下的问题：声明加了，但编译器看不见

### 错误组合说明了一切

```text
C2039 "GetGiftNeedState": 不是 "bot_ai" 的成员
C2270 "GetGiftNeedState": 非成员函数上不允许修饰符
```

`C2270` 说的"修饰符"是函数末尾那个 `const`。
**只有成员函数才能带 `const`** —— 编译器说它不是成员函数，
就是因为 `bot_ai.h` 里找不到对应声明。

### 三种可能，请逐个确认

我实查了上游 `bot_ai.h` 的结构：

```text
19-47 行   前向声明区（class Aura; class Group; ...）
51 行      class bot_ai : public CreatureAI
53 行      public:
   ...
867 行     };            <- 类在这里结束
869 行     #endif
```

**声明必须在 53 行到 867 行之间。**

| 可能 | 现象 |
|---|---|
| A. 加到了 51 行之前（前向声明区） | 就是你现在这样 |
| B. 加到了 867 行之后 | 同上 |
| C. 加到了 `private:` 段里 | 不会报 C2039，会报"无法访问" |
| D. 根本没保存 / 改了别的同名文件 | 同 A |

## 怎么确认位置对了（不用编译）

在 `bot_ai.h` 里，把光标放到你刚加的 `uint8 GetGiftNeedState(...)` 那一行，
看 **VS 编辑器窗口顶部的导航栏**（在代码上方）。

它应该显示：

```text
bot_ai   ->   GetGiftNeedState(uint8 itemKind)
```

**左边必须是 `bot_ai`。** 如果显示的是"全局范围"或空白，说明还在类外面。

### 另一个办法：看行号

你加的那几行，**行号必须在 53 到 867 之间**。
（`bot_ai` 类从 51 行开始，867 行的 `};` 结束）

如果你加在了 19-47 行那片（都是 `class Aura;` `class Group;` 这种单行声明），
那就是加错地方了。
