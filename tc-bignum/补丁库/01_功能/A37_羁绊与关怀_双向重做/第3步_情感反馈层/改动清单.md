# A37 第3步：情感反馈层

第2步 bot 收到礼物只会说一句固定的「谢谢你！」。
这一步让它**根据物品种类、自己的需求、和你的羁绊深浅，说不同的话**，
食物药水还会**当场吃掉/喝掉**（混合处置的另一半）。

**扩展已有的 `bot_companion.cpp/h`（A20 的模块），文件已存在 -> 不用重跑 CMake。**

---

## 这一步做完的效果

```text
你给它一块面包
  |
  +-- 它正好饿了(血量低)  -> "正好，我确实有点饿了。" + 【当场吃掉】
  +-- 它不饿              -> "先收着，等会儿再吃。"   + 存进银行
  +-- 你俩很熟了          -> "{player}，又给我带吃的？你把我当小孩了。"

你给它一件紫装
  -> "这……这么贵重的东西？我收下了。" + 鞠躬表情

你给它一块破布
  -> 生疏时："呃……谢谢。"
  -> 深交时："你从哪儿捡的破烂……行吧，我留着。"
```

台词**全部来自数据库**（`world.npcbot_gift_text`，已有 49 条），
改一句不用重编译。

## 四个维度怎么配

`npcbot_gift_text` 表的选词维度（第1步已建好）：

| 字段 | 含义 | 取值 |
|---|---|---|
| `item_kind` | 物品种类 | 1食物 2水 3药水 4装备 5珍稀 6垃圾 **7通用(兜底)** |
| `need_state` | bot 当前需不需要 | **0任意** 1正需要 2不需要 |
| `bond_tier` | 羁绊深浅 | **0任意** 1生疏(0-1级) 2熟悉(2-3级) 3深交(4-5级) |
| `react_type` | 反应方式 | 0收下 1当场用 2拒绝 |
| `bot_class` | 限定职业 | **0通用** |

**选词是三轮放宽**（已真编译验证）：

```text
第1轮  item_kind + react_type + need_state + bond_tier + bot_class 全匹配
第2轮  放宽 bot_class -> 0
第3轮  落到 item_kind=7 通用兜底
```

保证**永远能选到词**，不会出现 bot 沉默。

// ---------------------------------------------------------------------------
//  A37 第3步：加载礼物反馈台词
// ---------------------------------------------------------------------------
void BotCompanionMgr::LoadGiftTexts()
{
    uint32 oldMSTime = getMSTime();
    _giftTexts.clear();

    //                                            0   1          2           3          4           5          6     7      8
    QueryResult result = WorldDatabase.Query("SELECT id, item_kind, need_state, bond_tier, react_type, bot_class, text, emote, weight FROM npcbot_gift_text");
    if (!result)
    {
        TC_LOG_INFO("server.loading", ">> Loaded 0 npcbot gift texts. Table `npcbot_gift_text` is empty.");
        return;
    }

    uint32 count = 0;
    do
    {
        Field* fields = result->Fetch();

        CompanionGiftText t;
        t.Id        = fields[0].GetUInt32();
        t.ItemKind  = fields[1].GetUInt8();
        t.NeedState = fields[2].GetUInt8();
        t.BondTier  = fields[3].GetUInt8();
        t.ReactType = fields[4].GetUInt8();
        t.BotClass  = fields[5].GetUInt8();
        t.Text      = fields[6].GetString();
        t.Emote     = fields[7].GetUInt32();
        t.Weight    = fields[8].GetUInt8();

        if (t.Text.empty())
        {
            TC_LOG_ERROR("sql.sql", "npcbot_gift_text id {} has empty text, skipped.", t.Id);
            continue;
        }
        if (t.ItemKind == 0 || t.ItemKind > 7)
        {
            TC_LOG_ERROR("sql.sql", "npcbot_gift_text id {} has invalid item_kind {}, skipped.", t.Id, t.ItemKind);
            continue;
        }
        if (t.Weight == 0)
            t.Weight = 1;

        _giftTexts.push_back(std::move(t));
        ++count;
    }
    while (result->NextRow());

    TC_LOG_INFO("server.loading", ">> Loaded {} npcbot gift texts in {} ms", count, GetMSTimeDiffToNow(oldMSTime));
}

// ---------------------------------------------------------------------------
//  A37 第3步：四维度选词。三轮放宽，保证一定选得到。
// ---------------------------------------------------------------------------
CompanionGiftText const* BotCompanionMgr::PickGiftText(uint8 itemKind, uint8 needState,
                                                       uint8 bondTier, uint8 reactType, uint8 botClass) const
{
    std::vector<CompanionGiftText const*> pool;

    for (CompanionGiftText const& t : _giftTexts)
        if (t.ItemKind == itemKind && t.ReactType == reactType
            && (t.NeedState == needState || t.NeedState == 0)
            && (t.BondTier == bondTier || t.BondTier == 0)
            && t.BotClass == botClass)
            pool.push_back(&t);

    if (pool.empty())
        for (CompanionGiftText const& t : _giftTexts)
            if (t.ItemKind == itemKind && t.ReactType == reactType
                && (t.NeedState == needState || t.NeedState == 0)
                && (t.BondTier == bondTier || t.BondTier == 0)
                && t.BotClass == 0)
                pool.push_back(&t);

    if (pool.empty())
        for (CompanionGiftText const& t : _giftTexts)
            if (t.ItemKind == 7 && t.ReactType == reactType && t.BotClass == 0)
                pool.push_back(&t);

    if (pool.empty())
        return nullptr;

    uint32 total = 0;
    for (CompanionGiftText const* t : pool)
        total += t->Weight;

    if (!total)
        return pool[0];

    uint32 roll = urand(0, total - 1);
    for (CompanionGiftText const* t : pool)
    {
        if (roll < t->Weight)
            return t;
        roll -= t->Weight;
    }

    return pool.back();
}

// ---------------------------------------------------------------------------
//  A37 第3步：占位符替换 {item} {player} {n}
// ---------------------------------------------------------------------------
std::string BotCompanionMgr::FormatGiftText(std::string tpl, std::string const& itemName,
                                            std::string const& playerName, uint32 num)
{
    auto replaceAll = [&tpl](std::string const& from, std::string const& to)
    {
        std::size_t pos = 0;
        while ((pos = tpl.find(from, pos)) != std::string::npos)
        {
            tpl.replace(pos, from.length(), to);
            pos += to.length();
        }
    };

    replaceAll("{item}", itemName);
    replaceAll("{player}", playerName);
    replaceAll("{n}", std::to_string(num));
    return tpl;
}

// ---------------------------------------------------------------------------
//  A37 第3步：羁绊等级 0-5 换算成 tier 1-3
// ---------------------------------------------------------------------------
uint8 BotCompanionMgr::BondLevelToTier(uint8 bondLevel)
{
    if (bondLevel <= 1)
        return 1;
    if (bondLevel <= 3)
        return 2;
    return 3;
}

uint8 bot_ai::GetGiftNeedState(uint8 itemKind) const
{
    switch (itemKind)
    {
        case BOT_GIFT_KIND_FOOD:
            return me->GetHealthPct() < 70.0f ? 1 : 2;
        case BOT_GIFT_KIND_DRINK:
            return (me->GetMaxPower(POWER_MANA) > 1 && me->GetPowerPct(POWER_MANA) < 70.0f) ? 1 : 2;
        case BOT_GIFT_KIND_POTION:
            return me->GetHealthPct() < 50.0f ? 1 : 2;
        case BOT_GIFT_KIND_EQUIP:
            return HasRealEquipment() ? 2 : 1;
        default:
            return 0;
    }
}

uint8 bot_ai::GetBondTierWith(Player const* player) const
{
    if (!player)
        return 1;

    QueryResult res = CharacterDatabase.PQuery(
        "SELECT bond_level FROM npcbot_bond WHERE bot_id = {} AND owner_guid = {}",
        me->GetEntry(), player->GetGUID().GetCounter());

    uint8 lvl = res ? res->Fetch()[0].GetUInt8() : 0;
    return BotCompanionMgr::BondLevelToTier(lvl);
}
