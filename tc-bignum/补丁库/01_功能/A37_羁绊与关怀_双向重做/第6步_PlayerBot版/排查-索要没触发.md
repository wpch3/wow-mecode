# 排查：pbot 掉到 50% 血没索要

## 先自查三件事（不用改代码）

`TryBotRequest` 有 6 道前置门槛，任何一道没过都会静默返回。
按最可能的顺序：

### 1. 你和 pbot 组队了吗（最可能）

```cpp
Group* grp = bot->GetGroup();
if (!grp)
{
    timer = 60000;
    return;      // <- 没组队直接返回
}
```

**PlayerBot 版是用「队伍队长」作为索要对象的**，
因为 PlayerBot 没有"主人"概念。

**没组队 = 永远不会索要。**

```text
解决：.pbot invite 鲤鱼      （A39 的指令）
      或者你直接邀请它进队
```

### 2. 你是队长吗

```cpp
Player* owner = ObjectAccessor::FindPlayer(grp->GetLeaderGUID());
if (!owner || owner == bot || ...)
```

它只跟**队长**说话。如果 bot 自己是队长（`owner == bot`），
或者队长是别人，都不会跟你说。

```text
解决：确认队伍面板里【你】有王冠图标
      如果 bot 是队长：.pbot kick 后重新 .pbot invite
```

### 3. 距离和状态

```cpp
if (bot->GetMapId() != owner->GetMapId() || bot->GetExactDist2d(owner) > 40.0f)
if (!bot->IsAlive() || bot->IsInCombat())
if (owner->IsInCombat())
```

```text
必须：同地图 + 40码内 + 双方都脱战 + bot活着
```

**脱战很容易被忽略** —— 打完怪后有几秒战斗状态残留。

### 4. 等够时间了吗

```cpp
_pbotRequestTimer[bguid] = urand(60000, 120000);   // 首次登记 1-2 分钟
```

修复4 加的初始延迟：**bot 上线后头 1-2 分钟不会索要**。
之后每次判断的间隔是 30 秒（无需求时）。

```text
所以最坏情况：上线后 2 分钟 + 30 秒 才会开口
```

## 最快的验证流程

```text
1. .pbot spawn <账号> 鲤鱼
2. .pbot invite 鲤鱼              <- 关键，必须组队
3. 确认你是队长（你的头像有王冠）
4. 站在它旁边（10码内）
5. 让它掉血到 50%（.damage 或让怪打它）
6. 【脱战】—— 走开让战斗状态消失
7. 等 2-3 分钟
```

如果这样还不说话，装下面的诊断日志。

## 已知的设计问题（G11 会一起解决）

现在的索要机制有几个硬伤，我在 G11 规划里一并处理：

| 问题 | 现状 | G11 怎么改 |
|---|---|---|
| 必须组队才索要 | 没队 = 不说话 | 改成"附近有玩家就可能搭话" |
| 只跟队长说 | 队长是别人就不理你 | 改成跟"羁绊最高的在场玩家"说 |
| 索要了也没人管 | `answered` 永远是 0 | 检测你给的东西是否对口，自动标记 |
| 满足后没奖励 | 给了也不加分 | 满足索要额外加羁绊分 |
