## 一、报错原因

`botdatamgr.cpp` 第 910-913 行原文是：

```cpp
910:  void BotDataMgr::LoadNpcBots(bool spawn)
911:  {
912:      if (allBotsLoaded)
913:          return;
```

**第 912 行是函数体的第一行。**

报错 `C2447 "{" 缺少函数标题` 的意思是：
编译器在**函数定义之外**看到了一个 `{`。

典型的错法是把调用语句插在了 910 和 911 之间：

```cpp
void BotDataMgr::LoadNpcBots(bool spawn)
    sBotCompanionMgr->ReloadAll();      // <- 插在这里
{                                        // <- 编译器认为这个 { 没有函数头
    if (allBotsLoaded)
```

## 三、正确的挂载位置：函数【末尾】，不是开头

### 为什么必须放末尾

`LoadCareItems()` 要校验 `item_template` 是否存在（`sObjectMgr->GetItemTemplate`）。
放开头的话，物品表可能还没加载完，会导致**所有物品都被判定为不存在**。

放末尾还有一个好处：`allBotsLoaded = true;` 之后再加载，
逻辑上表示"bot 系统起来了，再挂伙伴数据"。

### 精确位置

**找到 `botdatamgr.cpp` 第 1187-1189 行**，原文是：

```cpp
    allBotsLoaded = true;
}
```

**改成**：

```cpp
    allBotsLoaded = true;

    // step34 伙伴关怀：台词、物品池、bot虚拟背包
    // 必须放在这里（函数末尾）—— LoadCareItems 要校验 item_template，
    // 放函数开头的话物品表还没加载完，会误判所有物品都不存在。
    sBotCompanionMgr->ReloadAll();
}
```

### 怎么快速定位

在 VS 里 `Ctrl+F` 搜：

```
allBotsLoaded = true;
```

**全文件只有这一处**（第 1187 行），它下面紧跟着一个 `}` 就是函数结尾。
